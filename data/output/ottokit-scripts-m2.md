## Lecon 2.7 — Troubleshooting : les 5 erreurs les plus courantes a l'installation

**Duree** : 5 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast WordPress admin + app.ottokit.com

---

**[INTRO — face camera]**

L'installation s'est bien passee pour toi ? Tant mieux. Mais si tu es bloque, ou si un eleve te pose la question, voici les 5 problemes les plus frequents et leurs solutions.

**[ECRAN — slide "Erreur 1 : Connexion echouee — SSL manquant"]**

**Probleme** : tu cliques sur "Connect" mais rien ne se passe, ou tu obtiens une erreur "SSL required".

**Cause** : ton site n'est pas en HTTPS. OttoKit refuse les connexions non securisees.

**Solution** :

[Montre la barre d'adresse du navigateur — HTTP vs HTTPS]

- Verifie que ton hebergeur a active le certificat SSL
- Force HTTPS dans les reglages WordPress : Reglages > General > remplace http:// par https://
- Si tu utilises Cloudflare, active "Always Use HTTPS"

**[ECRAN — slide "Erreur 2 : Le plugin ne detecte pas les plugins WP"]**

**Probleme** : tu connectes ton site, mais OttoKit ne voit aucun plugin compatible.

**Cause** : les plugins ne sont pas actifs, ou le cache empeche la detection.

**Solution** :

[Montre la page Extensions dans WordPress]

- Verifie que les plugins (WooCommerce, FluentCRM, etc.) sont bien actifs
- Vide le cache de ton site (plugin de cache, serveur)
- Deconnecte et reconnecte ton site dans OttoKit
- Attends 2-3 minutes : la detection n'est pas toujours instantanee

**[ECRAN — slide "Erreur 3 : Timeout a la connexion"]**

**Probleme** : la connexion demarre mais tourne en boucle, puis echoue avec un timeout.

**Cause** : ton serveur met trop de temps a repondre — souvent un hebergement mutualize trop lent.

**Solution** :

- Desactive temporairement les plugins de cache et de securite
- Augmente le timeout PHP dans wp-config.php (si tu as acces) :

```
set_time_limit(300);
```

- Contacte ton hebergeur pour verifier que les requetes REST API ne sont pas bloquees

**[ECRAN — slide "Erreur 4 : Pare-feu ou plugin de securite qui bloque"]**

**Probleme** : la connexion echoue avec une erreur 403 ou "Forbidden".

**Cause** : un plugin de securite (Wordfence, Sucuri, iThemes Security) bloque les requetes d'OttoKit.

**Solution** :

[Montre les reglages Wordfence en exemple]

- Ajoute les IPs d'OttoKit en liste blanche dans ton plugin de securite
- Desactive temporairement le firewall applicatif pour tester
- Verifie les regles du pare-feu de ton hebergeur (ModSecurity, etc.)
- Si ca fonctionne avec le firewall desactive, reactive-le et ajoute les exceptions

**[ECRAN — slide "Erreur 5 : WP-Cron desactive ou defaillant"]**

**Probleme** : la connexion fonctionne, mais les triggers ne se declenchent pas ou avec un gros retard.

**Cause** : WP-Cron est desactive ou ne fonctionne pas correctement. OttoKit utilise le cron pour communiquer avec le cloud.

**Solution** :

[Montre le fichier wp-config.php]

- Verifie que cette ligne n'est PAS dans ton wp-config.php :

```
define('DISABLE_WP_CRON', true);
```

- Si WP-Cron est desactive volontairement (cron systeme), assure-toi que le cron systeme tourne bien toutes les minutes
- Installe le plugin "WP Crontrol" pour verifier que les taches cron sont planifiees

[Montre Outils > Sante du site dans WordPress]

- Va dans Outils > Sante du site > Info. Verifie que le cron est marque comme actif.

**[ECRAN — slide "Resume des 5 erreurs"]**

| Erreur | Cause | Solution rapide |
|--------|-------|-----------------|
| Connexion echouee | SSL manquant | Activer HTTPS |
| Plugins non detectes | Plugins inactifs ou cache | Reactiver + vider le cache |
| Timeout | Serveur lent | Desactiver cache/securite temporairement |
| Erreur 403 | Pare-feu bloque | Ajouter IPs en whitelist |
| Triggers en retard | WP-Cron desactive | Verifier wp-config.php |

**[TRANSITION — face camera]**

Si tu rencontres un probleme qui n'est pas dans cette liste, la premiere chose a faire : va dans l'historique OttoKit et lis le message d'erreur. Il est souvent explicite. Sinon, le support Brainstorm Force est reactif.

Tu as termine le Module 2. Tu sais installer OttoKit, connecter ton site, ajouter une app, creer un workflow, le tester et le publier. Place au quiz pour valider tout ca.

- Les plugins de securite et le cache sont les premieres causes de blocage
- WP-Cron doit etre actif pour que les triggers fonctionnent
- L'historique OttoKit affiche les messages d'erreur detailles
