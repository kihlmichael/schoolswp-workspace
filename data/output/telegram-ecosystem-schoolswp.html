1. Vue d'ensemble

L'écosystème Telegram schoolsWP sert 3 usages distincts :

  • Production interne (allowlist stricte) : 5 agents spécialisés pilotant la rédaction, le SEO, l'automation, le social et l'orchestration Claude Code.
  • Interface mobile Claude (allowlist stricte) : 2 ponts mobiles (Claude Code à distance + Claude brainstorm).
  • Diffusion & acquisition (public) : 1 canal d'annonce des articles + 1 point d'entrée public accueillant les nouveaux visiteurs.

5. Sécurité & accès

  • Allowlist : TELEGRAM_ALLOWED_USERS=1020689775 (userID Michaël)
  • Webhook secret : TELEGRAM_WEBHOOK_SECRET (64 chars hex, vérifié header X-Telegram-Bot-Api-Secret-Token)
  • Admin token : ADMIN_TOKEN (reload contexte via /admin/reload)
  • Exemption allowlist : seul le bot welcome accepte les messages de n'importe qui (via PUBLIC_AGENTS)
  • Secrets : .env et .env.production gitignored, jamais commités
Point clé : les 4 agents internes (studio, radar, flow, pulse) rejettent silencieusement les messages non-allowlistés. Aucun retour utilisateur. Pour tester avec un 2e compte, il faut l'ajouter à TELEGRAM_ALLOWED_USERS séparé par virgules.

6. Opérations — déploiement & maintenance

Déploiement standard (après git push)

Via xCloud panel → Sites → telegram-agents → Node.js → Run Custom Command :

cd /var/www/telegram-agents.wp1.host && \
git pull origin main && \
npm install && \
pm2 restart telegram_agents --update-env && \
pm2 save

Ajouter un nouveau token (one-liner printf)

cd /var/www/telegram-agents.wp1.host && \
printf '\nTELEGRAM_TOKEN_NEWBOT=xxx:yyy\n' >> .env && \
pm2 restart telegram_agents --update-env
Bug xCloud connu : ne pas utiliser heredoc (<<'EOF') dans les Custom Commands — la UI tronque le délimiteur. Toujours printf one-liner.

Enregistrer les webhooks Telegram

cd /var/www/telegram-agents.wp1.host && \
node register-webhooks.js https://telegram-agents.wp1.host

Statut & logs

pm2 list
pm2 logs telegram_agents --lines 30 --nostream
curl http://localhost:3000/health | jq

Rollback

cd /var/www/telegram-agents.wp1.host && \
git reset --hard HEAD~1 && \
npm install && \
pm2 restart telegram_agents --update-env

8. Troubleshooting

Symptôme Diagnostic / fix
Bot muet complètement 1. pm2 list — vérifier telegram_agents online
2. /health — doit lister l'agent
3. api.telegram.org/bot$TOKEN/getWebhookInfo — vérifier URL
4. Si webhook cassé : re-register via register-webhooks.js
Bot rejette un utilisateur Logs : rejected fromId=... (not in allowlist). Ajouter le userID à TELEGRAM_ALLOWED_USERS + restart PM2.
Webhook retourne 401 TELEGRAM_WEBHOOK_SECRET ne matche pas. Re-register les webhooks.
Bot répond lentement Vérifier CLAUDE_MODE=api (pas subprocess). Subprocess = lancement CLI claude à chaque message, très lent.
Context markdown trop gros Warning au boot : [CONTEXT] X.md dépasse 10kB. Raccourcir le fichier dans context/ puis /admin/reload.
PM2 newline bug (ecosystem) File ecosystem.config.cjs not found via Deploy Now xCloud. Ne pas utiliser Deploy Now, passer par Run Custom Command.
