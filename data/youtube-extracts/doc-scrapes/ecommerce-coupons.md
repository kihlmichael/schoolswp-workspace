# Coupons eCommerce
> Source : https://docs.themeum.com/tutor-lms/ecommerce/coupons/

## Prerequis

Activer le eCommerce natif : **Tutor LMS > Settings > Monetization** > selectionner **Native**. L'onglet **Coupons** apparait dans le menu Tutor LMS.

## Creer un coupon

Cliquer **Create Coupon** dans l'onglet Coupons.

### Coupon Info

**Deduction Method** — comment le discount s'applique :
- **Code** : l'etudiant saisit un code au checkout
- **Automatic** : le discount s'applique automatiquement pour les items eligibles

**Coupon Title** — nom interne pour identification (ex: "Summer Sale 2024")

**Coupon Code** — code saisi au checkout (ex: SUMMER20), ou cliquer **Generate Code** pour creation automatique

### Discount

**Discount Type** :
- **Percent** : pourcentage de reduction sur le prix du cours
- **Amount** : montant fixe en dollars

**Discount Value** — valeur numerique correspondant au type choisi

**Applies To** — portee du discount :
- All Courses
- All Bundles
- All Courses and Bundles
- Specific Courses (selectionner via "Add Items")
- Specific Bundles (selectionner via "Add Items")
- Specific Category (selectionner via "Add Items")

### Usage Limitation

**Total Usage Limit** — nombre total de fois que le coupon peut etre utilise (tous etudiants confondus)

**Per-Customer Usage Limit** — nombre de fois qu'un etudiant individuel peut utiliser le coupon

### Minimum Purchase Requirements

Choisir une option :
- **No Minimum Requirements** : le coupon s'applique a tout achat
- **Minimum Purchase Amount** : seuil minimum en dollars (ex: $50)
- **Minimum Quantity of Items** : nombre minimum de cours dans le panier

### Validity

**Start Date** — date d'activation du coupon

**End Date** — date d'expiration optionnelle ; laisser vide pour une validite indefinie

## Activate and Save

Apres avoir rempli tous les champs, cliquer **Save** pour finaliser. Un apercu en direct s'affiche a droite pendant la configuration.

## Checkout Settings

Dans **Tutor LMS > Settings**, activer **Enable Coupon Code** pour autoriser l'application de coupons au checkout. Desactiver empeche l'utilisation des coupons sauvegardes lors de l'achat.
