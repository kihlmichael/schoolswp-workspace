# Certificate Builder — Installation

> Source : https://docs.themeum.com/tutor-lms/tutor-lms-certificate-builder/installation/

## Installation

To get started with installing the Tutor LMS Certificate builder the process is the same as all the other WordPress plugins. If you are already a user of Tutor LMS Pro you should be able to install the Tutor LMS Certificate builder with ease

## Install & Activate the Tutor LMS Certificate Builder

It's very easy to install Tutor LMS Certificate builder. Go to your [Tutor LMS Downloads](https://tutorlms.com/account/downloads/) page and there you will find the download file for Tutor LMS Certificate Builder.

Download the file and install it on your WordPress site, just like you would install any other plugin. Navigate to **WP-dashboard** > **Plugins** > **Add New**

Click on the Add New button and upload the Tutor LMS Certificate Builder plugin zip file. Once it's uploaded and installed, then activate it from the plugin list.

After successful installation, activate the plugin to start creating unique certificates for your Tutor LMS site.

**Please make sure you have enabled the Certificate Add-on from the Add-ons list.**
