# Quiz Settings
> Source : https://docs.themeum.com/tutor-lms/quizzes/quiz-settings/

## Basic Settings

### Time Limit

Definir une duree en secondes, minutes, heures, jours ou semaines. Mettre 0 pour desactiver la contrainte de temps. Exemple : 30 minutes oblige l'etudiant a terminer dans ce delai.

### Hide Quiz Time

Activer pour masquer le compte a rebours pendant que l'etudiant passe le quiz.

### Feedback Mode

Trois modes de feedback apres completion :

- **Default** : revele les bonnes reponses uniquement apres la fin du quiz complet
- **Reveal Mode** : affiche les reponses immediatement apres chaque tentative
- **Retry Mode** : permet plusieurs tentatives avec un nombre configurable via Attempts Allowed

### Attempts Allowed

Nombre maximum de tentatives (defaut : 10). Mettre 0 pour des tentatives illimitees.

### Passing Grade

Pourcentage minimum requis pour reussir le quiz.

### Max Questions Allowed

Randomise la selection des questions depuis le pool. Exemple : avec 50 questions au total, definir 10 signifie que chaque etudiant repond a une selection aleatoire unique de 10 questions.

### Prerequisites

Exiger la completion de lecons ou quiz specifiques avant d'acceder a ce quiz.

---

## Advanced Settings

### Quiz Auto Start

Activer pour demarrer automatiquement le quiz au chargement de la page.

### Question Layout

Choisir le format de presentation :
- **Single Question** : une question a la fois
- **Pagination** : questions paginees
- **Sequential** : questions les unes en dessous des autres (Question below the other)

### Hide Question Number

Activer pour masquer la numerotation des questions pendant le quiz.

### Set Character Limit for Short Answers

Configurer le nombre maximum de caracteres autorise (defaut : 200).

### Set Character Limit for Open-Ended/Essay Answers

Configurer le nombre maximum de caracteres autorise (defaut : 500).
