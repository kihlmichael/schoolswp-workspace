# Troubleshooting — General

> Source : https://docs.themeum.com/tutor-lms/troubleshooting/general/

## General

1. Check if you are using the latest version of PHP.
2. Check if you are using the latest version of MySQL or MariaDB.
3. Check if you are using the latest version of WordPress.
4. Check if you are using the latest version of Tutor LMS.
5. Check if you have set the correct time and date format in WordPress.
6. Check if the date and time formats are working properly from a post and saving times.
7. Check if you have set "Post Name" on the permalink settings.
8. Check if your hosting has sufficient space to upload images, videos and other media items.
9. Check if your uploads and other folders have writing permission.
10. Check WordPress Health Report from the **Admin Dashboard > Tools > Site Health**. All the possible issues can be listed there.
11. Check **Tutor LMS > Tools** page for potential misconfigurations.
12. Check browser console for JavaScript issues. You should also check after disabling all the browser extensions as well.
