# Orders eCommerce
> Source : https://docs.themeum.com/tutor-lms/ecommerce/orders/

## Prerequis

Activer le eCommerce natif : **Tutor LMS > Settings > Monetization** > selectionner **Native**. L'onglet **Orders** apparait dans le menu Tutor LMS.

## Order Tab

Le tableau des commandes affiche toutes les commandes avec :

**Informations affichees :**
- Statut de la commande (pending ou completed)
- Suivi du statut de paiement
- Methode de paiement utilisee

**Actions disponibles :**
- Bulk trash : supprimer plusieurs commandes en lot
- Edit : cliquer le bouton edit pour modifier une commande individuelle
- Voir les informations completes de la commande

## Order Details

La page de details fournit des informations completes sur chaque transaction :

- Informations detaillees de la commande
- Journal d'activite et mises a jour
- Ventilation complete du paiement
- Montant paye par l'etudiant

Acceder aux details en cliquant l'option edit depuis le tableau des commandes.

## Order Refund

Les remboursements se traitent depuis la page de details de la commande.

**Processus de remboursement :**

1. Cliquer le bouton **Refund**
2. Specifier le montant du remboursement :
   - **Full** : remboursement total
   - **Partial** : remboursement partiel
   - **Custom** : montant personnalise
3. **Obligatoire** : ajouter une raison pour le remboursement (champ requis)
4. **Optionnel** : cocher la case pour retirer l'etudiant du cours ("remove the student from the course")

Le popup de remboursement affiche le montant du paiement original pour aider a determiner le montant a rembourser.

## Order Cancellation

L'annulation est disponible depuis la section en haut a droite de la page de details.

**Processus d'annulation :**

1. Selectionner une raison d'annulation specifique dans le menu deroulant
2. Si applicable, selectionner **Other** et fournir un contexte supplementaire (optionnel)

> La selection d'une raison est obligatoire pour l'annulation d'une commande.
