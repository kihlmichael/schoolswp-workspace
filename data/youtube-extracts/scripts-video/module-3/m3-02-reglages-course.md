# Module 3 — Lecon 2 : Reglages Course
> Duree estimee : 4 min | Type : Adapte du transcript video #05

## Script de narration

[INTRO]

Les reglages des cours dans Tutor LMS sont parmi les plus importants. Ils definissent comment tes formations fonctionnent au quotidien : visibilite, acces, mode de completion, quiz... On passe tout en revue.

[CONTENU]

Rends-toi dans Tutor LMS, Reglages, onglet Course.

[CAPTURE ECRAN : Menu Settings > Course]

Premiere option : la visibilite des cours. Si tu actives ce toggle, seuls les utilisateurs connectes pourront voir tes formations. Ceux qui ne sont pas connectes ne verront rien. Utile si tu veux creer un espace prive, mais en general, laisse-le desactive pour que tes pages de vente restent accessibles.

[CAPTURE ECRAN : Toggle "Course Visibility" avec explication]

Ensuite, l'acces au contenu des cours. En l'activant, tu permets aux instructeurs et aux admins de consulter le contenu d'un cours sans avoir besoin de s'y inscrire. Pratique pour verifier qu'un cours est bien configure avant publication.

[CAPTURE ECRAN : Toggle "Course Content Access"]

Le resume du contenu de cours permet de cacher une partie du descriptif derriere un bouton "Afficher plus". Ca evite d'avoir une page de vente trop longue d'un coup.

[CAPTURE ECRAN : Apercu front-end avec le bouton "Show More"]

L'option de redirection automatique : quand un eleve termine son paiement WooCommerce, il est redirige directement vers le cours qu'il vient d'acheter. Active-le — ca ameliore l'experience utilisateur.

[CAPTURE ECRAN : Toggle "Auto Redirect to Courses"]

Le mode Spotlight est une fonctionnalite cle. En l'activant, le header et le footer de ton site disparaissent quand un eleve consulte une lecon. Resultat : l'eleve reste concentre sur le contenu, sans distraction. Je te recommande fortement de l'activer.

[CAPTURE ECRAN : Comparaison d'une lecon avec et sans mode Spotlight]

Pour le mode de completion d'un cours, tu as deux choix. Le mode Flexible laisse l'eleve avancer a son rythme, sans contrainte. Le mode Strict oblige l'eleve a completer toutes les lecons et reussir tous les quiz avant de valider le cours. Si tu delivres un certificat, le mode Strict est plus adapte.

[CAPTURE ECRAN : Selection Flexible vs Strict]

L'option de reprise de cours permet a un eleve de recommencer un cours qu'il a deja termine. A activer si tes formations meritent d'etre revues.

[CAPTURE ECRAN : Toggle "Course Retake"]

Pour les fichiers joints, tu peux choisir entre telechargement direct ou ouverture dans un nouvel onglet. Le telechargement est souvent preferable pour les documents de travail.

[CAPTURE ECRAN : Selection du mode d'ouverture des pieces jointes]

L'expiration d'inscription te permet de definir une duree d'acces. Passe un delai, l'eleve perd l'acces au cours. Utile pour les formations a acces limite, mais a utiliser avec precaution.

[CAPTURE ECRAN : Toggle et champ de duree d'expiration]

Tu peux activer l'editeur WordPress classique pour editer tes lecons, si tu preferes ca a l'editeur Tutor.

[CAPTURE ECRAN : Toggle editeur classique]

Le chargement automatique du contenu suivant : une fois qu'un eleve termine une lecon ou un quiz, le contenu suivant se charge automatiquement. Ca fluidifie le parcours.

[CAPTURE ECRAN : Toggle "Auto Load Next Content"]

Les commentaires sur les lecons permettent a tes eleves de laisser des retours sur chaque lecon individuellement. Tres utile pour recueillir du feedback.

[CAPTURE ECRAN : Toggle commentaires et apercu front-end]

Passons aux reglages des quiz. Quand le timer d'un quiz expire, tu as deux options : soumission automatique, ou abandon automatique. Avec l'abandon, l'eleve doit soumettre manuellement avant la fin du temps — ca ajoute une pression supplementaire.

[CAPTURE ECRAN : Selection du comportement a l'expiration du timer]

Tu peux definir le nombre de tentatives autorisees pour un quiz. Zero signifie tentatives illimitees.

[CAPTURE ECRAN : Champ nombre de tentatives]

Le bouton "Question precedente" permet aux eleves de revenir en arriere dans un quiz. A toi de voir si tu veux l'autoriser.

[CAPTURE ECRAN : Toggle bouton precedent]

Pour le calcul de la note finale, tu as quatre options : la meilleure note, la moyenne, la premiere tentative ou la derniere tentative. Si tu autorises plusieurs tentatives, la meilleure note est souvent le choix le plus juste.

[CAPTURE ECRAN : Selection du mode de calcul des notes]

Et enfin, tu choisis les sources video autorisees sur ta plateforme. Les sources que tu decoches ne seront plus disponibles dans le constructeur de cours.

[CAPTURE ECRAN : Cases a cocher des sources video]

[RECAP]

Les reglages de cours, c'est le coeur de Tutor LMS. Visibilite, Spotlight, mode de completion, quiz, sources video — chaque option impacte directement l'experience de tes eleves. Prends le temps de bien les configurer. Prochaine lecon : les reglages de design.
