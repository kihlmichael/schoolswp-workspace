# Module 2 — Lecon 1 : Dashboard frontend (tous utilisateurs)
> Duree estimee : 3 min | Type : A creer

## Script de narration

[INTRO]
Dans cette lecon, on fait le tour complet du dashboard TutorLMS cote frontend. C'est l'espace que chaque utilisateur — etudiant, instructeur ou admin — voit quand il se connecte. Tu vas decouvrir chaque section et comprendre a quoi elle sert.

[CONTENU]

[CAPTURE ECRAN : page du dashboard frontend TutorLMS, vue globale avec la sidebar a gauche]

Quand tu te connectes a ton site avec TutorLMS active, tu accedes au dashboard frontend. C'est une interface separee du back-office WordPress, pensee pour etre plus simple et plus visuelle.

Sur la gauche, tu as la sidebar de navigation. Elle regroupe toutes les sections accessibles. On va les parcourir une par une.

[CAPTURE ECRAN : section Dashboard Overview avec les statistiques]

La premiere section, c'est le Dashboard Overview. Tu y trouves un resume de ton activite : nombre de cours suivis, cours termines, cours en cours, et certificats obtenus. C'est ton tableau de bord personnel.

[CAPTURE ECRAN : section My Profile avec les champs editables]

Ensuite, My Profile. C'est ici que tu modifies tes informations personnelles : nom, bio, photo de profil, liens vers tes reseaux sociaux. Ces informations apparaissent sur ton profil public.

[CAPTURE ECRAN : section Enrolled Courses avec la liste des cours]

La section Enrolled Courses affiche tous les cours auxquels tu es inscrit. Tu vois la progression de chaque cours avec une barre de pourcentage, et tu peux reprendre directement la ou tu t'es arrete.

[CAPTURE ECRAN : section Wishlist avec des cours sauvegardes]

La Wishlist, c'est ta liste de favoris. Quand tu parcours le catalogue et qu'un cours t'interesse sans que tu veuilles t'inscrire tout de suite, tu l'ajoutes ici. Pratique pour ne rien oublier.

[CAPTURE ECRAN : section Reviews avec les avis laisses]

Dans Reviews, tu retrouves tous les avis que tu as laisses sur les cours que tu as suivis. Tu peux les consulter et les modifier si besoin.

[CAPTURE ECRAN : section Quiz Attempts avec l'historique des tentatives]

Quiz Attempts liste toutes tes tentatives de quiz. Pour chaque quiz, tu vois ton score, le statut (reussi ou echoue), et la date de la tentative. Tu peux aussi consulter le detail de tes reponses.

[CAPTURE ECRAN : section Order History avec les commandes]

Order History affiche l'historique de tes achats si tu as des cours payants sur le site. Tu retrouves les montants, les dates et les statuts de paiement.

[CAPTURE ECRAN : section Q&A avec les questions posees]

La section Q&A centralise toutes les questions que tu as posees dans les cours. Tu vois les reponses des instructeurs et tu peux continuer la discussion directement depuis cette page.

[CAPTURE ECRAN : section Calendar avec la vue mensuelle]

Enfin, le Calendar. Il affiche les evenements lies a tes cours : dates de debut, echeances de devoirs, sessions planifiees. Ca te donne une vue d'ensemble de ton planning de formation.

[CAPTURE ECRAN : bouton "Creer un cours" dans le dashboard]

Dernier point : si ton role le permet, tu verras aussi un bouton pour creer un cours directement depuis le dashboard. On reviendra dessus dans la lecon suivante.

[RECAP]
Tu connais maintenant les 9 sections du dashboard frontend TutorLMS. C'est le point central pour suivre ta progression, gerer ton profil, et acceder a toutes tes activites de formation. Dans la prochaine lecon, on passe cote instructeur et admin pour decouvrir les sections supplementaires.
