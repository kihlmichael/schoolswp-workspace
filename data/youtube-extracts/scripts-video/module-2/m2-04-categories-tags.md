# Module 2 — Lecon 4 : Menu Categories et Tags
> Duree estimee : 2 min 30 | Type : A creer

## Script de narration

[INTRO]
Pour que tes etudiants s'y retrouvent dans ton catalogue, tu dois organiser tes cours. TutorLMS utilise les categories et les tags de WordPress pour ca. Dans cette lecon, tu apprends a les creer, les gerer et les utiliser intelligemment.

[CONTENU]

[CAPTURE ECRAN : menu TutorLMS > Course Categories dans le back-office]

Dans le menu TutorLMS, tu trouves Course Categories. C'est exactement le meme systeme que les categories d'articles WordPress — si tu connais deja, tu ne seras pas perdu.

[CAPTURE ECRAN : formulaire de creation de categorie avec les champs Nom, Slug, Parent, Description]

Pour creer une categorie, tu remplis quatre champs. Le nom, c'est ce qui s'affiche sur le site — par exemple "Marketing Digital". Le slug, c'est la version URL — genere automatiquement si tu le laisses vide. Le parent te permet de creer des sous-categories. Et la description, optionnelle, peut s'afficher sur la page archive de la categorie.

[CAPTURE ECRAN : liste des categories avec une hierarchie parent/enfant visible]

Les categories sont hierarchiques. Tu peux creer des niveaux. Par exemple : "WordPress" comme categorie parente, puis "Themes", "Plugins" et "Securite" comme sous-categories. Ca structure ton catalogue et aide les visiteurs a naviguer.

[CAPTURE ECRAN : image de categorie (thumbnail) si le theme le supporte]

Selon ton theme, tu peux aussi ajouter une image a chaque categorie. Elle apparaitra sur la page du catalogue pour donner un apercu visuel de chaque thematique.

[CAPTURE ECRAN : menu TutorLMS > Course Tags]

Passons aux Tags. Contrairement aux categories, les tags ne sont pas hierarchiques. Ce sont des mots-cles libres que tu associes a un cours pour le decrire plus finement.

[CAPTURE ECRAN : formulaire de creation de tag avec Nom, Slug, Description]

La creation d'un tag est plus simple : un nom, un slug et une description optionnelle. Par exemple, pour un cours sur WooCommerce, tu pourrais ajouter les tags "ecommerce", "paiement en ligne", "boutique".

[CAPTURE ECRAN : editeur de cours avec les metaboxes Categorie et Tags sur le cote]

Quand tu crees ou modifies un cours, tu retrouves les categories et les tags dans les metaboxes a droite de l'editeur. Tu coches les categories et tu tapes tes tags — comme pour un article WordPress classique.

[CAPTURE ECRAN : page catalogue frontend avec les filtres par categorie]

Cote frontend, les categories apparaissent comme filtres sur la page du catalogue. Les etudiants peuvent cliquer sur une categorie pour voir uniquement les cours qui en font partie. Les tags permettent aussi de naviguer entre cours lies.

Mon conseil : limite-toi a 5 ou 6 categories principales maximum, avec eventuellement un niveau de sous-categories. Pour les tags, sois coherent — utilise toujours les memes termes et evite les doublons. Un catalogue bien organise, c'est un catalogue ou les etudiants trouvent ce qu'ils cherchent.

[RECAP]
Categories hierarchiques pour structurer, tags libres pour affiner. Les deux sont des taxonomies WordPress natives, donc tu les maitrises si tu connais deja WordPress. Prochaine lecon : la gestion des etudiants et des instructeurs.
