# Module 2 — Lecon 7 : Menu Quiz Attempts et Outils
> Duree estimee : 3 min | Type : A creer

## Script de narration

[INTRO]
Derniere lecon du module 2. On termine avec deux sections essentielles du back-office TutorLMS : le suivi des tentatives de quiz et les outils d'administration. C'est ce qui te permet de controler l'apprentissage et de maintenir ta plateforme en bon etat.

[CONTENU]

[CAPTURE ECRAN : menu TutorLMS > Quiz Attempts dans le back-office]

La section Quiz Attempts du back-office centralise toutes les tentatives de quiz de tous les etudiants, tous cours confondus. C'est ta vue d'ensemble sur l'evaluation.

[CAPTURE ECRAN : liste des tentatives avec colonnes etudiant, cours, quiz, score, statut, date]

Le tableau affiche pour chaque tentative : l'etudiant, le cours, le quiz concerne, le score obtenu, le statut — reussi, echoue ou en attente de correction — et la date. Tu as tout sous les yeux.

[CAPTURE ECRAN : filtres par cours, par quiz, par statut]

Les filtres sont precieux ici. Tu peux afficher uniquement les tentatives d'un cours, d'un quiz specifique, ou filtrer par statut. Par exemple, afficher seulement les tentatives en attente de correction manuelle.

[CAPTURE ECRAN : detail d'une tentative avec les reponses de l'etudiant]

En cliquant sur une tentative, tu accedes au detail complet. Chaque question est affichee avec la reponse de l'etudiant et la bonne reponse. Pour les questions a choix multiples, la correction est automatique. Pour les questions ouvertes ou les essais, c'est a toi de noter.

[CAPTURE ECRAN : correction manuelle d'une question ouverte avec champ de note et commentaire]

Pour corriger manuellement, tu attribues une note et tu peux laisser un commentaire. L'etudiant verra ton feedback quand il consultera sa tentative. C'est un outil pedagogique autant qu'un outil d'evaluation.

[CAPTURE ECRAN : bouton "Approve" ou "Reject" sur une tentative en attente]

Une fois toutes les questions corrigees, tu approuves ou rejettes la tentative. Le statut final — reussi ou echoue — depend du seuil de reussite que tu as defini dans les parametres du quiz.

[CAPTURE ECRAN : menu TutorLMS > Tools dans le back-office]

Passons aux outils d'administration. Le menu Tools regroupe des fonctions utilitaires pour la maintenance de ta plateforme.

[CAPTURE ECRAN : page Tools avec les onglets Import/Export]

La fonction Import/Export te permet de sauvegarder tes cours et de les reimporter. L'export genere un fichier qui contient la structure du cours — lecons, quiz, topics. Tu peux l'utiliser pour migrer un cours vers un autre site TutorLMS ou pour garder une sauvegarde.

[CAPTURE ECRAN : onglet Import avec le champ d'upload de fichier]

L'import fonctionne dans l'autre sens. Tu charges un fichier exporte depuis un autre site TutorLMS, et le cours est recree avec toute sa structure. Les contenus media ne sont pas inclus — tu devras les reajouter manuellement.

[CAPTURE ECRAN : page Status/Diagnostic avec les informations systeme]

L'outil de diagnostic affiche les informations techniques de ton installation : version de TutorLMS, version de PHP, extensions actives, conflits eventuels. C'est la premiere chose a verifier si tu rencontres un probleme technique. Tu peux copier ces informations pour les envoyer au support.

[CAPTURE ECRAN : section Pages avec la verification des pages requises par TutorLMS]

Tu trouveras aussi une verification des pages. TutorLMS a besoin de certaines pages WordPress pour fonctionner — page du dashboard, page du catalogue, page de checkout. L'outil te dit si elles existent et si elles sont correctement configurees.

[RECAP]
Tu maitrises maintenant le suivi des quiz — consultation, correction manuelle, approbation — et les outils d'administration — import/export et diagnostic. Avec cette lecon, tu as fait le tour complet de l'interface TutorLMS. Tu es pret pour le Module 3, ou on passera a la creation de cours.
