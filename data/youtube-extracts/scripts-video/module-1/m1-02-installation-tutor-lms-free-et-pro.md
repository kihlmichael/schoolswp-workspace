# Module 1 — Lecon 2 : Installation de Tutor LMS Free et Pro
> Duree estimee : 3 min | Type : Adapte du transcript (videos #2 et #30)

## Script de narration

[INTRO]
Dans cette lecon, tu vas installer les deux versions de Tutor LMS : la version gratuite depuis WordPress, puis la version Pro depuis le site officiel. Les deux doivent etre installees et activees ensemble pour que le Pro fonctionne.

[CONTENU]
On commence par la version gratuite. C'est l'etape obligatoire — meme si tu as achete la version Pro, tu as besoin de la version Free comme base.

Rends-toi dans ton tableau de bord WordPress. Dans le menu lateral, clique sur Extensions, puis Ajouter.

[CAPTURE ECRAN : menu Extensions > Ajouter dans WordPress]

Dans la barre de recherche, tape "Tutor LMS". Le premier resultat qui apparait, c'est le plugin officiel de Themeum. Clique sur Installer maintenant.

[CAPTURE ECRAN : resultat de recherche "Tutor LMS" dans le repertoire WordPress]

L'installation prend quelques secondes. Une fois terminee, clique sur Activer. Tutor LMS Free est maintenant installe — tu devrais voir un nouveau menu "Tutor LMS" dans ta barre laterale WordPress.

[CAPTURE ECRAN : menu Tutor LMS visible dans la barre laterale apres activation]

Passons a la version Pro. Pour ca, tu dois te rendre sur le site tutor lms point com. Connecte-toi avec le compte que tu as utilise pour acheter ta licence.

[CAPTURE ECRAN : page de connexion tutor lms point com]

Une fois connecte, clique sur ton profil en haut a droite, puis sur Downloads. Tu verras la liste des produits disponibles sur ton compte. Clique sur "Download Latest" a cote de Tutor LMS Pro pour telecharger le fichier zip.

[CAPTURE ECRAN : page Downloads avec le bouton "Download Latest" pour Tutor LMS Pro]

Pendant que tu es sur cette page, je te conseille aussi de telecharger le Certificate Builder si tu prevois de delivrer des certificats a tes etudiants. On en reparlera dans un module dedie.

Retourne maintenant dans WordPress. Va dans Extensions, puis Ajouter. Cette fois, clique sur le bouton Telecharger une extension en haut de la page.

[CAPTURE ECRAN : bouton "Telecharger une extension" en haut de la page Ajouter des extensions]

Clique sur Parcourir, selectionne le fichier zip de Tutor LMS Pro que tu viens de telecharger, puis clique sur Installer maintenant.

[CAPTURE ECRAN : interface d'upload avec le fichier zip selectionne]

L'installation se lance. Une fois terminee, WordPress te confirme que le plugin a ete installe avec succes. Clique sur Activer l'extension.

[CAPTURE ECRAN : message "Extension installee avec succes" avec le bouton Activer]

Et voila. Tu as maintenant Tutor LMS Free et Tutor LMS Pro installes et actives cote a cote. C'est normal d'avoir les deux — le Pro s'appuie sur le Free pour fonctionner, ils ne se remplacent pas.

[CAPTURE ECRAN : liste des extensions avec Tutor LMS et Tutor LMS Pro tous deux actifs]

[RECAP]
Deux etapes a retenir : installe d'abord la version gratuite depuis le repertoire WordPress, puis telecharge et uploade la version Pro depuis ton compte sur tutor lms point com. Les deux versions doivent rester actives en permanence. Dans la prochaine lecon, on active la licence Pro pour debloquer toutes les fonctionnalites.
