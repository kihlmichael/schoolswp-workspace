# Module 1 — Lecon 3 : Activation de la licence Pro
> Duree estimee : 2 min | Type : Adapte du transcript (videos #2 et #30)

## Script de narration

[INTRO]
Tu as installe Tutor LMS Free et Pro — bien joue. Maintenant, il faut activer ta licence pour debloquer les fonctionnalites premium et recevoir les mises a jour automatiques. C'est rapide, on fait ca ensemble.

[CONTENU]
Premiere etape : generer ta cle de licence. Retourne sur tutor lms point com et connecte-toi a ton compte.

Dans le menu de ton profil, clique sur Licenses. C'est ici que tu vas associer ton site WordPress a ta licence.

[CAPTURE ECRAN : page Licenses sur tutor lms point com]

Clique sur le bouton "Add Website". Une fenetre s'ouvre. Si tu as plusieurs abonnements, selectionne d'abord le plan concerne. Ensuite, colle l'URL complete de ton site WordPress — par exemple https://monsite.com — et clique sur Submit.

[CAPTURE ECRAN : popup "Add Website" avec champ URL et bouton Submit]

Une fois le site ajoute, une cle de licence apparait. Clique sur l'icone de copie a cote de la cle pour la copier dans ton presse-papiers.

[CAPTURE ECRAN : cle de licence generee avec icone de copie]

Important : chaque cle est liee a un site precis. Si tu as un plan pour un seul site, tu ne pourras activer la licence que sur un seul domaine. Pour l'utiliser sur un autre site, il faudra d'abord retirer l'ancien.

Deuxieme etape : coller la cle dans WordPress. Retourne sur ton site. Dans le menu lateral, va dans Tutor LMS Pro, puis clique sur Licenses.

[CAPTURE ECRAN : menu Tutor LMS Pro > Licenses dans WordPress]

Tu vois un champ texte. Colle ta cle de licence dans ce champ, puis clique sur "Connect with License Key".

[CAPTURE ECRAN : champ de saisie de la licence avec le bouton de connexion]

Si tout est correct, tu recevras un message de confirmation. Ta licence Pro est maintenant active.

[CAPTURE ECRAN : message de confirmation "License activated successfully"]

A partir de maintenant, tu recevras les mises a jour de Tutor LMS Pro directement dans WordPress, comme n'importe quel autre plugin. Tu auras aussi acces a toutes les fonctionnalites premium : types de quiz avances, rapports detailles, certificats, integrations...

Un point a surveiller : si ta licence est un abonnement annuel, pense a la renouveler avant expiration. Sans licence active, tu gardes le plugin mais tu ne recois plus les mises a jour ni le support.

[RECAP]
En resume : va sur tutor lms point com, ajoute ton site dans l'onglet Licenses, copie la cle generee, et colle-la dans Tutor LMS Pro > Licenses dans WordPress. Ta licence est active, tu as acces a tout. On passe a la configuration.
