# Module 1 — Lecon 7 : Import des donnees demo
> Duree estimee : 2 min | Type : A creer

## Script de narration

[INTRO]
Tutor LMS propose d'importer des donnees de demonstration pour decouvrir le plugin avec du contenu pre-rempli — cours, lecons, quiz. C'est le meilleur moyen d'explorer les fonctionnalites sans partir d'une page blanche. On le fait ensemble.

[CONTENU]
Juste apres l'installation de Tutor LMS, un assistant de configuration s'affiche. Si tu l'as ferme ou si tu veux le relancer plus tard, tu peux y acceder depuis Tutor LMS, puis Setup Wizard dans le menu lateral.

[CAPTURE ECRAN : assistant de configuration Tutor LMS — ecran de bienvenue]

L'assistant te guide a travers plusieurs etapes : choix de la monetisation, configuration du tableau de bord, preferences generales. Avance dans les etapes jusqu'a arriver a l'option d'import des donnees demo.

[CAPTURE ECRAN : etape de l'assistant avec l'option "Import Sample Data" ou "Import Demo Data"]

Clique sur le bouton pour importer les donnees demo. Le processus prend quelques secondes. Tutor LMS va creer automatiquement :

- Plusieurs cours de demonstration avec des images, descriptions et categories
- Des lecons avec du contenu texte et video
- Des quiz avec differents types de questions
- Les pages necessaires — tableau de bord etudiant, page d'inscription, listing des cours

[CAPTURE ECRAN : listing des cours apres import des donnees demo]

Une fois l'import termine, rends-toi dans Tutor LMS puis Courses dans ton menu lateral. Tu verras les cours de demo listes. Clique sur l'un d'entre eux pour voir a quoi ressemble un cours complet — structure, lecons, quiz.

[CAPTURE ECRAN : vue d'un cours de demo avec ses lecons et quiz]

Va aussi verifier le front-end de ton site. Visite la page d'archive des cours — c'est generalement monsite.com/courses. Tu vois les cours affiches avec leurs vignettes, comme les verront tes futurs etudiants.

[CAPTURE ECRAN : page front-end /courses montrant les cours demo avec vignettes]

Prends le temps d'explorer. Inscris-toi a un cours de demo en tant qu'etudiant test pour voir le parcours complet : page de cours, progression, quiz, resultats. Ca te donne une vision concrete de ce que tes etudiants vivront.

[CAPTURE ECRAN : vue etudiant — progression dans un cours demo avec barre d'avancement]

Un conseil : quand tu seras pret a passer en production, supprime les cours de demo avant de publier ton site. Va dans Tutor LMS, Courses, selectionne les cours de demo, et deplace-les dans la corbeille. Ne les laisse pas visibles sur un site en production — ca fait mauvais effet.

[CAPTURE ECRAN : selection des cours demo pour mise en corbeille]

Si tu as saute l'assistant de configuration et que l'option d'import n'apparait plus, tu peux aussi explorer les fonctionnalites en creant manuellement un cours rapide. On verra comment faire dans le Module 2.

[RECAP]
En resume : lance l'assistant de configuration de Tutor LMS, importe les donnees demo, et prends le temps d'explorer les cours, lecons et quiz crees automatiquement. C'est la meilleure facon de comprendre comment le plugin fonctionne avant de creer ton propre contenu. Pense a supprimer les demos avant de publier ton site. Le Module 1 est termine — tu as un Tutor LMS installe, licence activee et pret a l'emploi.
