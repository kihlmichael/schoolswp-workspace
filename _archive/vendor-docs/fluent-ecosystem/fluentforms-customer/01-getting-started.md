## How to Install Fluent Forms
URL : https://fluentforms.com/docs/how-to-install-fluent-forms/

Are you ready to Install Fluent Forms on your WordPress Website? Before starting the installation process, let’s quickly check the requirements to ensure everything is in place.

### Requirements #

To use Fluent Form, you need – 

  * WordPress version 4.5 or later 
  * PHP version 5.4 or later 


### Installing Fluent Forms #

Now, it’s time to get started with Fluent Forms. There are two ways to install Fluent Forms – 

  1. You can install Fluent Forms from your WordPress dashboard. 
  2. Alternatively, download the Fluent Forms from wordpress.org and manually install it on your WordPress dashboard. 


We will cover both of these processes. 

### Installing Fluent Forms from WordPress Dashboard #

The steps of installing Fluent Forms are just like installing any other WordPress plugin. Here are the steps – 

  * Navigate to **WordPress Dashboard** **Plugins** section and click **Add New Plugin**.
  * Now, search for **Fluent Forms.** Click on**Install Now**. Wait for the plugin to be installed, and then click **Activate** to activate it.

![Fluent Form install 01 scaled 26147](https://fluentforms.com/wp-content/uploads/2024/12/Fluent-Form-install-01-scaled.webp)

### **Installing Fluent Forms from the WordPress Repository** #

You can manually install Fluent Forms by downloading it from the WordPress plugin repository. First, go to the [Fluent Forms](https://wordpress.org/plugins/fluentform/) page on WordPress.org and click the **Download** button to get the plugin file. Then, upload it to your WordPress site to complete the installation.

![02 2 scaled 26147](https://fluentforms.com/wp-content/uploads/2024/12/02-2-scaled.webp)

Now, navigate to your WordPress Dashboards **Plugin** sections. Click the **Add New** button from the left sidebar and then click the **Upload Plugin** button.

![03 3 scaled 26147](https://fluentforms.com/wp-content/uploads/2024/12/03-3-scaled.webp)

After that, click, **choose the .zip f** ile you just downloaded and click on the **Install Now** button.

![04 2 scaled 26147](https://fluentforms.com/wp-content/uploads/2024/12/04-2-scaled.webp)

Once the plugin is installed, search for **Fluent Forms** in the list of your installed plugins and click on **Activate**.

![05 scaled 26147](https://fluentforms.com/wp-content/uploads/2024/12/05-scaled.webp)

There you go! You have just installed the best WordPress form builder solution. Now, you are all set to explore all the impressive features it offers you.

## Upgrade to Fluent Forms Pro Add-on
URL : https://fluentforms.com/docs/how-to-upgrade-to-fluent-forms-pro/

Fluent Forms Pro offers a variety of advanced features that are unavailable in the free version. It is packed with numerous features and functionalities to create effective forms. 

To unlock the ultimate potential of Fluent Forms, you need to upgrade to the Pro add-on. Here is how you can upgrade Fluent Forms. 

> _To use Fluent Forms Pro, you must first install and activate Fluent Forms (free). To know more about Fluent Forms free vs pro, read this_[ _article_](https://fluentforms.com/fluent-forms-free-vs-pro-everything-you-need-to-know/) _._

## How to Upgrade to Fluent Form Pro Add-on #

Before upgrading to Fluent Forms Pro, ensure you have the **Pro Add-on .zip file** ready. Below is a step-by-step process to get the .zip file-

### Get the Zip File #

You’ll first need to purchase the**Pro** version of Fluent Forms to get started. You can do this in two ways:  


Visit the official[ **Fluent Forms**](https://fluentforms.com/)**** or[ **WPManageNinja**](https://wpmanageninja.com/)**** websites and choose a pricing plan that fits your needs.

![Pricing plan 27267](https://fluentforms.com/wp-content/uploads/2023/05/Pricing-plan.webp)

Or, you can open the **Fluent Forms free** plugin from your WordPress dashboard and click the **Upgrade to Pro** button. This will take you directly to the purchase page.

![01 2 scaled 27267](https://fluentforms.com/wp-content/uploads/2024/12/01-2-scaled.webp)

Once your purchase is complete, you can access the WPManageninja Dashboard. Log in to the[ account](https://wpmanageninja.com/account/dashboard/) with your credentials.

Then go to the **Dashboard** , and you will find **Fluent Forms** **Pro** zip under **Downloads**. Now, click the **Download** button and you will see the Fluent Forms **.zip** file has downloaded to your device.

![fluentforms pro download scaled 27267](https://fluentforms.com/wp-content/uploads/2023/05/fluentforms-pro-download-scaled.webp)

To access your Fluent Forms license, navigate to **Licenses** in the left sidebar. You’ll find your Fluent Forms license key there. You’ll need this key later when activating the plugin. If you miss it now, you can always come back and retrieve it from your WPManageNinja Dashboard.

Click **View List** to see all active sites currently using this license key.

![Fluent Forms License Key from Wpmanageninaj dashboard](https://fluentforms.com/wp-content/uploads/2023/05/Fluent-Forms-License-scaled.webp)

## Install the Fluent Form Pro #

Once you get the zip file, go to **Plugins** from your WordPress Dashboard and click on the **Add New Plugin** button.

![02 3 scaled 27267](https://fluentforms.com/wp-content/uploads/2024/12/02-3-scaled.webp)

Now, click the **Upload** **Plugin** button. Then, press the **Choose file** to upload the Fluent Forms .zip file you’ve downloaded before, and click the**Install Now** button.

The Fluent Forms Pro plugin will be successfully installed on your WordPress site!

> Do not deactivate or uninstall the Fluent Forms plugin from the Installed Plugins list. If you do this, you will be unable to use the Pro features and will need to reinstall and activate the Pro add-on.

![04 3 scaled 04 25 2025 12 52 PM 27267](https://fluentforms.com/wp-content/uploads/2023/05/04-3-scaled-04-25-2025_12_52_PM.webp)

Now, to activate the plugin, click the **Activate Plugin** button.

![activate plugin 04 25 2025 12 37 PM 27267](https://fluentforms.com/wp-content/uploads/2023/05/activate-plugin-04-25-2025_12_37_PM.webp)

### Activate the License Key #

To activate all the Pro features of Fluent Forms with the license key, follow the steps with the screenshots below - 

First, go to **Global** **Settings** from your Fluent Forms Dashboard, open **License** from the left sidebar, and enter the **License Key** you’ve copied before into the input field.  
And finally, click the **Activate License** button. Your Fluent Forms Pro plugin will also be successfully activated on your WordPress site!

![License Key 04 25 2025 12 40 PM scaled 27267](https://fluentforms.com/wp-content/uploads/2023/05/License-Key-04-25-2025_12_40_PM-scaled.webp)

## How to update Fluent Forms #

To update the Fluent Form plugin manually, follow the steps in the screenshot below - 

Go to the **Installed** **Plugins** page of your WordPress Dashboard and search for **Fluent Forms** from the Search Bar in the top right corner.  
Now, check if any updates are available. If yes, click on the **Update** button.

## Getting Started With Fluent Forms

Welcome to [Fluent Forms](https://wordpress.org/plugins/fluentform/) documentation.

Fluent Forms is a powerful, user-oriented WordPress plugin that allows you to create amazing forms without requiring any coding skills.

With its simple drag-and-drop interface, you can quickly create forms that look and function exactly as you want. Whether you need a simple contact form or a complex multi-step form, **Fluent Forms** has you covered.

### **Key Features** #

  * Drag and drop form builder
  * Advanced field option
  * Conditional logic
  * Integration with popular CRM tools
  * Advanced Customization options


Let’s see how you can Install, Upgrade, and use this all-in-one form builder plugin for WordPress.
