# T6 — Content Brief

## Objectif

Générer des briefs détaillés pour les top opportunités.

## Inputs

- T5_GAP (top 10 keywords)
- T4_SERP (angles gagnants)

## Output

- Onglet `T6_BRIEFS`
- 1 brief par keyword prioritaire

## Structure d'un brief

```
# Brief : [KEYWORD]

**Intent** : informationnelle | comparative | décisionnelle
**Pilier** : LMS | CRM | SEO | automatisation
**Angle** : [différenciation vs concurrents]
**Format** : guide | comparatif | listicle | tool
**Longueur cible** : 1800-2500 mots
**CTA** : email | affiliation | formation

## Structure H2-H3 proposée
1. H2 : Introduction + problématique
2. H2 : [Section principale]
3. H2 : Comparaison / Alternatives
4. H2 : Pour qui / Cas d'usage
5. H2 : Conclusion + CTA

## Entités à inclure
- [liste des plugins/outils à mentionner]

## E-E-A-T
- Expérience : [ce qui a été testé]
- Sources : [liens à citer]
```

## KPIs

- 10 briefs générés
- 100% avec structure H2-H3
