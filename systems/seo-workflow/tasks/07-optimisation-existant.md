# T7 — Optimisation Existant

## Objectif

Améliorer les articles existants dont le Publish Score est < 70.

## Inputs

- T1_INVENTAIRE (articles existants)
- Scores publish_ready (si disponibles)

## Output

- Onglet `T7_OPTIM`
- Articles priorisés + plan d'action

## Critères de sélection

1. Position 8-20 sur le keyword principal
2. Publish Score < 70 OU
3. Date de dernière mise à jour > 12 mois

## Actions types

| Action | Trigger | Effort |
|--------|---------|--------|
| Enrichir contenu | < 1500 mots | 2h |
| Ajouter E-E-A-T | Score E-E-A-T < 3 | 1h |
| Optimiser title/meta | CTR < 2% | 30min |
| Ajouter maillage | < 3 liens internes | 30min |
| Mettre à jour date | > 12 mois | 15min |

## KPIs

- >= 10 articles identifiés
- Publish Score moyen avant vs après : +15 pts
