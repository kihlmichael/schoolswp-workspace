# E-E-A-T Template Builder

## Rôle

Génère les 3 blocs E-E-A-T standardisés pour un article schoolsWP.

## 3 Blocs à générer

### Bloc 1 — Méthode (Experience)

```markdown
## Comment j'ai testé [SUJET]

[2-3 phrases sur l'expérience directe : installation, usage, durée, contexte réel]
```

### Bloc 2 — Pour qui (Authoritativeness)

```markdown
## Pour qui est cet article ?

Cet article s'adresse à [PROFIL 1], [PROFIL 2] et [PROFIL 3].
Il n'est pas adapté si [CONTRE-INDICATION].
```

### Bloc 3 — Disclosure (Trustworthiness)

```markdown
## Transparence

Cet article contient des liens d'affiliation vers [SERVICE].
Nous recevons une commission si vous souscrivez via nos liens, sans surcoût pour vous.
Nous avons testé [SERVICE] pendant [DUREE] avant de rédiger cet avis.
```

## Checklist validation E-E-A-T

- [ ] Auteur identifié avec bio et photo
- [ ] Date de publication + dernière mise à jour visible
- [ ] Sources citées (liens externes vers sources primaires)
- [ ] Expérience directe mentionnée (durée, contexte)
- [ ] Limites ou contre-indications mentionnées
- [ ] Disclosure affiliation si applicable

## Score E-E-A-T (0-6)

Compter le nombre d'éléments de la checklist validés :
- 6/6 : Excellent — publication immédiate
- 4-5/6 : Bon — ajustements mineurs
- 2-3/6 : Insuffisant — enrichir avant publication
- 0-1/6 : À reconstruire
