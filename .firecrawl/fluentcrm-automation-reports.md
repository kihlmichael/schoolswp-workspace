[FluentCRM](https://fluentcrm.com/) offers a **Reports** section for each **Automation,** helping companies analyze campaign data and customer interactions to improve their **CRM** strategy. This article will guide you through using all the features of the **Reports** section inside a specific **Automation**.

## View Reports [\#](https://fluentcrm.com/docs/automation-reports\#view-reports)

To learn how to view the Automation Reports in FluentCRM, follow the steps with the screenshots below –

First, go to the **Automations** section from the **FluentCRM Navbar**, and open your **desired** **Automation** by clicking on its **Title**.

Or, create a new one by clicking the **\+ New Automation.** To learn how to create a new automation funnel, read this [Documentation](https://fluentcrm.com/docs/automation-editor/).

For example, I opened the **List Applied** automation funnel to explain the **Reports** section.

![Open desired automation funnel](https://fluentcrm.com/wp-content/uploads/2022/08/1.-Open-desired-Automation-funnel-scaled.webp)

Once you are on the [Automation Editor](https://fluentcrm.com/docs/automation-editor/#automation-editor) page, click the **View Reports** button and the **Reports** section will appear with all available options.

![View reports button](https://fluentcrm.com/wp-content/uploads/2022/08/2.-View-Reports-button-scaled.webp)

In the Reports Section, you will find two major types of reporting options for the funnel. These are:

1. Summary Reporting
2. Individual Reporting

Also, to sync new steps to existing completed contacts, click the **Re-apply New Steps** button in the top right corner.

> **For example**, if you add any new step to your automation funnel after some contacts complete the automation, you can resume the newly added steps to the existing completed contacts using this **Re-apply New Steps** button.

![Reports section](https://fluentcrm.com/wp-content/uploads/2022/08/3.-Reports-section-scaled.webp)

**The major two types of reporting options mentioned above are explained below –**

### 1\. Summary Reporting   [\#](https://fluentcrm.com/docs/automation-reports\#1-summary-reporting%C2%A0%C2%A0)

In this section, you will get another three options to view the summary report for each action of the funnel. These are:

- Chart Report
- Step Report
- Emails Analytics

#### Chart Report [\#](https://fluentcrm.com/docs/automation-reports\#chart-report)

This tab displays a summary of each [Automation Action](https://fluentcrm.com/docs/primary-automation-actions/) in a **Chart** with a **Bar Diagram** and **Line** using **Percentages**. Simply, hover over any action to see its **Numerical** report.

![Chart report tab](https://fluentcrm.com/wp-content/uploads/2022/08/4.-Chart-Report-tab-scaled.webp)

#### Step Report [\#](https://fluentcrm.com/docs/automation-reports\#step-report)

This tab also displays a summary of each [Automation Action](https://fluentcrm.com/docs/primary-automation-actions/) but in a **Circle Graph.**

![Step report tab](https://fluentcrm.com/wp-content/uploads/2022/08/5.-Step-Report-tab-scaled.webp)

#### Email Analytics [\#](https://fluentcrm.com/docs/automation-reports\#email-analytics)

This tab displays an analytical summary of your [Email Action](https://fluentcrm.com/docs/automation-email-actions/) in the automation funnel with four different options. These are:

- **Sent**: This option will show how many emails were sent using this automation.
- **Opened**: This will show what percentage of subscribers have opened your email.
- **Clicked**: If you included any link in your automated email, this section will indicate what percentage of recipients have clicked (visited) the link.
- **Unsubscribed**: This will show you the percentage of the unsubscribed rate.

![Email analytics tab](https://fluentcrm.com/wp-content/uploads/2022/08/6.-Email-Analytics-tab-scaled.webp)

### 2\. Individual Reporting [\#](https://fluentcrm.com/docs/automation-reports\#2-individual-reporting)

This section will show you the individual reports of every contact.

Here, you will get several options to view individual reports of the automation. These are:

1. Individual Action Thread
2. Sequence Filter
3. Status Filter
4. Search Box
5. Delete Option
6. Pagination

![Indiviual reporting section](https://fluentcrm.com/wp-content/uploads/2022/08/7.-Indiviual-Reporting-section.webp)

#### A. Individual Actions Thread [\#](https://fluentcrm.com/docs/automation-reports\#a-individual-actions-thread)

To view the activity of each action for a specific contact, click the **Dropdown Arrow.**

Then, a thread will appear with a report of all the action activity details for a desired contact.

![Individual actions thread](https://fluentcrm.com/wp-content/uploads/2022/08/8.-Individual-Actions-Thread.webp)

#### B. Sequence Filter [\#](https://fluentcrm.com/docs/automation-reports\#b-sequence-filter)

This will filter the reports according to the automated action in the funnel.

![Sequence filter](https://fluentcrm.com/wp-content/uploads/2022/08/9.-Sequence-filter-scaled.webp)

#### C. Status Filter [\#](https://fluentcrm.com/docs/automation-reports\#c-status-filter)

This will filter the reports according to the following **Status** of **Automation**.

- **All**: It will show you the reports of all the contacts listed for automation.
- **Active**: This will display any active automation that hasn’t yet been finished.
- **Completed**: This will show each unique outcome of the finished automated activity.
- **Canceled**: This will display a report of any cancellation performed by automation for that particular contact.
- **Pending**: This will show the automations that are still on the pending list and waiting for a subscriber.

![Status filter](https://fluentcrm.com/wp-content/uploads/2022/08/10.-Status-filter-scaled.webp)

#### D. Search Box  [\#](https://fluentcrm.com/docs/automation-reports\#d-search-box%C2%A0)

Using this option, you can search for specific customers with User Name & Email.

For example, here I searched for a customer by name.

![Search filter](https://fluentcrm.com/wp-content/uploads/2022/08/11.-Search-filter-scaled.webp)

#### E. Delete [\#](https://fluentcrm.com/docs/automation-reports\#e-delete)

Click this **Trash Icon,** if you want to delete any existing specific report if needed.

Plus, to delete all reports at once, click the **Checkbox** in the top left corner and press the **Delete Selected Contacts** button.

![Delete individually or in a bulk](https://fluentcrm.com/wp-content/uploads/2022/08/12.-Delete-individually-or-in-a-bulk-scaled.webp)

#### F. Pagination [\#](https://fluentcrm.com/docs/automation-reports\#f-pagination)

With this option, you can set how many individual reports you want to display per page.

![Pagination option](https://fluentcrm.com/wp-content/uploads/2022/08/13.-Pagination-option-scaled.webp)
