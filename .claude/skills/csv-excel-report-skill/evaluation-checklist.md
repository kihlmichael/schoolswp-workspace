# Evaluation checklist

## Le rapport est correct si :

### Structure

- [ ] le résumé exécutif tient en 5 lignes maximum
- [ ] les 6 sections sont présentes et complètes
- [ ] le tableau périmètre/qualité est rempli
- [ ] le top 5 et le flop 5 sont dans deux tableaux séparés

### Qualité analytique

- [ ] les tendances importantes sont chiffrées (valeurs + unités)
- [ ] les anomalies sont utiles et pas décoratives
- [ ] le top 5 / flop 5 précise la dimension et la métrique utilisées
- [ ] les recommandations découlent directement des constats
- [ ] les limites sont explicites et honnêtes

### Ton

- [ ] le ton reste clair et professionnel
- [ ] aucun jargon inutile
- [ ] chaque chiffre est lisible par un non-spécialiste

### Précision

- [ ] le KPI principal retenu est mentionné
- [ ] la période couverte est indiquée
- [ ] les volumes faibles sont signalés dans les classements
- [ ] aucune causalité n'est affirmée sans preuve
