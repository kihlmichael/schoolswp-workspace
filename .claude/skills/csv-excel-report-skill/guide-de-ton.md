# Guide de ton

## Target voice

Professionnel, sobre, clair, pédagogique.

## Writing rules

- phrases courtes
- formulation directe
- aucun jargon gratuit
- toujours expliquer la signification des chiffres importants
- éviter les mots creux

## Preferred phrasing

- "le revenu progresse de 14 %"
- "ce segment pèse 42 % du total"
- "ce point mérite une vérification"
- "les données disponibles ne permettent pas de conclure davantage"
- "en l'absence de données sur X, il est difficile d'affirmer que..."
- "ce résultat est à interpréter avec précaution (faible volume)"

## Avoid

| Formulation interdite                         | Pourquoi                        |
| --------------------------------------------- | ------------------------------- |
| "insight disruptif"                           | jargon vide                     |
| "forte corrélation donc causalité probable"   | confusion corrélation/causalité |
| "ce résultat prouve" (sans preuve suffisante) | suraffirmation                  |
| "il est évident que"                          | condescendance                  |
| "comme on peut le constater clairement"       | remplissage                     |
| chiffres sans unité ni contexte               | illisible                       |

## Numbers formatting

- toujours inclure l'unité (€, %, pts, commandes...)
- arrondir à 1 ou 2 décimales maximum pour la lisibilité
- indiquer la période de référence (28j, S1, etc.)
- signaler les volumes faibles qui relativisent un résultat
