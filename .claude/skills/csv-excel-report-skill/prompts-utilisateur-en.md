# User prompts — English

## Universal prompt (simple)

```
Analyze this CSV or Excel file and generate a structured report with a 5-line executive
summary, key trends with numbers, detected anomalies, a top 5, a flop 5, and practical
recommendations.
```

## Sales prompt

```
Analyze this sales file. Focus on revenue, strong and weak products, visible anomalies,
and priority actions.
```

## CRM prompt

```
Analyze this CRM file. I want to understand the best lead sources, bottlenecks,
profitable segments, and priority actions.
```

## Marketing prompt

```
Analyze this marketing file and identify the best and worst performing channels,
campaigns, or segments. Finish with clear recommendations.
```

## Finance prompt

```
Analyze this financial spreadsheet. Show me the dominant cost/revenue items,
unusual variances, and any concentration patterns.
```

## Support / operations prompt

```
Analyze this support or operations file. I want to see problematic categories,
unusual resolution times, and priority actions.
```

## Enriched prompt (all parameters)

```
Analyze the sheet [SHEET_NAME] from this Excel file.
Use [KPI] as the primary metric.
Focus especially on the dimensions [DIM1], [DIM2], and [DIM3].
Compare performance between [PERIOD1] and [PERIOD2] if possible.
Context: [BUSINESS_CONTEXT].
The report should remain accessible to a non-specialist reader.
```
