## Arborescence type - Nouveau projet

```
[Nom Projet]/
├── 00_Brief/
│   └── brief-initial.md
├── 01_Ressources/
│   ├── images/
│   ├── documents/
│   └── references/
├── 02_Production/
│   ├── drafts/
│   └── finals/
├── 03_Exports/
│   └── [par date]
└── _Archive/
```
