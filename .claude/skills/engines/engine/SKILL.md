# schoolsWP ENGINE (ASPT EP)

Une méthode unique, claire et répétable pour piloter l'ensemble des actions schoolsWP.
Ordre logique: Architecture -> Strategy -> Production -> Transformation -> Experimentation -> Performance Loop.

## Objectif
- Remplacer les frameworks isoles par une seule methode
- Aligner decision, production et performance
- Rendre l execution repeterable et scalable

## Architecture
- Scope
- Purpose
- Environment
- Constraints
- Success criteria

## Strategy
- Diagnostic
- Options
- Priorisation
- ROI estime
- Recommandation structuree

## Production
- Structure claire
- Optimisation SEO
- Citabilite IA
- Conversion integree

## Transformation
- Article -> LinkedIn
- Video -> Page pilier
- Transcript -> Cluster
- FAQ -> Featured Snippet

## Experimentation
- Hypothese
- Action ciblee
- KPI
- Seuil de reussite

## Performance Loop
- Test
- Implementation
- Debug
- Amelioration

## Sorties obligatoires
1) Architecture: scope + contraintes
2) Strategy: diagnostic + priorites
3) Production: structure + SEO + conversion
4) Transformation: 3 derivations minimum
5) Experimentation: hypothese + KPI
6) Performance: boucle d iteration

## Prompt principal
Tu es le moteur schoolsWP ENGINE.
Applique les 6 modules dans l ordre: Architecture, Strategy, Production, Transformation, Experimentation, Performance Loop.
Produis une reponse structuree et actionnable.

## Exemple entree / sortie
Entree (exemple):
- Sujet: Cluster LMS WordPress
- Objectif: moneter via affiliation

Sortie (exemple):
- Architecture: scope LMS, contraintes temps, succes = 5 pages publiees
- Strategy: priorites TutorLMS vs LearnDash, ROI eleve
- Production: plan H2 + SEO + CTA
- Transformation: article -> LinkedIn, comparatif -> FAQ, transcript -> cluster
- Experimentation: hypothese sur CTR, KPI, seuil 3%
- Performance: iteration sur 30 jours
