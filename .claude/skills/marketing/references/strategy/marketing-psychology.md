## Philosophie schoolsWP

```
PERSUASION ÉTHIQUE

✅ Aider à prendre une bonne décision
✅ Réduire les frictions légitimes

❌ Exploiter les vulnérabilités
❌ Cacher des informations importantes
```

## Principes de Cialdini appliqués

### 1. Réciprocité

**Principe** : On se sent redevable envers ceux qui nous donnent quelque chose.

```
APPLICATION SCHOOLSWP

✅ ÉTHIQUE
- Contenu gratuit de qualité (guides, checklist)
- Valeur avant demande de vente
- Ressources sans contrepartie immédiate

❌ À ÉVITER
- "Je t'ai donné X, maintenant tu me dois Y"
- Valeur faible pour forcer la réciprocité
```

**Exemple schoolsWP** :
```
"Télécharge gratuitement la checklist des 47 points SEO WordPress.
Aucune obligation, pas de spam."

→ Le prospect reçoit de la valeur AVANT qu'on lui propose quoi que ce soit.
```

### 2. Engagement et cohérence

**Principe** : On cherche à rester cohérent avec nos actions et engagements passés.

```
APPLICATION SCHOOLSWP

✅ ÉTHIQUE
- Micro-engagements progressifs (newsletter → lead magnet → formation)
- Rappeler les actions déjà prises
- Faire visualiser le résultat souhaité

❌ À ÉVITER
- Foot-in-the-door manipulatoire
- Piéger dans des engagements non désirés
```

**Exemple schoolsWP** :
```
"Tu as déjà téléchargé la checklist performance.
Tu as commencé à optimiser ton site.
La formation complète t'aide à aller jusqu'au bout."

→ Cohérence avec l'engagement initial d'optimiser son site.
```

### 3. Preuve sociale

**Principe** : On regarde ce que font les autres pour guider nos décisions.

```
APPLICATION SCHOOLSWP

✅ ÉTHIQUE
- Vrais témoignages avec contexte
- Chiffres vérifiables
- Logos clients réels
- Communauté visible

❌ À ÉVITER
- Faux témoignages
- Chiffres gonflés
- "Tout le monde le fait"
```

**Exemples schoolsWP** :

| Type | Exemple |
|------|---------|
| Chiffres | "2,500+ abonnés à la newsletter" |
| Témoignage | "Mon PageSpeed est passé de 34 à 91" — Marie D. |
| Logos | Logos d'entreprises clientes |
| Communauté | "Rejoins 500+ membres sur Discord" |

### 4. Autorité

**Principe** : On fait confiance aux experts et figures d'autorité.

```
APPLICATION SCHOOLSWP

✅ ÉTHIQUE
- Démontrer l'expertise par le contenu
- Partager les résultats obtenus
- Montrer l'expérience (années, projets)
- Citations et apparitions (podcasts, conférences)

❌ À ÉVITER
- Fausses certifications
- Expertise inventée
- Name-dropping abusif
```

**Signaux d'autorité schoolsWP** :
```
- "Depuis 2021, j'aide les entrepreneurs à optimiser WordPress"
- "Former 500+ étudiants"
- "Invité sur [Podcast WordPress reconnu]"
- "Méthode testée sur 100+ sites"
```

### 5. Sympathie (Liking)

**Principe** : On dit oui plus facilement à ceux qu'on apprécie.

```
APPLICATION SCHOOLSWP

✅ ÉTHIQUE
- Être authentique et humain
- Montrer les coulisses
- Partager ses galères et apprentissages
- Répondre personnellement

❌ À ÉVITER
- Fausse proximité
- Flatterie excessive
- Manipulation émotionnelle
```

**Ton schoolsWP** :
```
- Tutoyer (proximité)
- Partager les erreurs ("J'ai fait cette erreur, voici ce que j'ai appris")
- Humour dosé
- Authenticité ("Ce n'est pas pour tout le monde...")
```

### 6. Rareté

**Principe** : Ce qui est rare est perçu comme plus précieux.

```
APPLICATION SCHOOLSWP

✅ ÉTHIQUE (rareté réelle)
- Places limitées (capacité réelle de support)
- Bonus limité dans le temps (vraie deadline)
- Accès early-bird (avantage réel)
- Édition limitée (si vraiment limitée)

❌ À ÉVITER
- Faux compteurs
- "Plus que 3 places" permanent
- Urgence artificielle
- Deadline qui revient sans cesse
```

**Utilisation éthique** :
```
✅ "Inscriptions ouvertes jusqu'au 15 février — je limite à 30 places
    pour pouvoir répondre personnellement à tout le monde."

❌ "🚨 DERNIÈRE CHANCE !!! Plus que 2h !!!" (tous les jours)
```

## Biais cognitifs utiles

### Effet d'ancrage

**Principe** : La première information influence la perception des suivantes.

```
APPLICATION
- Montrer le prix "complet" avant la réduction
- Comparer au coût de ne pas agir
- Ancrer sur la valeur, pas le prix

EXEMPLE SCHOOLSWP
"La formation représente 12h de mon temps en consulting (2400€).
Tu y accèdes pour 397€."

"Un site lent peut coûter 20% de conversions perdues.
Sur 10 000€/an de CA, c'est 2000€ perdus."
```

### Aversion à la perte

**Principe** : On ressent plus fortement les pertes que les gains équivalents.

```
APPLICATION ÉTHIQUE
- Mettre en avant ce qu'on risque de perdre (opportunité réelle)
- Quantifier le coût de l'inaction
- Rappeler la deadline sans manipulation

EXEMPLE SCHOOLSWP
"Chaque jour avec un site lent, c'est des visiteurs qui partent
chez la concurrence."

"Le bonus 'Audit personnalisé' n'est disponible que cette semaine."
(Si c'est vraiment le cas)
```

### Paradoxe du choix

**Principe** : Trop de choix paralyse la décision.

```
APPLICATION
- Maximum 3 options (Good-Better-Best)
- Recommander un choix clair
- Simplifier les comparaisons

EXEMPLE SCHOOLSWP
Pas : 7 formations différentes
Mais : 3 niveaux d'une même formation avec "Recommandé" visible
```

### Effet de cadrage

**Principe** : La façon de présenter l'info influence la perception.

```
CADRAGE PRIX
"397€" → neutre
"1.09€/jour" → accessible
"Moins cher qu'un café par jour" → très accessible
"ROI en moins d'un mois" → investissement

CADRAGE RÉSULTAT
"Améliore ton site" → vague
"Divise ton temps de chargement par 4" → concret
"Passe de 34 à 91 sur PageSpeed" → très concret
```

## Application par contexte

### Page de vente

```
STRUCTURE PSYCHOLOGIQUE

1. DOULEUR (aversion à la perte)
   "Ton site met 4 secondes à charger.
    53% des visiteurs partent avant de le voir."

2. AUTORITÉ + PREUVE SOCIALE
   "J'ai optimisé 100+ sites WordPress.
    Voici les résultats de Marie, Pierre, Sophie..."

3. SOLUTION (engagement)
   "La méthode en 5 étapes que j'utilise
    sur tous mes projets clients."

4. OFFRE (ancrage + rareté éthique)
   "Valeur totale : 2400€
    Ton investissement : 397€
    Bonus inclus jusqu'au [date réelle]"

5. GARANTIE (réduction du risque)
   "Satisfait ou remboursé 30 jours.
    Tu ne risques rien."
```

### Email marketing

```
SÉQUENCE PSYCHOLOGIQUE

Email 1 : Réciprocité
→ Donner de la valeur gratuite

Email 2-3 : Autorité
→ Démontrer l'expertise

Email 4 : Preuve sociale
→ Témoignages et résultats

Email 5 : Sympathie
→ Histoire personnelle, connexion

Email 6-7 : Engagement
→ Micro-actions, cohérence

Email 8 : Rareté éthique
→ Offre avec vraie deadline
```

## Checklist éthique

Avant d'utiliser un principe, vérifier :

```
□ Est-ce basé sur une réalité ? (pas de manipulation)
□ Le client serait-il content après achat ? (pas de regret)
□ Serais-je fier de montrer cette tactique publiquement ?
□ Est-ce dans l'intérêt du client ? (pas juste le mien)
□ L'information est-elle complète ? (pas d'omission)
```
