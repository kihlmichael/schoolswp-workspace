# Copywriting — schoolsWP Marketing

Rédaction marketing orientée conversion pour pages, emails et contenus schoolsWP.

## Triggers

- "écris du copy", "rédige une landing page"
- "améliore ce texte marketing"
- "headline", "CTA"

## Pré-requis

Avant d'écrire, vérifier :

1. **Contexte produit** : Consulter `05_Branding/procedures/brand-identity.md`
2. **Ton de voix** : Consulter `05_Branding/procedures/tone-of-voice.md`

## Phase de découverte

### Questions essentielles

```
1. TYPE DE PAGE
   □ Landing page (trafic payant)
   □ Page de vente (formation/produit)
   □ Page de capture (lead magnet)
   □ Homepage
   □ Page feature/fonctionnalité

2. OBJECTIF PRINCIPAL
   □ Inscription newsletter
   □ Téléchargement ressource
   □ Inscription formation
   □ Achat produit
   □ Prise de contact

3. AUDIENCE
   □ Qui est le lecteur idéal ?
   □ Quel problème veut-il résoudre ?
   □ Quelles objections a-t-il ?
   □ Quel vocabulaire utilise-t-il ?

4. OFFRE
   □ Qu'est-ce qui est proposé exactement ?
   □ Quelle transformation/résultat ?
   □ Qu'est-ce qui différencie de la concurrence ?
   □ Quelles preuves avons-nous ?

5. CONTEXTE
   □ D'où vient le trafic ?
   □ Que sait déjà le visiteur ?
   □ Quel est le niveau de sensibilisation ?
```

## Principes de rédaction schoolsWP

### Les 5 règles d'or

| Règle | Explication | Exemple |
|-------|-------------|---------|
| **Clarté > Créativité** | Être compris prime sur être original | "Accélère ton site" > "Libère la puissance de ton WordPress" |
| **Bénéfices > Fonctionnalités** | Résultat pour l'utilisateur | "Charge en 1.2s" > "Cache LiteSpeed intégré" |
| **Spécificité > Généralité** | Chiffres et détails concrets | "47 vidéos, 12h de formation" > "Formation complète" |
| **Langage client > Jargon** | Vocabulaire de l'audience | "Ton site rame" > "Latence élevée" |
| **Une idée par section** | Flow logique et scannable | Sections courtes, hiérarchisées |

### Style schoolsWP

```
✅ À FAIRE
- Phrases courtes (< 20 mots)
- Vocabulaire simple ("utiliser" pas "utiliser")
- Voix active ("Tu vas apprendre" pas "Sera enseigné")
- Ton confiant sans arrogance
- Montrer les résultats plutôt que les décrire

❌ À ÉVITER
- Superlatifs vides ("révolutionnaire", "incroyable")
- Urgence artificielle ("DERNIÈRE CHANCE !!!")
- Promesses non vérifiables ("Deviens riche")
- Jargon technique non expliqué
- Paragraphes > 3 lignes
```

## Framework de page

### Structure type landing page

```
1. HERO SECTION
   ├── Headline (proposition de valeur principale)
   ├── Subheadline (expansion du headline)
   ├── CTA primaire
   └── Visuel/Preuve sociale rapide

2. PROBLÈME/DOULEUR
   ├── Identifier le problème
   ├── Montrer qu'on comprend
   └── Amplifier (conséquences)

3. SOLUTION
   ├── Présenter l'offre
   ├── Comment ça résout le problème
   └── Transformation promise

4. BÉNÉFICES
   ├── 3-5 bénéfices clés
   ├── Format: Bénéfice + Preuve
   └── Orienté résultat

5. SOCIAL PROOF
   ├── Témoignages avec contexte
   ├── Logos/Chiffres
   └── Cas d'étude si disponible

6. COMMENT ÇA MARCHE
   ├── 3-4 étapes simples
   ├── Réduire la complexité perçue
   └── Montrer que c'est accessible

7. OBJECTIONS
   ├── FAQ ciblée
   ├── Garanties
   └── Comparaisons (si pertinent)

8. CTA FINAL
   ├── Récapitulatif de la valeur
   ├── Réduction du risque
   └── CTA avec urgence légitime
```

## Formules de headlines

### Templates éprouvés

```
1. RÉSULTAT + DÉLAI
   "Passe de [problème] à [résultat] en [délai]"
   → "Passe de 4s à 1s de chargement en 1 weekend"

2. COMMENT + RÉSULTAT
   "Comment [action] pour [bénéfice] sans [objection]"
   → "Comment optimiser ton WordPress pour Google sans toucher au code"

3. LE SECRET DE
   "Le [secret/méthode] des [groupe de référence] pour [résultat]"
   → "La méthode des agences WP pour un PageSpeed 95+"

4. NOMBRE + BÉNÉFICE
   "[Nombre] façons de [résultat]"
   → "7 optimisations pour diviser ton temps de chargement par 2"

5. SPÉCIFIQUE + PREUVE
   "[Résultat chiffré] grâce à [méthode]"
   → "Score Core Web Vitals 100/100 avec cette configuration"
```

### Headlines schoolsWP — Exemples

| Page | Headline |
|------|----------|
| Formation Performance | "Ton WordPress en 1 seconde — La méthode complète en 12 modules" |
| Lead Magnet SEO | "La checklist SEO WordPress en 47 points (PDF gratuit)" |
| Page Consulting | "Audit performance WordPress — Rapport détaillé en 48h" |

## Formules de CTA

### Structure

`[Verbe d'action] + [Bénéfice/Résultat] + [Qualificateur optionnel]`

### Exemples par contexte

| Contexte | Faible | Fort |
|----------|--------|------|
| Newsletter | "S'inscrire" | "Recevoir les tips performance chaque mardi" |
| Formation gratuite | "Commencer" | "Démarrer le module 1 gratuit" |
| Formation payante | "Acheter" | "Accéder à la formation complète" |
| Lead magnet | "Télécharger" | "Recevoir la checklist PDF" |
| Consultation | "Contacter" | "Réserver mon audit gratuit" |

## Rédaction des sections clés

### Social Proof

```
TEMPLATE TÉMOIGNAGE
"[Citation spécifique avec résultat mesurable]"
— [Prénom] [Nom], [Rôle/Entreprise]
[Contexte additionnel si pertinent]

EXEMPLE
"J'ai appliqué les 3 optimisations du module 4 et mon score
PageSpeed est passé de 34 à 91 en 2 heures."
— Marie D., Freelance WordPress
Site e-commerce WooCommerce, 500 produits
```

### Gestion des objections

```
FORMAT FAQ
Q: [Objection formulée comme question du client]
R: [Réponse directe] + [Preuve/Réassurance]

EXEMPLE
Q: "La formation est-elle adaptée aux débutants ?"
R: Oui, chaque module part des bases. Tu n'as besoin que
   d'un site WordPress installé. 73% de nos étudiants
   n'avaient jamais optimisé leur site avant.
```

## Livrable type

Pour chaque page, fournir :

```
1. COPY COMPLET
   Organisé par sections avec annotations

2. ALTERNATIVES
   2-3 variantes pour headline et CTA avec justification

3. META CONTENT (si pertinent)
   - Title tag (< 60 caractères)
   - Meta description (< 160 caractères)

4. NOTES DE COHÉRENCE
   Vérification vs brand guidelines schoolsWP
```

## Checklist finale

```
□ Headline orienté résultat avec spécificité
□ Bénéfices > Fonctionnalités
□ Preuves concrètes (chiffres, témoignages)
□ CTA action + bénéfice
□ Objections adressées
□ Ton schoolsWP respecté (pédagogique, direct)
□ Scannable (titres, listes, paragraphes courts)
□ Mobile-friendly (longueur adaptée)
```
