# Code Audit Templates

Templates de sortie pour les rapports d'audit.

## Templates disponibles

| Template | Format | Usage |
|----------|--------|-------|
| [report-templates.md](report-templates.md) | MD, JSON, CSV | Tous les formats de rapport |

## Formats de sortie

### Markdown (audit-report.md)

Format lisible pour documentation et partage avec l'équipe.

- Résumé exécutif
- Findings détaillés par sévérité
- Statistiques
- Actions recommandées

### JSON (audit.json)

Format machine pour intégration CI/CD et outils.

- Métadonnées complètes
- Findings structurés
- Métriques calculées
- Recommandations priorisées

### CSV (findings.csv)

Format tableur pour analyse et tracking.

- Import Excel/Google Sheets
- Filtrage et tri faciles
- Historique des audits
