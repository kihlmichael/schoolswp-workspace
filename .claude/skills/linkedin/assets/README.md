## Format recommandé

```markdown
# Template : [Nom]

## Utilisation
_Quand utiliser ce template_

## Structure

[ACCROCHE - 1 ligne max]

[CORPS - 3-5 paragraphes courts]

[CTA - Call to action]

## Variables à remplacer
- {{sujet}} : Le sujet principal
- {{cta}} : L'appel à l'action

## Exemple
_Un exemple concret rempli_
```
