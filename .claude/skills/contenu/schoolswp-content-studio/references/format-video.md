# Format : Script video YouTube schoolsWP

## Objectif

Enseigner visuellement, montrer comment faire etape par etape, rendre WordPress accessible en video.

## Longueur

5 a 15 minutes de video. Le script doit indiquer les reperes visuels et les transitions.

## Structure obligatoire

```markdown
# [Titre de la video]

## HOOK (0:00 - 0:05)

[Probleme ou promesse en une phrase. Maximum 5 secondes a l'oral.]

## INTRO (0:05 - 0:30)

[Ce qu'on va voir dans la video. Pourquoi c'est utile. 3-4 phrases max.]

[ECRAN : montrer brievement le resultat final]

## ETAPE 1 — [Nom de l'etape]

[Instructions claires. Phrases courtes. Commentees comme si on parlait en temps reel.]

[ECRAN : capture ou screencast de l'action]

> Astuce : [conseil bonus contextuel]

## ETAPE 2 — [Nom de l'etape]

[Meme format que l'etape 1.]

[ECRAN : capture ou screencast]

## ETAPE 3 — [Nom de l'etape]

[Meme format.]

[ECRAN : capture ou screencast]

## RECAP (avant-derniere section)

[Ce qu'on a vu. Les 3 points cles a retenir. Format liste courte.]

## OUTRO

[CTA : s'abonner, lien en description, invitation a tester.]
[Question pour les commentaires.]

---

## DESCRIPTION YOUTUBE

[Resume en 2-3 phrases]

Liens utiles :

- [Lien 1]
- [Lien 2]

Chapitres :

- 0:00 — Introduction
- [timestamps des etapes]

#WordPress #schoolsWP #[hashtag sujet]
```

## Regles specifiques aux scripts video

- Le hook doit accrocher en 5 secondes. Probleme ou promesse, rien d'autre.
- L'intro ne depasse pas 30 secondes. Le spectateur veut voir, pas ecouter un monologue.
- Chaque etape est numerotee et nommee clairement.
- Les instructions sont ecrites comme du langage parle, pas ecrit.
- Indiquer les moments visuels avec [ECRAN : ...] pour guider le montage.
- Les astuces bonus sont optionnelles mais tres appreciees.
- Le recap liste les points cles en 3 bullets max.
- L'outro contient un seul CTA principal + une question pour les commentaires.
- La description YouTube est incluse dans le fichier, prete a copier-coller.
- Les chapitres (timestamps) sont obligatoires dans la description.

## Exemple de hook

```
Vous voulez envoyer un email automatique a chaque nouvel abonne ?
```

## Exemple d'intro

```
Dans cette video, je vous montre comment faire ca en 10 minutes avec FluentCRM.

On va creer l'automatisation ensemble, pas a pas.

C'est parti.
```

## Ton specifique video

- Conversationnel et naturel. Comme si on parlait a un ami.
- Energique sans etre force. Pas de faux enthousiasme.
- Phrases encore plus courtes que dans les articles (5-12 mots).
- Tutoyer ou vouvoyer selon le choix de l'utilisateur (par defaut : vouvoyer).
- Eviter les "euh", "alors", "du coup" dans le script ecrit.
