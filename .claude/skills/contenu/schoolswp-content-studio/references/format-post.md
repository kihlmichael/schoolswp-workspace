# Format : Post LinkedIn / Bluesky

## Objectif

Partager une idee actionnable, inspirer, engager la communaute WordPress.

## Longueur

100 a 200 mots. Concis et percutant.

## Structure obligatoire

```markdown
[Accroche — une verite, un constat ou une question. 1-2 phrases max.]

[Developpement — 3 points cles, lecons ou constats. Format liste avec -> ou tirets.]

[Conclusion engageante — phrase de cloture + question ouverte pour inviter a reagir.]
```

## Regles specifiques aux posts

- Pas de H1, H2 ou H3. C'est un post, pas un article.
- Pas de liens dans le corps du post (sauf si la plateforme le permet bien — eviter sur LinkedIn).
- Chaque ligne doit pouvoir se lire seule et avoir du sens.
- Sauts de ligne entre chaque idee pour aerer.
- Utiliser -> pour les listes plutot que des tirets classiques (plus visuel sur les reseaux).
- Un emoji max par post, et seulement si naturel.
- Terminer par une question ouverte pour generer des commentaires.

## Exemple complet

```
WordPress ne fait pas le SEO a votre place.

Installer Yoast ou RankMath ne suffit pas.

Voici ce qui compte vraiment :

-> Structure de contenu claire (H2, H3, listes)
-> Reponse directe a une intention de recherche
-> Liens internes intelligents

Le plugin, c'est juste l'outil. La strategie, c'est vous.

Vous optimisez vos articles avant ou apres publication ?
```

## Adaptation par plateforme

### LinkedIn

- Ton legerement plus professionnel
- Possibilite d'ajouter un lien en commentaire (pas dans le post)
- Hashtags : 3-5 max, en fin de post

### Bluesky

- Ton plus decontracte, communautaire
- Plus court si possible (sous 200 mots)
- Pas de hashtags

### Instagram

- Adapter pour le format legende
- Hashtags : 5-10 pertinents en fin de legende
- Premiere ligne = accroche visible avant le "voir plus"

### X (Twitter)

- Version ultra-condensee (sous 280 caracteres) ou thread
- Si thread : une idee par tweet, numeroter
