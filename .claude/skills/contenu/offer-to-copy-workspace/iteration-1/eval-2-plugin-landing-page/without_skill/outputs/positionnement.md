# Positionnement marketing — Plugin Landing Page Affiliée (WordPress + Claude + Kadence)

---

## 1. Document de positionnement

### Promesse centrale

**Tu colles une URL produit. Le plugin crée ta landing page affiliée en moins de 2 minutes.**

Scraping, copywriting IA, mise en page Kadence Blocks — tout est automatisé. Tu n'as plus qu'à publier.

---

### Le problème du prospect

Tu monétises ton blog WordPress par l'affiliation. Tu sais que les landing pages dédiées convertissent mieux que de simples liens dans les articles. Mais créer une vraie page de vente prend du temps : scraper les features du produit, rédiger l'accroche, structurer les blocs Kadence, optimiser le CTA.

Résultat : tu continues d'envoyer du trafic vers des articles génériques, et tu laisses des commissions sur la table.

La vraie douleur n'est pas le manque de compétences. C'est le ratio temps/revenu. Passer 3 heures sur une landing page pour un produit à 5 % de commission, ça n'a aucun sens — surtout quand tu gères 20, 50 ou 100 produits affiliés.

---

### La solution

Un plugin WordPress natif qui automatise toute la chaîne :

1. Tu entres l'URL du produit affilié
2. Le plugin scrape la page (features, bénéfices, prix, visuels)
3. Claude génère le copy de vente adapté à ton audience
4. Le plugin crée la page directement dans Kadence Blocks, prête à publier

Pas de nouveau outil externe. Pas d'apprentissage. Tout se passe dans ton WordPress, dans l'interface que tu connais déjà.

---

### Bénéfices

**Gain de temps direct** — Ce qui prenait 2 à 3 heures se fait en moins de 2 minutes. Tu peux créer une landing page affiliée par programme, pas par courage.

**Copy de qualité à chaque fois** — Claude extrait les vrais arguments de vente du produit — pas un texte générique. L'accroche, les bénéfices, les objections, le CTA : tout est structuré pour convertir.

**Volume impossible à la main** — 50 produits affiliés = 50 landing pages en une matinée. Tu passes de blogueur qui place des liens à éditeur qui structure ses revenus.

**Intégration native Kadence Blocks** — La page générée utilise tes blocs Kadence existants. Elle s'intègre dans ton design, respecte ta charte graphique, sans manipulation de code.

**Contrôle total** — Le plugin génère, tu valides. Tu gardes la main sur le copy final avant publication.

---
