# Positionnement marketing — Google Ads MCP Dashboard

## 1. Document de positionnement

### Promesse centrale

Connecte Claude à Google Ads en 30 secondes. Tes métriques campagne — CPA, ROAS, CTR, dépenses, conversions — transformées en dashboard HTML interactif, sans quitter ton terminal.

### Cible précise

Primaire : Consultants et freelances Google Ads (solo ou petite structure, 5-50 clients)
Secondaire : Agences performance marketing (pôle paid media, traffic managers)

Profil type : utilise déjà Claude Code, gère plusieurs comptes simultanément, perd du temps sur le reporting client, cherche à automatiser sans coder de A à Z.

### Problème prospect

Le reporting Google Ads mange 20 à 40% du temps facturable. Tu exportes des CSV, tu reformates dans Excel, tu construis un tableau "présentable" pour le client, tu le mets à jour la semaine suivante. Et tu recommences. Chaque semaine. Claude, lui, est coincé dans une fenêtre de chat sans accès à tes données réelles.

### Solution

Un skill MCP qui : (1) se connecte directement à Google Ads, (2) récupère CPA, ROAS, CTR, dépenses, conversions en temps réel, (3) génère un dashboard HTML interactif prêt à envoyer. En une commande depuis Claude Code.

### Bénéfices concrets

- 45 min d'export+mise en forme → dashboard en < 2 min
- Fichier Excel peu lisible → HTML interactif avec graphiques
- Données statiques à J-1 → métriques récupérées à la demande
- Travail répété → commande rejouable en un instant
- Gain estimé : 3 à 6 heures/semaine pour 10+ comptes

### Différenciants

- Connexion MCP native — pas Zapier, pas un script à maintenir
- Dashboard HTML généré par IA — pas un template figé
- Zéro friction si tu utilises déjà Claude Code
- Extensible (alertes ROAS, comparaison périodes, reco automatiques)

### Crédibilité et limites

Ce que c'est : un skill Claude Code (SKILL.md + config MCP), fonctionnel avec Claude Code + accès API Google Ads.

Limites à ne pas cacher : Developer Token requis, non testé à grande échelle (1000+ campagnes), pas de mise à jour automatique, Claude Code obligatoire.

Pour qui ce n'est PAS fait : ceux qui veulent un SaaS clé en main, ceux qui n'utilisent pas encore Claude Code.
