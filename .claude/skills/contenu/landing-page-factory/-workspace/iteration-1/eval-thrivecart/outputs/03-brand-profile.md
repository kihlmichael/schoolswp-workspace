# Brand Profile — ThriveCart

## Personnalite de marque
- Ton : professionnel mais accessible, oriente resultats, pas corporate
- Registre : anglais d'origine, adaptation FR = tutoiement (convention schoolsWP)
- Niveau technique : intermediaire — s'adresse a des gens qui vendent deja en ligne, pas a des debutants absolus

## Patterns linguistiques detectes
- Phrases signatures :
  - "Revenue Infrastructure for Modern Creators"
  - "Build Your Revenue Engine in Minutes"
  - "Five Pillars. One Platform."
  - "Selling Online Shouldn't Require 10 Different Tools"
- Mots recurrents : revenue, conversion, AOV, creators, funnels, high-converting, built-in, automation, one-time payment
- Structure argumentaire : probleme (trop d'outils, ca coute cher, ca ne convertit pas) → solution (une plateforme unifiee) → preuve (stats + temoignages)

## Adaptation schoolsWP

Le copy final fusionne la voix ThriveCart avec les regles schoolsWP :
- Tutoiement systematique
- Phrases courtes (8-15 mots en moyenne, max 20)
- Paragraphes aeres (2-4 phrases)
- Pas de jargon sans explication (AOV = "panier moyen", funnel = "tunnel de vente")
- Actionnable : chaque section = quelque chose a faire
- Les stats ThriveCart sont utilisees telles quelles (prouvables)
- Le vocabulaire "revenue engine" est traduit en "machine a revenus" ou equivalent concret

## Ban List
Tous les mots de `references/ban-list.md` sont interdits :
- Pas de "revolutionner", "booster", "puissant", "innovant", "game-changer", "ultime"
- Pas de "Dans le monde de...", "Il est important de noter que..."
- Pas de fausse urgence ("offre limitee", "derniere chance")
- Pas de claims non prouvables ("le meilleur du marche", "resultats immediats")
- Chaque phrase passe le test : "Est-ce que quelqu'un paierait pour cette information ?"
