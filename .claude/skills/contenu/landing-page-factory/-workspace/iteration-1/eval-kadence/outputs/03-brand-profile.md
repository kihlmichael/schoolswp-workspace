# Brand Profile — Kadence Theme

## Personnalite de marque
- **Ton** : accessible et technique a la fois — Kadence parle comme un developpeur ami qui simplifie tout
- **Registre** : vouvoiement implicite en anglais (neutre), tutoiement obligatoire pour l'adaptation schoolsWP
- **Niveau technique** : intermediaire — assez technique pour rassurer (CSS pre-loading, component stylesheets) sans noyer le debutant

## Patterns linguistiques detectes
- **Phrases signatures** :
  - "Build Fast & Beautiful Websites"
  - "Your way" / "It's all up to you" / "Your header, your way"
  - "Getting Started Has Never Been This Easy"
  - "Performance Without Compromise"
  - "Making building websites fun again"
- **Mots recurrents** : "easy", "fast", "beautiful", "customize", "drag and drop", "global", "powerful", "lightning-fast", "professional"
- **Structure argumentaire** : Feature → Benefice concret → Preuve visuelle (screenshot ou demo). Kadence montre beaucoup, decrit peu.

## Adaptation schoolsWP
Le copy final fusionne la voix Kadence (technique accessible, confiance, simplicite) avec les regles schoolsWP :
- **Tutoiement systematique** — "Tu peux" au lieu de "Vous pouvez"
- **Phrases courtes** — 8-15 mots en moyenne, max 20
- **Paragraphes aeres** — 2-4 phrases max
- **Pas de jargon sans explication** — si on dit "CSS pre-loading", on explique ce que ca change pour le visiteur
- **Actionnable** — chaque section = quelque chose a faire ou a constater

## Typographie suggeree
- Titres : "Plus Jakarta Sans" (moderne, geometrique, lisible — evite Inter/Roboto/Arial)
- Corps : "Source Sans 3" (professionnel, grande lisibilite)
- Fallback : system-ui, -apple-system, sans-serif

## Ban List
Voir `references/ban-list.md` — tous les mots interdits s'appliquent. En particulier pour Kadence :
- NE PAS utiliser "revolutionnaire", "game-changer", "puissant" sans preuve
- NE PAS utiliser "ultime", "incontournable"
- NE PAS utiliser "dans le monde de WordPress..."
- NE PAS utiliser "seamless" / "fluide" comme remplissage
