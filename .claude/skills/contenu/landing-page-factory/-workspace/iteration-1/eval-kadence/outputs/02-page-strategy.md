# Page Strategy — Kadence Theme

## Analyse du probleme
- **Quel probleme resout Kadence ?** Les themes WordPress classiques sont soit lents (Divi, Avada chargent des tonnes de JS), soit rigides (themes natifs FSE peu matures), soit complexes a configurer. Kadence offre performance + flexibilite sans code.
- **Pour qui exactement ?**
  - Persona A : freelance WordPress qui cree des sites pour ses clients et veut un theme rapide, pro, customisable sans coder
  - Persona B : createur de cours en ligne (LMS) qui veut un site beau, integre avec LearnDash/TutorLMS, et qui charge vite
- **Alternative actuelle ?** Astra, GeneratePress, ou les page builders lourds (Elementor + Hello Theme). Astra est le concurrent direct mais moins integre a l'editeur Gutenberg natif. GeneratePress est performant mais moins riche en design.

## Angles proposes

### Angle 1 : "Le theme qui rend ton site WordPress rapide sans compromis"
- **Hook** : "Ton theme WordPress te ralentit. Kadence charge en 0.5s."
- **Cible** : freelance WordPress / webdesigner qui livre des sites clients
- **Emotion dominante** : frustration (sites lents = clients mecontents, mauvais SEO)
- **CTA principal** : "Essaie Kadence gratuitement"
- **Mecanisme de preuve** : temoignage Jake Pfohl (tests comparatifs) + chiffres (3.4M sites, 4.9 Trustpilot) + architecture technique (component CSS, inline SVG, pas de JS lourd)
- **Layout** : Theme WP → visual-first + live preview CTA

### Angle 2 : "Construis un site pro en 10 minutes, sans toucher une ligne de code"
- **Hook** : "Un site pro en 10 minutes. Templates inclus. Zero code."
- **Cible** : createur de cours / entrepreneur solo qui veut un site maintenant, pas dans 3 semaines
- **Emotion dominante** : aspiration (avoir un vrai site pro rapidement) + frustration (trop de temps perdu a configurer des themes)
- **CTA principal** : "Choisis ton template et lance-toi"
- **Mecanisme de preuve** : temoignage Chris Badgett (course builders, coaches) + Adam Preiser (10 ans de WP) + starter templates visuels + processus 3 etapes (template → couleurs → polices)
- **Layout** : Theme WP → visual-first + demo/template gallery CTA
