## FAQ

**Ai-je besoin de savoir coder pour utiliser Kadence ?**
Non. Zero code necessaire. Le header builder, les templates et les reglages globaux se configurent visuellement dans le customizer WordPress.

**Les templates sont-ils personnalisables ?**
Completement. Les templates sont un point de depart. Tu modifies chaque element : textes, images, couleurs, mise en page. Tout passe par l'editeur Gutenberg natif.

Oui. Kadence s'integre nativement avec LearnDash, LifterLMS et TutorLMS. Les pages de cours, les lecons et les grilles s'adaptent a tes couleurs de marque.
