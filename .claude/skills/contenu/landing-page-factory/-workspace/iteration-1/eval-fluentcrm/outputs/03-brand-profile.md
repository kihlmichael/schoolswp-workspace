# Brand Profile — FluentCRM

## Personnalite de marque
- **Ton** : accessible-technique, confiant sans arrogance, oriente action
- **Registre** : tutoiement (adaptation schoolsWP) — le site original utilise le "you" anglophone
- **Niveau technique** : intermediaire (s'adresse a des utilisateurs WordPress qui savent installer un plugin, pas des debutants absolus)

## Patterns linguistiques detectes
- **Phrases signatures** :
  - "Without Limits!"
  - "Goodbye Success Taxes!"
  - "Connect. Communicate. Convert. Repeat!"
  - "Work Less. Sell More!"
  - "Your Marketing, On Autopilot!"
- **Mots recurrents** : unlimited, self-hosted, WordPress, automation, 360 degres, inside WordPress, no add-ons, no hidden costs
- **Structure argumentaire** : probleme SaaS couteux → solution self-hosted abordable → preuve (chiffres + temoignages) → CTA

## Adaptation schoolsWP
Le copy final fusionne la voix FluentCRM avec les regles schoolsWP :
- Tutoiement systematique (jamais de vouvoiement)
- Phrases courtes : 8-15 mots en moyenne, max 20
- Paragraphes aeres : 2-4 phrases max
- Pas de jargon sans explication (ex: "SPA" → "interface rapide")
- Actionnable : chaque section = une action concrete
- Ton direct, factuel, pas de superlatifs creux

## Ban List
Les mots suivants sont interdits dans tout le copy (cf. `references/ban-list.md`) :
- Verbes : debloquer, revolutionner, transformer (sans objet), booster, exploiter le potentiel, propulser
- Adjectifs : innovant, disruptif, unique (sauf preuve), puissant (sans preuve), ultime, incontournable, game-changer, cutting-edge, robuste, seamless, holistique
- Promesses : garantit des resultats, 10x, le meilleur du marche, N1, resultats immediats, sans effort, tout-en-un magique
- Structures IA : "Dans le monde de...", "Il est important de noter que...", "Force est de constater...", "En definitive..."
- Faux urgence : offre limitee (sauf vraie deadline), derniere chance, ne manquez pas, agissez maintenant
