# Brand Profile — FluentCRM

## Personnalite de marque (FluentCRM)
- Ton : technique-accessible — explique des concepts CRM sans jargon excessif
- Registre : anglophone, vouvoiement implicite (site en anglais)
- Niveau technique : intermediaire — s'adresse a des utilisateurs WordPress qui savent installer un plugin

## Patterns linguistiques detectes
- Phrases signatures : "Without Limits!", "Inside WordPress", "Self Hosted"
- Mots recurrents : automation, unlimited, self-hosted, 360-degree, integrations, workflows
- Structure argumentaire : probleme (couts SaaS) → solution (self-hosted) → preuve (chiffres + temoignages)

## Adaptation schoolsWP

Le copy final utilise la voix schoolsWP, pas celle de FluentCRM :

- **Tutoiement systematique** — "tu", "ton", "tes", jamais "vous"
- **Phrases courtes** — 8-15 mots en moyenne, max 20
- **Paragraphes aeres** — 2-4 phrases max
- **Pas de jargon sans explication** — "self-hosted" devient "heberge sur ton propre serveur"
- **Actionnable** — chaque section donne quelque chose a faire ou a comprendre
- **Expressions signature schoolsWP** :
  - "En clair :"
  - "Teste et approuve."
  - "Pas de blabla, juste du concret."
  - "WordPress peut vraiment travailler pour toi."

## Identite visuelle appliquee

Les pages utilisent la palette schoolsWP (pas FluentCRM) :
- Primaire : #00D400 (vert)
- Accent : #E668D4 (rose/magenta)
- Fond : #12111F (dark mode)
- Texte : #FAFBFD
- Typo titres : Nunito Sans 700
- Typo body : Roboto 400

Voir `references/ban-list.md` — mots et structures interdits dans tout le copy.
Vigilance particuliere sur : "revolutionner", "puissant", "ultime", "dans le monde de", "il est important de noter".
