# Brand Profile — ThriveCart (iteration 2)

## Personnalite de marque (ThriveCart)
- Ton : confiant, direct, oriente resultats — pas corporate, pas decontracte non plus
- Registre : anglophone vouvoiement implicite ("you"), traduit en tutoiement schoolsWP
- Niveau technique : intermediaire — le freelance WordPress sait ce qu'est un checkout mais ne veut pas coder

## Patterns linguistiques detectes
- Phrases signatures : "Revenue Infrastructure", "Built for creators", "Zero transaction fees"
- Mots recurrents : revenue, conversion, creators, checkout, funnel, one-time
- Structure argumentaire : probleme (trop d'outils, trop cher) → solution (tout-en-un, paiement unique) → preuve (stats + temoignages)

## Adaptation schoolsWP

Le copy final utilise la voix schoolsWP, PAS celle de ThriveCart :
- **Tutoiement systematique** — "tu", "ton", "tes", jamais "vous"
- **Phrases courtes** : 8-15 mots en moyenne, max 20
- **Paragraphes aeres** : 2-4 phrases max
- **Pas de jargon sans explication** : "funnel" → expliquer brievement, "AOV" → "panier moyen"
- **Actionnable** : chaque section amene a une decision ou une action
- **Expressions signature** :
  - "En clair :"
  - "Teste et approuve."
  - "Pas de blabla, juste du concret."
  - "WordPress peut vraiment travailler pour toi."

## Ban List

Mots interdits — voir `references/ban-list.md`. Resume :
- Pas de : revolutionner, booster, innovant, disruptif, puissant, ultime, incontournable, game-changer, seamless, holistique
- Pas de : "Dans le monde de...", "Il est important de noter...", "Force est de constater..."
- Pas de fausse urgence : "offre limitee", "derniere chance", "agissez maintenant"
- Chaque phrase doit repondre a : "Est-ce que quelqu'un paierait pour cette information ?"
