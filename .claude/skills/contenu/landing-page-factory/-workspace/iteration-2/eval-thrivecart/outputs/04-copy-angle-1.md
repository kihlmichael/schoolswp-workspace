## FAQ

**ThriveCart fonctionne avec WordPress ?**
Oui. Tu integres le checkout en embed sur n'importe quelle page WordPress avec un simple code a coller. Aucun plugin supplementaire necessaire.

**C'est vraiment un paiement unique ?**
La licence Standard ($495) est un achat definitif. La version Pro+ ajoute un abonnement annuel ($295/an) pour les fonctions avancees (affilies, crypto, tax automation).

**Je peux migrer depuis WooCommerce ?**
ThriveCart ne remplace pas WooCommerce pour un e-commerce catalogue. Il remplace WooCommerce pour la vente de services, formations et produits digitaux avec checkout + funnels.

**Et si j'ai deja un LMS (TutorLMS, LearnDash) ?**
Tu peux garder ton LMS WordPress et utiliser ThriveCart uniquement pour le checkout. Ou utiliser le LMS integre de ThriveCart pour simplifier.

**Les taxes sont gerees automatiquement ?**
Oui, en Pro+. TVA europeenne, GST, sales tax US — calcul et collecte automatiques.
