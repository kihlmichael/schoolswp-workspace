# Brand Profile — Kadence Theme

## Personnalite de marque (Kadence)
- Ton : accessible et technique a la fois — Kadence parle a des utilisateurs WordPress qui veulent du controle sans complexite
- Registre : vouvoiement / neutre sur le site officiel (anglais)
- Niveau technique : intermediaire — presuppose une connaissance de WordPress mais explique ses features

## Patterns linguistiques detectes (site Kadence)
- Phrases signatures : "Effortlessly Build", "Lightning-fast performance", "Make building websites fun again", "Built from the ground up"
- Mots recurrents : fast, performance, customizable, drag & drop, starter templates, blocks, design library
- Structure argumentaire : feature → benefice → preuve visuelle (screenshots)

## Adaptation schoolsWP

Le copy final utilise la voix schoolsWP, pas celle de Kadence :
- **Tutoiement** systematique
- **Phrases courtes** : 8-15 mots en moyenne, max 20
- **Paragraphes aeres** : 2-4 phrases max
- **Pas de jargon sans explication** : "CSS pre-loading" → "le CSS se charge avant l'affichage, ton site s'affiche instantanement"
- **Actionnable** : chaque section doit donner envie d'agir
- **Expressions signature schoolsWP** :
  - "En clair :"
  - "Teste et approuve."
  - "Pas de blabla, juste du concret."
  - "WordPress peut vraiment travailler pour toi."
- **Modele funnel affiliation** : CTA = "Acheter Kadence et recevoir la formation gratuite" + mention lien affilie + section bonus

## Identite visuelle appliquee (schoolsWP, pas Kadence)
- Fond sombre : #12111F
- Texte principal : #FAFBFD
- CTA : fond #00D400, texte #12111F, hover #00A100
- Accent : #E668D4

- Body : Roboto regular 400

## Ban List
Consulter references/ban-list.md — aucun mot de cette liste ne doit apparaitre dans le copy.
Mots interdits cles : revolutionner, innovant, puissant (sans preuve), ultime, game-changer, seamless, "dans le monde de...", "il est important de noter".
