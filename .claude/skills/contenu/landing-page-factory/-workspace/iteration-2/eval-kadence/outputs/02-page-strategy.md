# Page Strategy — Kadence Theme

## Analyse du probleme

- **Quel probleme resout Kadence ?** Les themes WordPress gratuits sont soit lents, soit limites en personnalisation. Les themes premium sont souvent usines a gaz (Divi, Avada) qui alourdissent le site. Kadence offre performance + flexibilite sans page builder externe.
- **Pour qui ?** Deux personas principaux :
  1. Le freelance/createur de contenu qui lance son site WordPress et veut un resultat pro sans coder
  2. Le proprietaire de site WordPress existant qui veut accelerer son site et moderniser son design
- **Alternative actuelle ?** Astra (rapide mais basique en free), GeneratePress (technique, pas de header builder gratuit), Divi (lourd, proprio)

## Angles proposes

### Angle 1 : "Le theme qui ne te ralentit pas"
- **Hook** : Ton site WordPress rame. Kadence le remet a plat.
- **Cible** : proprietaire de site WordPress frustre par la lenteur (freelance, blogueur, e-commercant)
- **Emotion dominante** : frustration → soulagement
- **CTA principal** : Acheter Kadence et recevoir la formation gratuite
- **Mecanisme de preuve** : temoignages Jake Pfohl ("loads faster") + stats (3.4M sites) + garantie 30j
- **Structure** : probleme (lenteur) → cause (theme lourd) → solution (Kadence = leger + complet) → preuve → bonus schoolsWP → CTA

### Angle 2 : "Ton site pro en 30 minutes, sans coder"
- **Hook** : Finis les themes qui te font perdre 3 jours de config.
- **Cible** : createur de contenu / entrepreneur qui lance son premier site ou refait le sien
- **Emotion dominante** : aspiration → efficacite
- **CTA principal** : Acheter Kadence et recevoir la formation gratuite
- **Mecanisme de preuve** : starter templates + header builder + temoignage Adam Preiser ("the theme I have been waiting for") + formation schoolsWP offerte
- **Structure** : douleur (config interminable) → solution (templates + builder) → demo features → bonus schoolsWP → CTA
