# Ban List — Mots et expressions interdits

Ces mots tuent la credibilite du copy. Ils signalent "ecrit par une IA" ou "marketing creux".
Si un mot de cette liste apparait dans le copy, le remplacer ou supprimer la phrase entiere.

## Mots interdits (tolerace zero)

### Verbes vides
- Debloquer / Unlock
- Revolutionner / Revolutionize
- Transformer (sans objet concret)
- Booster
- Optimiser (quand utilise comme buzzword sans metrique)
- Exploiter le potentiel / Leverage
- Propulser

### Adjectifs creux
- Innovant / Innovative
- Disruptif / Disruptive
- Unique (sauf si prouve factuellement)
- Puissant / Powerful (sans preuve)
- Ultime / Ultimate
- Incontournable
- Game-changer
- Cutting-edge / A la pointe
- Robuste / Robust
- Seamless / Fluide (quand c'est du fluff)
- Holistique / Holistic

### Promesses non prouvables
- Garantit des resultats
- 10x / multipliez par 10
- Le meilleur du marche (sauf benchmark source)
- N°1 (sauf classement verifie)
- Resultats immediats
- Sans effort / Effortless
- Tout-en-un magique

### Structures IA typiques
- "Dans le monde de..." / "In today's..."
- "Il est important de noter que..."
- "Cela dit, il convient de..."
- "Force est de constater..."
- "En definitive..."
- "Au final, c'est un outil..."
- "Que vous soyez X ou Y, ce produit..."

### Faux urgence
- Offre limitee (sauf si vraie deadline)
- Derniere chance
- Ne manquez pas
- Agissez maintenant

## Alternatives recommandees

| Au lieu de... | Ecrire... |
|---------------|-----------|
| "Revolutionnez votre workflow" | "Gagne 2h par semaine sur [tache precise]" |
| "Solution puissante et innovante" | "Gere [X] sans installer [Y]" |
| "Boostez vos conversions" | "Les utilisateurs de [Produit] voient +15% de [metrique] (source)" |
| "Outil ultime pour..." | "[Produit] fait [chose precise] pour [persona]" |
| "Seamless integration" | "Se connecte a WooCommerce en 2 clics" |

## Regle d'or

Chaque phrase doit repondre a : "Est-ce que quelqu'un paierait pour cette information ?"
Si non → supprimer.
