# 5 Concepts de Miniatures YouTube -- [Maintenance WordPress]

## Concept 1 : "Le Site qui Explose"
- **Emotion** : Peur / urgence
- **Texte** : **TON SITE VA CRASHER**
- **Mise en page** : Visage choque (bouche ouverte, yeux ecarquilles) a gauche (40%), ecran d'erreur 500 WordPress a droite (60%)
- **Couleurs** : Degrade noir vers rouge fonce (#1a1a1a > #8B0000), texte blanc avec contour rouge
- **Expression** : Choc total -- sourcils leves, bouche en O, regard fixe camera

## Concept 2 : "La Checklist Secrete"
- **Emotion** : Curiosite / FOMO
- **Texte** : **7 ERREURS FATALES** (chiffre 7 en taille 3x)
- **Mise en page** : Visage complice (sourire en coin, sourcil leve) a gauche, liste avec coches vertes/croix rouges a droite, dernier item floute
- **Couleurs** : Bleu fonce (#0D1B2A) vers bleu WordPress (#21759B), chiffre en jaune (#FFD700)
- **Expression** : Malice confiante -- sourire asymetrique, regard complice

## Concept 3 : "Avant / Apres Desastre"
- **Emotion** : Contraste / transformation
- **Texte** : **AVANT** (rouge) | **APRES** (vert) + **MAINTENANCE WP** en bas
- **Mise en page** : Split screen 50/50 avec zigzag -- cote gauche desature (site casse), cote droit vif (score PageSpeed 100)
- **Couleurs** : Gauche gris/rouge terne, droite vert vif (#00E676) / bleu WordPress
- **Expression** : Pas de visage -- le contraste visuel est le hook

## Concept 4 : "Le Hacker a ta Porte"
- **Emotion** : Peur / menace directe
- **Texte** : **HACKE EN 3 MIN** (effet glitch) + **ton WordPress**
- **Mise en page** : Silhouette a capuche (hacker) a gauche sur fond code Matrix, logo WordPress avec cadenas casse a droite
- **Couleurs** : Noir (#000000) + vert Matrix (#00FF41), texte rouge alarme (#FF0000)
- **Expression** : Visage cache (hacker) ou alternative terrifiee avec regard lateral

## Concept 5 : "Le Gardien WordPress"
- **Emotion** : Aspiration / empowerment
- **Texte** : **PROTEGE TON SITE** + badge **en 10 min/mois**
- **Mise en page** : Visage confiant bras croises au centre, dashboard WordPress au vert en arriere-plan floute, bouclier vert semi-transparent
- **Couleurs** : Degrade bleu WordPress (#21759B > #0A1628), vert confiance (#00E676), badge orange (#FFA726)
- **Expression** : Confiance calme -- sourire leger, menton releve, bras croises

**Recommandations** : 1280x720px, max 5 mots, visage = 30% minimum, tester lisibilite sur mobile a 150px de large.
