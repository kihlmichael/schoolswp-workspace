# Miniatures pour la série "Les Coulisses de schoolsWP"

## Concept visuel général

**Format** : 1280 x 720 px (16:9), optimisé YouTube
**Style** : Personal branding authentique — ton visage en plan rapproché, expression engagée, fond épuré mais dynamique.

---

## Charte graphique des miniatures

### Palette de couleurs
- **Primaire** : bleu schoolsWP (#1E3A5F ou le bleu de ta charte) pour les éléments de structure (bandes, cadres)
- **Accent** : orange ou jaune vif pour les textes d'accroche (contraste fort, lisibilité mobile)
- **Fond** : dégradé sombre (gris anthracite → noir) ou fond flou de ton bureau/setup — renforce le côté "coulisses"
- **Texte** : blanc pur pour le titre principal

### Typographie
- **Titre** : police bold sans-serif (Montserrat Bold, Inter Black ou Poppins Bold), 2-4 mots max
- **Sous-titre optionnel** : même police en regular, taille réduite
- Toujours un contour ou une ombre portée pour garantir la lisibilité sur tous les fonds

### Logo schoolsWP
- Positionné en **bas à droite** ou **haut à gauche**, taille modérée (ne pas écraser le visage)
- Version blanche ou couleur selon le fond — toujours lisible
- Optionnel : léger effet lumineux (glow) autour du logo pour le faire ressortir

---

## Composition type (layout)

```
+----------------------------------------------+
|  [Logo schoolsWP]                            |
|                                              |
|         +----------------+                   |
|         |                |    TITRE ACCROCHE  |
|         |  TON VISAGE    |    (2-4 mots)     |
|         |  (détouré)     |                   |
|         |                |    sous-titre      |
|         +----------------+                   |
|                                              |
|                          [icône ou emoji]     |
+----------------------------------------------+
```

- **Visage** : détouré, légèrement décentré à gauche (règle des tiers)
- **Texte** : à droite du visage, aligné verticalement au centre
- **Fond** : dégradé ou photo floutée de ton environnement de travail

### Épisode 1 — "Pourquoi j'ai tout quitté"

- **Couleur accent** : orange

## Règles de cohérence pour la série

1. **Même cadrage** du visage sur chaque miniature (plan poitrine, même distance)
2. **Même position** du logo schoolsWP (toujours au même endroit)
3. **Même police** et même taille de texte — seuls le contenu et la couleur accent changent
4. **Fond cohérent** : même type de dégradé ou même environnement, décliné en variantes de couleur
5. **Bandeau "LES COULISSES"** en petit, toujours au même endroit (ex : haut gauche, sous le logo), pour identifier la série d'un coup d'oeil

---

## Conseils de production

- **Photos** : prendre une session photo dédiée avec 10-15 expressions différentes, éclairage constant, fond neutre (détourage facile ensuite)
- **Outils recommandés** : Canva Pro (templates réutilisables), Photoshop, ou Figma pour le template de base
- **Test mobile** : toujours vérifier la lisibilité en 120 x 68 px (taille d'affichage mobile YouTube) — si le texte n'est pas lisible à cette taille, simplifier
- **A/B testing** : YouTube permet de tester 3 miniatures par vidéo — préparer 2 variantes (avec/sans sous-titre, couleur accent différente)
