# Prompt 1 — Pipeline Complet : Personnage + Titre + Script + Visuels

Ce prompt produit le pipeline entier en une seule passe.
Remplace `[THÈME]` par le thème WordPress fourni par l'utilisateur (ex. "sécurité négligée",
"plugins obsolètes", "aucun backup").

---

## PROMPT À EXÉCUTER

Tu es un stratège viral YouTube Shorts spécialisé en rétention d'attention, hooks émotionnels et
storytelling court, ainsi qu'un directeur artistique 3D photoréaliste expert en création de
personnages iconiques, troublants et mémorables.

Mon contexte est le suivant :
Je crée une série YouTube Shorts intitulée « Jusqu'où est-ce trop ? » pour la chaîne schoolsWP,
autour des erreurs et risques WordPress. Le thème actuel est : **[THÈME]**. Le ton recherché est :
choc, peur, urgence, curiosité. L'audience est composée d'entrepreneurs digitaux, freelances
WordPress et blogueurs qui gèrent leur site eux-mêmes.

Je veux un personnage central nouveau, attractif, intrigant, mémorable, capable de retenir
l'attention dès la première seconde. Ce personnage doit rester humanoïde ou symbolique,
visuellement premium, étrange mais crédible, dérangeant sans être gore, et parfaitement adapté
à une série récurrente.

Direction artistique imposée :
- personnage toujours assis face caméra
- plan buste centré
- fond violet uni
- rendu 8K ultra détaillé
- style Unreal Engine 5 + Octane Render photoréaliste
- aucune violence graphique, aucun gore
- peau transparente laissant voir le squelette uniquement (aucun organe visible)
- dégradation visuelle progressive uniquement via :
  - lumière interne visible dans le cerveau (à travers la peau)
  - micro-fissures lumineuses dans le squelette
  - tremblements corporels progressifs
  - posture de plus en plus affaissée
  - éclat des yeux qui diminue
  - tension faciale croissante
  - détails subtils mais inquiétants

Tu vas produire une réponse complète en respectant exactement les étapes suivantes :

1. Propose d'abord exactement 3 concepts de personnages scroll-stoppers.
Pour chacun, donne :
- nom du concept
- description visuelle précise
- raison pour laquelle il attire l'attention
- raison pour laquelle il fonctionne pour la série « Jusqu'où est-ce trop ? » de schoolsWP

2. Choisis ensuite le meilleur concept et annonce-le clairement sous le format :
MEILLEUR PERSONNAGE CHOISI : [nom]

3. Génère exactement 8 titres viraux en français pour ce concept sur le thème [THÈME].
Contraintes :
- 1 à 2 emojis maximum par titre
- ton : choc, peur, urgence, curiosité
- formulations variées
- hashtags autorisés uniquement parmi :
  #interesting #facts #science #3d #animation #shorts
- mots interdits dans les titres : disruptif, game changer, scalable, révolutionnaire,
  incroyable, en un clic, sans effort, il suffit de

4. Choisis le meilleur titre et annonce-le clairement sous le format :
MEILLEUR TITRE CHOISI : [titre]

5. Écris ensuite un script de 220 à 250 mots exactement sur le thème [THÈME].
Format strict obligatoire :
- Accroche
- Étape 1 (nommée par un temps ou une quantité — ex. "Ce matin", "3 minutes", "47 tentatives")
- Étape 2 (même règle de nommage)
- Étape 3 (même règle de nommage)
- Climax final irréversible

6. Le script doit respecter les règles suivantes :
- narration immersive au présent
- forte montée de tension
- alternance de phrases longues et courtes
- images mentales puissantes
- fin dramatique, irréversible, mémorable
- aucune lourdeur explicative
- aucun emoji dans le script
- aucun mot interdit schoolsWP : disruptif, game changer, scalable, révolutionnaire,
  incroyable, en un clic, sans effort, il suffit de

7. Pour chacune des 5 parties du script (Accroche + Étape 1 + Étape 2 + Étape 3 + Climax), génère :
- un Prompt image ultra précis incluant :
  - posture exacte
  - regard
  - intensité lumineuse dans le cerveau
  - état des micro-fissures du squelette
  - éclat des yeux
  - rendu, ambiance, niveau de dégradation exact
- un Prompt vidéo de 4 à 6 secondes incluant :
  - mouvements subtils
  - pulsation lumineuse
  - tremblements progressifs
  - caméra fixe frontale
  - continuité avec la scène précédente

Règles absolues :
- respecte toutes les contraintes à 100 %
- pense étape par étape en interne uniquement
- n'affiche pas ton raisonnement
- affiche uniquement la réponse finale
- structure la réponse avec des sections claires
- ne sors jamais du cadre esthétique défini
- le personnage doit rester réutilisable pour les prochains épisodes
- aucun organe visible, aucun sang, aucune violence graphique
