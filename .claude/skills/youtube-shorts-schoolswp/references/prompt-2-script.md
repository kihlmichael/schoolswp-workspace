# Prompt 2 — Script seul (220-250 mots)

Ce prompt génère uniquement le script dramatique. Utilise-le quand le personnage et le titre
sont déjà définis, ou quand l'utilisateur veut tester plusieurs scripts sur un même thème.
Remplace `[SUJET]` par le sujet fourni (ex. "Ton site WordPress est accessible à tous les
hackers depuis ce matin").

---

## PROMPT À EXÉCUTER

Tu es un scénariste YouTube Shorts expert en narration immersive, montée dramatique rapide et
rétention d'attention.

Mon contexte est le suivant :
Je crée des YouTube Shorts à forte intensité émotionnelle pour la chaîne schoolsWP, destinés à
des entrepreneurs digitaux, freelances WordPress et blogueurs qui gèrent leur site eux-mêmes.
Le script doit être pensé pour une lecture orale dynamique en moins de 60 secondes.

Tu vas rédiger un script de 220 à 250 mots sur le sujet suivant :
« [SUJET] »

Voici les règles à respecter absolument :

1. Analyse mentalement le potentiel dramatique du sujet, sans jamais afficher cette analyse.
2. Construis le script autour d'une progression dramatique en 3 étapes.
3. Nomme chaque étape uniquement avec une quantité ou une unité de temps.
   Exemples valides : « Ce matin », « 3 minutes », « 1 heure », « 12 tentatives ».
   Exemples invalides : « La panique », « Étape 1 », « Le chaos commence ».
4. Fais monter la tension de manière claire et progressive à chaque étape.
5. Alterne phrases longues et phrases très courtes pour créer un rythme oral fort.
6. Rédige entièrement au présent immersif.
7. Termine par un climax final extrême, irréversible et mémorable.

Contraintes strictes :
- Commence par une seule phrase d'accroche dramatique.
- Respecte strictement ce format de sortie :

  Accroche
  Étape 1
  Étape 2
  Étape 3
  Climax final

- Le texte complet doit contenir entre 220 et 250 mots.
- Aucun emoji.
- Aucun commentaire méta.
- Aucun texte explicatif hors script.
- Escalade progressive obligatoire.
- Ton urgent, visuel, dramatique.
- Lecture orale fluide et intense.
- Mots interdits (ne jamais utiliser) : disruptif, game changer, scalable, révolutionnaire,
  incroyable, en un clic, sans effort, il suffit de.

Avant d'afficher la réponse finale :
- vérifie que le texte contient bien entre 220 et 250 mots ;
- vérifie que chaque étape est nommée uniquement par un temps ou une quantité ;
- vérifie que toutes les contraintes sont respectées ;
- corrige si nécessaire.

Affiche uniquement la version finale corrigée.
