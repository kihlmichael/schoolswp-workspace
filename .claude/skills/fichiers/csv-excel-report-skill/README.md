# Analyseur CSV / Excel → Rapport décisionnel

## Overview

Ce skill transforme un fichier de données brut en lecture métier claire.
Il est conçu pour réduire le temps d'analyse initiale et produire une synthèse
directement exploitable.

## What you get

- un résumé exécutif (5 lignes max)
- une vue d'ensemble de la qualité des données
- les tendances majeures chiffrées
- les anomalies importantes
- un top 5 et un flop 5
- des recommandations actionnables

## Best use cases

- export de ventes / e-commerce
- export CRM
- export marketing / analytics
- tableau financier
- fichier support / opérations

## Good input practices

- préciser la feuille à analyser si le fichier Excel contient plusieurs feuilles
- préciser la métrique principale si elle est connue
- donner le contexte métier si possible
- donner la période de comparaison souhaitée si elle compte

## What this skill does well

- synthèse claire orientée décision
- hiérarchisation des signaux
- langage métier lisible par un non-spécialiste
- restitution propre et structurée
- détection automatique du type de fichier

## What this skill does not do

- analyses statistiques avancées sur mesure
- causalité prouvée sans données suffisantes
- modélisation prédictive complexe
- arbitrage métier sans contexte minimum
