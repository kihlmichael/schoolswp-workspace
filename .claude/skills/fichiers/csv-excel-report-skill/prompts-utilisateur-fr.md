# Prompts utilisateur — Français

## Prompt universel (simple)

```
Analyse ce fichier CSV ou Excel et génère un rapport structuré avec un résumé exécutif
en 5 lignes, les tendances principales chiffrées, les anomalies détectées, un top 5,
un flop 5 et des recommandations concrètes.
```

## Prompt ventes

```
Analyse ce fichier de ventes. Mets l'accent sur le chiffre d'affaires, les produits
forts et faibles, les anomalies visibles et les actions prioritaires.
```

## Prompt CRM

```
Analyse ce fichier CRM. Je veux comprendre les meilleures sources de leads,
les points de blocage, les segments rentables et les priorités d'action.
```

## Prompt marketing

```
Analyse ce fichier marketing et identifie les canaux, campagnes ou segments
les plus performants et les moins performants. Termine par des recommandations simples.
```

## Prompt finance

```
Analyse ce tableau financier. Montre-moi les postes dominants, les dérives inhabituelles
et les concentrations de coûts ou revenus.
```

## Prompt support / opérations

```
Analyse ce fichier de tickets ou d'opérations. Je veux voir les catégories problématiques,
les délais anormaux et les priorités d'action.
```

## Prompt enrichi (tous paramètres)

```
Analyse la feuille [NOM_FEUILLE] de ce fichier Excel.
Utilise [KPI] comme métrique principale.
Regarde surtout les dimensions [DIM1], [DIM2] et [DIM3].
Compare si possible les performances entre [PERIODE1] et [PERIODE2].
Contexte : [CONTEXTE_METIER].
Le rapport doit rester compréhensible pour un non-spécialiste.
```
