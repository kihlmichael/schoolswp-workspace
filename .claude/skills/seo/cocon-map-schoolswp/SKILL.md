## Mode Maillage Page Unique (Dispatch)

Quand l'utilisateur fournit un contenu ou une URL a analyser pour le maillage interne
(depuis Dispatch ou mobile) :

### Entree

- URL, contenu colle ou fichier local
- Si le pilier/cocon n'est pas precise, le deduire du sujet

### Format court

```
## Position dans l'architecture
[A quel cocon/pilier cette page appartient, quel role elle joue]

## Liens internes a ajouter
[3-5 liens vers des pages existantes ou planifiees du site]
[Format : ancre suggeree → page cible]

## Liens entrants a creer
[2-3 pages du site qui devraient pointer vers cette page]

## Contenus complementaires a creer
[1-3 pages satellites manquantes dans le cocon]

## Priorite
[Critique / Important / Utile plus tard — avec justification courte]

## Sous-taches Dispatch
[2-3 taches : rediger un satellite, ajouter les liens, auditer le cocon]
```

### Contraintes mobile

- Pas d'arborescence complete — focus sur la page analysee
- Ancres concretes, pas de "voir aussi"
- 1 ecran par section max
