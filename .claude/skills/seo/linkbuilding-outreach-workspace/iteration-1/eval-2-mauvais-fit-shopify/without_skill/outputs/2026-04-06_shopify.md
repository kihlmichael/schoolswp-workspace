# Analyse de prospect backlink — Shopify Blog FR

**Prospect** : https://www.shopify.com/fr/blog/creer-boutique-en-ligne
**Page a promouvoir** : https://schoolswp.com/guides/woocommerce-vs-shopify/

## Statut des pages

Les deux URLs retournent 404 (confirme par double scrape Firecrawl, cache + fresh). Aucun contenu accessible sur aucune des deux pages.

## Verdict : 0/10 — NE PAS poursuivre

Trois raisons bloquantes cumulees :

1. **Page prospect 404** — la page Shopify n'existe plus. Impossible d'obtenir un lien depuis une page qui n'existe pas. Aucune surface d'accroche editoriale.

2. **Concurrent direct** — Shopify est le concurrent frontal de WooCommerce. Ils n'ont strictement aucun interet a linker vers un guide "WooCommerce vs Shopify" heberge sur un site pro-WordPress. C'est un conflit d'interet fondamental.

3. **Corporate ferme** — Le blog Shopify est produit par une equipe interne avec des standards corporate stricts. Pas de guest posts, pas de contributions externes, pas de mecanisme d'outreach. Meme si la page existait, la probabilite d'obtenir un lien est proche de zero.

## Note sur la page a promouvoir

schoolswp.com/guides/woocommerce-vs-shopify/ retourne egalement un 404. Avant toute demarche d'outreach future, cette page doit d'abord exister et contenir du contenu indexable.

## Alternatives recommandees

Pour placer un backlink sur un comparatif WooCommerce vs Shopify, cibler :
- Blogs WordPress independants (WPBeginner, etc.)
- Sites de comparatifs SaaS neutres (Capterra, G2)
- Blogueurs e-commerce francophones ouverts au guest posting
- Sites d'actualite WordPress (WP Tavern, ManageWP)
