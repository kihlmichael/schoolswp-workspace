# Checklist SEO — schoolsWP

Utiliser cette checklist pour chaque article publié sur schoolsWP. Chaque point doit être validé avant publication.

---

## Avant la rédaction

- [ ] Mot-clé principal identifié
- [ ] Intention de recherche analysée (informationnelle, transactionnelle, navigationnelle)
- [ ] SERP analysée (top 5 résultats, questions PAA, featured snippets)
- [ ] Angle différenciant défini (qu'est-ce que schoolsWP apporte de plus ?)
- [ ] Plan H2/H3 établi à partir des questions réelles des utilisateurs

## Structure du contenu

- [ ] H1 unique, descriptif, contient le mot-clé principal
- [ ] H2 descriptifs et utiles (pas de H2 génériques comme "Introduction")
- [ ] H3 si nécessaire pour sous-parties complexes
- [ ] Hiérarchie logique (pas de H3 sans H2 parent)
- [ ] Table des matières si l'article dépasse 2000 mots

## Optimisation on-page

- [ ] Title tag : mot-clé + bénéfice clair (< 60 caractères)
- [ ] Meta description : promesse concrète + incitation (< 155 caractères)
- [ ] URL : courte, descriptive, mot-clé principal, tirets
- [ ] Mot-clé dans le premier paragraphe (naturellement)
- [ ] Mot-clé dans au moins un H2
- [ ] Pas de bourrage de mots-clés

## Liens

- [ ] Au moins 3 liens internes vers d'autres contenus schoolsWP
- [ ] Liens internes pertinents (pas forcés)
- [ ] Liens externes vers sources fiables si pertinent
- [ ] Ancres de liens descriptives (pas de "cliquez ici")
- [ ] Liens affiliés avec mention transparente

## Images et médias

- [ ] Images pertinentes et utiles (captures d'écran, schémas)
- [ ] Alt text descriptif sur chaque image
- [ ] Images compressées (WebP si possible)
- [ ] Noms de fichiers descriptifs (pas "image1.png")

## Lisibilité

- [ ] Phrases de 8 à 15 mots en moyenne
- [ ] Paragraphes de 2 à 4 phrases
- [ ] Listes à puces pour les énumérations
- [ ] Gras sur les concepts clés (avec parcimonie)
- [ ] Aération suffisante (pas de murs de texte)

## Après publication

- [ ] Article indexé (vérifier dans Google Search Console)
- [ ] Pas d'erreur 404 sur les liens internes
- [ ] Affichage correct sur mobile
- [ ] Temps de chargement acceptable (< 3 secondes)
- [ ] Partage sur les réseaux sociaux
