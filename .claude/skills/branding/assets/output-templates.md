## A) Article de Blog schoolsWP

**Objectif** : Éduquer et apporter une solution concrète et actionnable.
**Longueur** : 1200 à 2500 mots selon complexité.
**Ton** : Pédagogique, clair, actionnable.

### Structure

```
1. ACCROCHE
   → Problème ou question directe (tutoiement)

2. CONTEXTE
   → Pourquoi c'est important (2-3 phrases)

3. SOLUTION DÉTAILLÉE
   → Étapes, exemples, captures

4. APPLICATION CONCRÈTE
   → Comment faire chez toi

5. FAQ / ERREURS COURANTES
   → Anticiper les blocages

6. CONCLUSION + CTA
   → Récap + lien interne ou affilié transparent
```

### CTA recommandés
- Lien vers outil recommandé (avec disclosure affilié)
- Ressource schoolsWP
- Invitation newsletter

- Invitation à tester

## F) Comparatif (plugins/outils)

**Objectif** : Aider à choisir selon le cas d'usage.
**Ton** : Objectif, structuré, orienté décision.

### Structure

```
1. CONTEXTE + CRITÈRES
   → 3-7 critères max

2. TABLEAU DÉCISIONNEL
   → "Si tu veux X, prends Y"

3. POUR CHAQUE OUTIL
   → Avantages + limites + pour qui (OBLIGATOIRE)

4. RECOMMANDATION FINALE
   → "Selon ton cas..."
```

### Format tableau
```
| Outil | Config | Perf | Prix | Pour qui |
|-------|--------|------|------|----------|
| A     | 5/5    | +++  | 59€  | Débutants |
| B     | 3/5    | ++   | 0€   | Techniques |
```

## M) Promotion d'article (déclinaison multi-canal)

**Objectif** : Décliner un article de blog en posts adaptés pour chaque réseau.
**Ton** : Adapté par canal (voir templates ci-dessus).

### Workflow

```
1. LIRE L'ARTICLE SOURCE
   → Identifier : sujet, angle, outil, bénéfice principal, CTA

2. EXTRAIRE LES ÉLÉMENTS CLÉS
   → 1 accroche forte (problème/question)
   → 3 points différenciants de l'outil/méthode
   → 1 bénéfice concret pour le lecteur
   → Lien affilié (si applicable, vérifier BRAND_CONTEXT.json)

3. DÉCLINER PAR CANAL
   → LinkedIn : post structuré (180 mots)
   → Facebook : conversationnel (100 mots)
   → X : percutant (60 mots)
   → Bluesky : technique et direct (70 mots)
   → Instagram : caption + hashtags (50 mots)
   → Pinterest : SEO-friendly (40 mots)
   → TikTok : script voix-off (100 mots)
   → Discord : message communauté (70 mots)

4. VÉRIFICATIONS
   → Lien affilié correct (slug ClickWhale)
   → Disclosure présent si lien affilié
   → Tutoiement partout
   → Aucun mot interdit
   → Brand QA scoré
```

### Règle clé
Chaque post doit pouvoir fonctionner seul. Pas de copier-coller entre canaux. L'angle, la longueur et le ton s'adaptent au canal.
