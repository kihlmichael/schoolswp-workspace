# Branding - Templates & Examples

Structures de sortie et exemples complets pour le skill **schoolsWP Branding Studio V3**.

## Fichiers disponibles

| Fichier | Description | Quand l'utiliser |
|---------|-------------|------------------|
| `output-templates.md` | Structures détaillées par canal | Production de contenu (Step 4) |
| `examples.md` | Exemples complets annotés | Référence qualité, inspiration |

## Structures disponibles

| Canal | Longueur | Ton |
|-------|----------|-----|
| **Article Blog** | 1200-2500 mots | Pédagogique, structuré |
| **Newsletter** | 300-600 mots | Personnel, direct |
| **LinkedIn** | 100-200 mots | Inspirant, conversationnel |
| **Facebook** | 80-150 mots | Conversationnel, accessible |
| **YouTube Script** | 5-15 min | Énergique, démonstratif |
| **Comparatif** | Variable | Objectif, orienté décision |
| **Bio** | 150 mots max | Concise, percutante |
| **Calendrier** | 1-2 semaines | Structuré par piliers |

## Exemples inclus

1. **Article blog** — Intro annotée (FluentCRM)
2. **Newsletter** — Exemple complet avec annotations
3. **LinkedIn** — Post complet WordPress/SEO
4. **YouTube** — Script intro + corps + récap
5. **Comparatif** — Tableau + recommandation
6. **Mode check** — Output QA attendu
7. **Bio** — Version courte + one-liner
8. **Calendrier** — Plan 2 semaines

## Usage

Le skill charge automatiquement `output-templates.md` lors de la production (Step 4).
Consulter `examples.md` pour voir des exemples réels annotés et comprendre le niveau de qualité attendu.

## Ajouter un template/exemple

1. Identifier le canal/format manquant
2. Ajouter la structure dans `output-templates.md`
3. Ajouter un exemple complet annoté dans `examples.md`
4. Tester avec le skill
