# Branding - Procedures & References

Documentation de fond pour le skill **schoolsWP Branding Studio V3**.
Ces fichiers sont chargés à la demande (progressive disclosure) selon le workflow.

## Fichiers disponibles

| Fichier | Description | Quand l'utiliser |
|---------|-------------|------------------|
| `brand-identity.md` | Mission, promesse, profil MK, 10 principes | Toujours consulter avant d'écrire |
| `tone-of-voice.md` | Personnalité, vocabulaire, expressions signature | Toujours consulter avant d'écrire |
| `writing-rules.md` | Règles d'écriture strictes (phrases, paragraphes) | Production de contenu |
| `pillars-calendar.md` | Piliers éditoriaux + calendrier 2 semaines | Mode `calendar` |
| `coherence-scorecard.md` | Grille QA /100 + checklist IA | Mode `check` + Step 5 QA |

## Usage dans le workflow

1. **Step 1-3** : Lire `brand-identity.md` + `tone-of-voice.md`
2. **Step 4** : Appliquer `writing-rules.md` pendant la production
3. **Step 5** : Appliquer `coherence-scorecard.md` pour la QA obligatoire

## Contenu fusionné (V3)

Cette version fusionne :
- L'ancien skill schoolsWP complet (identité, profil MK, 10 principes, règles d'écriture)
- La structure hub-and-spoke avec progressive disclosure
- Les modes explicites (draft/rewrite/check/calendar/bio/one-liner)

## Maintenance

Pour modifier les guidelines schoolsWP :
1. Mettre à jour le fichier concerné
2. Tester avec `/schoolswp-branding-studio check` sur un contenu existant
3. Vérifier la cohérence avec les autres fichiers
