# Writing Rules — schoolsWP (V3)

Règles d'écriture **strictes** à appliquer systématiquement.

---

## Structure de Phrase

| Règle | Détail |
|-------|--------|
| **Longueur moyenne** | 8 à 15 mots |
| **Maximum absolu** | 20 mots (sauf exception justifiée) |
| **Structure** | Sujet + verbe + complément |
| **Subordonnées** | Éviter les complexes |
| **Rythme** | Alterner courtes (impact) et moyennes (fluidité) |
| **Forme** | Affirmatives plutôt que négatives |
| **Engagement** | Questions pour impliquer le lecteur |

**Exemples :**

✅ "WordPress peut être simple. Voici comment." (10 mots)
❌ "WordPress, qui est souvent perçu comme compliqué par les débutants, peut en réalité devenir simple si vous suivez les bonnes méthodes." (24 mots)

---

## Structure de Paragraphe

| Règle | Détail |
|-------|--------|
| **Longueur** | 2 à 4 phrases maximum |
| **Contenu** | Une idée par paragraphe |
| **Espacement** | Toujours un espace entre chaque paragraphe |
| **Interdit** | Blocs de texte compacts |

**Exemple :**

✅
> Installer un plugin de cache prend 2 minutes.
>
> La configuration de base suffit dans 80% des cas.
>
> Voici les 3 réglages essentiels.

❌
> Installer un plugin de cache est une opération qui ne prend que quelques minutes et qui peut considérablement améliorer les performances de votre site WordPress. La plupart des utilisateurs n'ont besoin que de la configuration de base, qui est généralement suffisante pour obtenir de bons résultats. Dans cet article, nous allons voir ensemble les trois réglages les plus importants à effectuer.

---

## Structure Globale de Contenu

### Introduction

1. **Accroche** — Problème, question ou vérité
2. **Contexte** — En une phrase
3. **Promesse** — Ce que le lecteur va apprendre/faire

### Développement

1. **H2 clairs et descriptifs** — Pas de titres vagues
2. **H3 si nécessaire** — Pour sous-parties
3. **Listes** — Pour clarifier points multiples
4. **Exemples concrets** — Captures d'écran si pertinent
5. **Transitions fluides** — Entre les parties

### Conclusion

1. **Synthèse** — 1-2 phrases max
2. **Ouverture** — Invitation à l'action
3. **CTA** — Naturel et transparent

## Mise en Forme

| Élément | Usage |
|---------|-------|
| **Gras** | Concepts clés (avec parcimonie) |
| **Listes** | Clarifier points multiples |
| **Citations/encadrés** | Mettre en avant idée forte |
| **Sous-titres** | Réguliers pour aérer |
| **Italique** | Uniquement titres d'outils/logiciels |
| **Emojis** | 1 par section max, si pertinent |

---

## Règles SEO Naturelles

| Règle | Détail |
|-------|--------|
| **Titre** | Orienté résultat, pas promesse excessive |
| **H2/H3** | Structurés et descriptifs |
| **Mots-clés** | Intégrés naturellement, pas de bourrage |
| **Meta description** | Promesse + action en 155 caractères |
| **Liens internes** | Vers ressources schoolsWP pertinentes |
| **Alt text images** | Descriptifs avec mots-clés naturels |

## Longueurs Recommandées par Format

| Format | Longueur | Notes |
|--------|----------|-------|
| **Article blog** | 1200-2500 mots | Selon complexité |
| **Newsletter** | 300-600 mots | Personnel et direct |
| **Post LinkedIn** | 100-200 mots | Accroche + liste + CTA |
| **Post Facebook** | 80-150 mots | Conversationnel |
| **Script YouTube** | 5-15 min | Selon sujet |
| **Bio** | 150 mots max | Concise et percutante |
| **One-liner** | 1 phrase | Transformation + méthode |

---

## Checklist Avant Publication

Avant de finaliser, vérifier :

- [ ] **Phrases** : Aucune > 20 mots ?
- [ ] **Paragraphes** : Tous < 5 phrases ?
- [ ] **Aération** : Espace entre chaque bloc ?
- [ ] **Structure** : Intro-Body-Conclusion respectée ?
- [ ] **H2/H3** : Clairs et descriptifs ?
- [ ] **Gras** : Utilisé avec parcimonie ?
- [ ] **CTA** : Présent et naturel ?
- [ ] **Jargon** : Tout expliqué ?

---

## Anti-Patterns d'Écriture

| Anti-pattern | Correction |
|--------------|------------|
| Phrase de 30 mots | Couper en 2-3 phrases |
| Paragraphe de 10 lignes | Diviser par idée |
| Introduction de 5 paragraphes | Réduire à 3-4 phrases |
| Titre vague "Mon avis" | Titre spécifique "WP Rocket vs LiteSpeed : mon test" |
| Conclusion sans CTA | Ajouter action simple |
| Texte sans sous-titre | Aérer avec H2 tous les 200-300 mots |
