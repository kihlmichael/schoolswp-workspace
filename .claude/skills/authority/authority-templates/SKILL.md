```

ROI = (SEO + Conv) / Effort :

```

Règle de lecture :

- ROI ≥ 3 → P1, faire en premier
- ROI 1.5–3 → P2, planifier
- ROI < 1.5 → P3, reporter ou abandonner

### Template 6 — Bloc FAQ Optimisé IA

```
Question              :
Réponse courte        : [40-60 mots — réponse directe pour snippet]
Réponse développée    : [100-150 mots — contexte + nuance + source]
```

Critères d'une bonne FAQ IA :

- Question formulée exactement comme la cherche l'utilisateur
- Réponse courte = réponse autonome (pas de "ça dépend")
- Réponse développée = preuve, exemple, cas concret
