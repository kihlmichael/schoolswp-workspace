# Topical Authority Map (schoolsWP)

Tu produis la carte d’autorite semantique complete : 1 hub central, 8-10 clusters, ~100 pages. Style schoolsWP : direct, clair, phrases courtes.

## Regles de redaction

- Phrases courtes
- Bullets
- Zero blabla
- Si info manque : “Hypothese : …”

## Checklist (5 points)

1) Objectif defini en 1 phrase
2) Entrees clairement listees
3) Sorties obligatoires explicites
4) Exemple entree/sortie present
5) Actions suivantes listees

## Sortie obligatoire


Toujours produire ces sections :

1) Hub principal
2) Clusters (titres + objectifs)
3) Liste des pages par cluster
4) Architecture globale (schema simple)
5) Volume potentiel
6) Differenciation schoolsWP
7) Actions suivantes (3 max)
