# Structures de carrousels Instagram — schoolsWP

> Templates de carrousels éprouvés pour Instagram. Chaque structure = un chemin clair de lecture du slide 1 au slide final, avec un framework narratif assumé.

**Longueur par défaut** : 8–10 slides. Jamais plus de 10 sauf justification forte.

Chaque slide = 1 idée max, 1 phrase, 1 visuel simple. **Si tu ne peux pas lire la slide en 2 secondes, elle est trop chargée.**

---

## Structure 1 — "Erreur → Correction" (PSPC)

**Pour** : alerter, déconstruire une mauvaise pratique.

| Slide | Contenu                                                                |
| ----- | ---------------------------------------------------------------------- |
| 1     | Hook "erreur" → "La faute que 9/10 font avec [outil]"                  |
| 2     | Pourquoi c'est un problème (impact concret)                            |
| 3     | D'où vient l'erreur (cause typique)                                    |
| 4     | Ce qu'il faut faire à la place (méthode claire)                        |
| 5     | Étape 1 du correctif                                                   |
| 6     | Étape 2 du correctif                                                   |
| 7     | Preuve / exemple chiffré / avant-après                                 |
| 8     | Récap en 3 points                                                      |
| 9     | CTA : "Sauvegarde ce carrousel pour plus tard" ou "Lis le guide complet" |

---

## Structure 2 — "Tutoriel en N étapes" (PSPC)

**Pour** : apprendre à faire quelque chose de concret.

| Slide | Contenu                                                                |
| ----- | ---------------------------------------------------------------------- |
| 1     | Hook promesse : "[Résultat concret] en 5 étapes"                      |
| 2     | Pourquoi c'est utile (contexte + enjeu)                                |
| 3     | Étape 1 (verbe d'action + résultat)                                    |
| 4     | Étape 2                                                                |
| 5     | Étape 3                                                                |
| 6     | Étape 4                                                                |
| 7     | Étape 5                                                                |
| 8     | Résultat obtenu (preuve visuelle ou chiffrée)                          |
| 9     | CTA : "Teste par toi-même" + lien en bio                               |

---

## Structure 3 — "Comparatif A vs B" (PSPC ou PAS)

**Pour** : aider à choisir entre 2 outils / 2 approches.

| Slide | Contenu                                                                |
| ----- | ---------------------------------------------------------------------- |
| 1     | Hook comparatif : "[Outil A] vs [Outil B] : mon verdict"               |
| 2     | Pourquoi ce comparatif (cas d'usage précis)                            |
| 3     | Critère 1 (Prix, features, UX…) + verdict                              |
| 4     | Critère 2 + verdict                                                    |
| 5     | Critère 3 + verdict                                                    |
| 6     | Critère 4 + verdict                                                    |
| 7     | "Quand choisir A"                                                      |
| 8     | "Quand choisir B"                                                      |
| 9     | Mon choix personnel (tranché) + CTA                                    |

**Règle schoolsWP** : jamais de comparatif fade. Tranche clairement. Donne ton verdict.

## Structure 4 — "Opinion tranchée" (PAS)

**Pour** : poser une position forte, générer commentaires.

| Slide | Contenu                                                                |
| ----- | ---------------------------------------------------------------------- |
| 1     | Hook contrarien : "Je n'utilise plus [X] en 2026"                      |
| 2     | Contexte — pourquoi je l'utilisais avant                               |
| 3     | Le problème que je rencontrais (agitation)                             |
| 4     | Le moment du déclic                                                    |
| 5     | Ce que j'utilise à la place                                            |
| 6     | Le gain concret (chiffre, temps, résultat)                             |
| 7     | À qui ça ne convient **pas** (honnêteté)                               |
| 8     | "Tu es dans quel cas ?" → CTA commentaire                              |

## Structure 5 — "Stack / méthode schoolsWP" (AIDA)

**Pour** : partager un système, une pile d'outils, une méthode.

| Slide | Contenu                                                                |
| ----- | ---------------------------------------------------------------------- |
| 1     | Hook : "Ma stack [domaine] en 2026"                                    |
| 2     | Le problème qu'elle résout                                             |
| 3     | Outil 1 + rôle                                                         |
| 4     | Outil 2 + rôle                                                         |
| 5     | Outil 3 + rôle                                                         |
| 6     | Comment les outils se parlent (flux)                                   |
| 7     | Résultat obtenu (preuve)                                               |
| 8     | "Stack complète en commentaire" ou lien bio                            |

## Structure 10 — "Idée reçue déconstruite"

**Pour** : générer débat, affirmer une expertise.

| Slide | Contenu                                                                |
| ----- | ---------------------------------------------------------------------- |
| 1     | Hook : "Non, [croyance commune] est faux"                              |
| 2     | D'où vient cette croyance (origine)                                    |
| 3     | Pourquoi elle semble vraie (grain de vérité)                           |
| 4     | Mais dans la réalité : [nuance / contre-exemple]                       |
| 5     | Preuve concrète (chiffre, cas, test)                                   |
| 6     | La vraie logique c'est [X]                                             |
| 7     | Comment appliquer cette vraie logique                                  |
| 8     | CTA discussion : "Tu en penses quoi ?"                                 |

## Règles communes à tous les carrousels

1. **Slide 1 = hook seul.** Pas de développement. Jamais.
2. **Slide 2 = contexte / enjeu.** Sert à vendre la lecture de la suite.
3. **Slides intermédiaires** = 1 idée par slide, 1 phrase courte, 1 visuel simple.
4. **Avant-dernière slide** = récap en 3 points OU transition vers le CTA.
5. **Dernière slide** = CTA unique, utile, non agressif.

## CTA carrousel schoolsWP (à alterner)

- "Sauvegarde pour plus tard 📎"
- "Partage à quelqu'un qui galère avec [outil]"
- "Lis le guide complet sur schoolsWP (lien bio)"
- "Teste par toi-même et dis-moi en DM"
- "Question ou retour ? Commente 👇"
- "Reçois la stack complète par email (lien bio)"

**Jamais** : "Double-tap si tu es d'accord", "N'hésitez pas à liker", "Smash that like button" (équivalents IG creux).

## Checklist finale avant livraison

- [ ] Slide 1 passe le test stop-scroll (< 10 mots, curiosité ou heurt)
- [ ] Slide 2 donne envie de lire la suite
- [ ] Une preuve / cas / chiffre présent quelque part
- [ ] Progression claire slide après slide (pas de saut logique)
- [ ] CTA unique et cohérent avec le sujet
- [ ] Caption en-dessous (150–220 mots) + 8–12 hashtags
- [ ] Zéro mot interdit schoolsWP
- [ ] Tutoiement systématique
