# Mode Campagne — 10 posts Instagram schoolsWP

> Détail complet du mode Campagne : construction du tableau maître Phase 1, règles de progression, mix recommandé, anti-patterns, exemples.

Ce mode fonctionne en **2 phases strictes**. Phase 1 = tableau maître seul. Phase 2 = production, **uniquement après GO explicite de l'utilisateur**.

---

## Cadrage — Interpréter l'input utilisateur

L'utilisateur donne un des inputs suivants :

| Type d'input                              | Angle directeur à construire                                            |
| ----------------------------------------- | ----------------------------------------------------------------------- |
| Lancement d'un guide                      | Teasing → preuve → mise en avant → CTA vers lead magnet                 |
| Mise en avant d'un comparatif             | Problème de choix → critères → verdict tranché → CTA article            |
| Campagne autour d'un plugin WordPress     | Douleur → solution → stack → preuve → CTA tuto / affiliation            |
| Série éducative sur l'automatisation      | Cas d'usage → méthode → stack → erreurs → transition offre              |
| Campagne sur une erreur fréquente         | Symptôme → diagnostic → correction → preuve → CTA guide                 |
| Soutien d'une offre de service            | Signaux → douleur → méthode → preuve → CTA démo/réservation             |
| Faire connaître schoolsWP                 | Qui → quoi → comment → preuves → CTA newsletter/guide                   |

**Questions à poser si l'input est trop vague** (max 3) :
1. Quel est l'objectif final de la campagne (trafic / lead / conversion / notoriété) ?
2. Y a-t-il un contenu pilier / une ressource à pousser en fin de campagne ?
3. Y a-t-il un délai ou un contexte (lancement, saison, actualité) ?

Si 2 réponses sur 3 sont données → lance Phase 1.

## Phase 1 — Tableau maître

### Livrables obligatoires en Phase 1

1. **Nom de campagne** — clair, descriptif, court. Jamais de nom marketing creux.
   - ✅ "Campagne FluentCRM — Remplacer Mailchimp en 10 jours"
   - ❌ "Campagne Ultimate Boost"
2. **Angle directeur** — 1 phrase qui résume la thèse de la campagne.
   - ✅ "Montrer comment FluentCRM remplace Mailchimp sur WordPress, sans perte de fonctionnalités et avec un vrai gain de contrôle."
   - ❌ "Parler de FluentCRM."
3. **Tableau maître** — 12 colonnes × 10 lignes (voir schéma détaillé ci-dessous).
4. **Question finale** — `GO pour la phase 2 ?`

### Schéma du tableau maître (12 colonnes)

| Colonne             | Contenu                                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------- |
| `#`                 | Numéro du post (01 à 10)                                                                    |
| `Rôle post`         | Fonction dans la campagne (accroche / éducation / problème / solution / comparatif / preuve / transition) |
| `Post Type`         | Catégorie éditoriale (erreur / conseil / méthode / comparatif / opinion / tutoriel / checklist) |
| `Format`            | Carrousel / post simple / mini-checklist / mini-comparatif                                  |
| `Sujet`             | Sujet précis du post (1 ligne)                                                              |
| `Angle`             | L'angle narratif choisi (lié à `angle-patterns.md`)                                         |
| `Hook`              | Première ligne / slide 1 (concrète, pas un placeholder)                                     |
| `Promesse`          | Ce que l'audience va apprendre ou gagner (1 phrase)                                         |
| `Message clé`       | L'idée force à retenir si l'audience ne voit que ce post (1 phrase)                         |
| `CTA`               | Action précise attendue (sauvegarder, lire, partager, DM, lien bio…)                        |
| `Niveau d'intention`| Découverte / Intérêt / Considération / Pré-conversion                                       |
| `Objectif business` | Visibilité / Éducation / Crédibilité / Engagement / Capture / Conversion douce              |

### Règles de progression

Une campagne 10 posts **n'est pas une liste aléatoire**. Elle suit une trajectoire.

**Trajectoire type (à adapter selon le sujet)** :

1. **Post 1–2 — Accroche / découverte** : capter, créer de l'intrigue, identifier le problème cible (niveau Découverte)
2. **Post 3–5 — Éducation** : enseigner, poser la méthode, crédibiliser (niveau Intérêt)
3. **Post 6–7 — Problème / Solution** : agiter la douleur puis poser la solution schoolsWP (niveau Intérêt → Considération)
4. **Post 8 — Comparatif / preuve** : verdict tranché, preuve par l'usage, différenciation (niveau Considération)
5. **Post 9 — Crédibilité / retour d'expérience** : cas concret, chiffres, résultat (niveau Considération)
6. **Post 10 — Transition conversion douce** : pont vers la ressource / offre / newsletter / guide (niveau Pré-conversion)

**Contraintes de mix** :
- Au moins 3 niveaux d'intention différents représentés
- Au moins 4 objectifs business différents
- Au moins 3 formats différents (pas 10 carrousels)
- Au moins 1 post "erreur" OU "comparatif" (génèrent les meilleurs saves)
- Au moins 1 post "retour d'expérience chiffré" (crédibilité schoolsWP)
- Maximum 2 posts "opinion tranchée" sur une même campagne

### Conventions de rédaction du tableau

- **Hook** : écris le hook réel, pas un résumé (ex: "La faute que 9 utilisateurs sur 10 font avec FluentCRM" et non "hook erreur")
- **Promesse** : verbe + résultat concret ("Savoir en 30 secondes si FluentCRM remplace Mailchimp pour ton cas")
- **Message clé** : 1 phrase, peut être cité en slide de récap
- **CTA** : action concrète et mesurable ("Sauvegarde le carrousel", "Commente ton cas", "Lis le guide en bio"), jamais vague

### Contraintes de fond (non-négociables)

Chaque post doit être :
- Utile
- Crédible
- Concret
- Compréhensible vite
- Aligné avec schoolsWP
- Rédigé pour de vraies personnes, pas pour flatter l'algorithme

### Anti-patterns Phase 1

- Listing de 10 "top 10 [sujet]"
- 10 posts du même format
- Progression absente (les 10 posts pourraient être dans n'importe quel ordre)
- CTA identique sur les 10 posts
- Hooks génériques type "Tu savais que…", "Voici LE secret…"
- Niveaux d'intention tous identiques (ex: 10 posts "Découverte")
- Objectifs business tous "Visibilité"
- Aucun post dédié à la crédibilité ou à la preuve
- Angle directeur vague ("parler de [sujet]")

### Fin de Phase 1

Après le tableau :

```
GO pour la phase 2 ?
```

**Ne produis jamais Phase 2 tant que l'utilisateur ne valide pas explicitement.** S'il demande des ajustements sur le tableau → reste en Phase 1, ajuste, redemande le GO.

## Phase 2 — Production détaillée (après GO)

Pour chaque post (10 au total), produis dans cet ordre :

### A. Fiche éditoriale

```markdown
## Post N — [Titre interne]

- **Objectif** : [reprendre l'objectif business du tableau, contextualiser]
- **Angle** : [reprendre angle du tableau, enrichir si besoin]
- **Hook final** : [version finalisée du hook — peut être ajusté par rapport au tableau]
- **CTA final** : [CTA final avec formulation précise]
```

### B. Contenu du post

**Selon le format du post** (voir tableau maître) :

- **Carrousel** → utilise `references/carousel-structures.md` (10 structures), applique framework PSPC / PAS / AIDA selon angle, slide par slide (8–10 slides), caption IG 150–220 mots, hashtags 8–12
- **Post simple** → texte principal 50–150 mots, structure AIDA, hashtags 5–8
- **Mini-checklist** → titre + 5–8 items ordonnés + outro utile (100–150 mots total)
- **Mini-comparatif** → intro contexte + 3–5 critères comparés + verdict tranché + CTA
- **Post erreur / conseil / méthode / avis** → structure PAS ou PSPC selon angle, 80–130 mots, chute forte

### C. Brief visuel

Voir `references/visual-brief-template.md` pour template complet.

Structure minimum :

```markdown
### Brief visuel — Post N

- **Intention visuelle** : …
- **Type de composition** : …
- **Hiérarchie de texte** : …
- **Ambiance** : …
- **Niveau de contraste** : …
- **Élément à mettre en avant** : …
- **Recommandation visuelle** : …
- **À éviter visuellement** : …
```

### D. Prompt visuel de production

Prompt opérationnel pour outil de génération (Nano Banana par défaut — voir memory `feedback_image_gen.md`).

Voir `references/visual-brief-template.md` pour structure détaillée et exemples.

### E. Structure de livraison

Détails complets : `references/delivery-structure.md`.

Arborescence à créer :

```
/Reseaux/
  /Campagne-[nom-campagne-kebab-case]/
    ├── 00-tableau-maitre.md
    ├── 01-post-01.md
    ├── 02-post-02.md
    ├── …
    └── 10-post-10.md
```

Un fichier par post. Format de nommage : `NN-post-NN.md` (zéro-padding sur 2 chiffres).

## Exemples de campagnes types

### Exemple 1 — Campagne FluentCRM (remplacer Mailchimp)

- **Nom** : "Remplacer Mailchimp par FluentCRM"
- **Angle directeur** : "Montrer comment FluentCRM remplace Mailchimp sur WordPress, avec plus de contrôle et moins de frais mensuels."
- **Trajectoire** :
  - Post 1 (accroche) : "Tu paies 99 €/mois à Mailchimp ?" (post simple, Découverte, Visibilité)
  - Post 2 (accroche) : "4 signaux que ton CRM te freine" (carrousel, Découverte, Éducation)
  - Post 3 (éducation) : "Comment fonctionne FluentCRM" (carrousel, Intérêt, Éducation)
  - Post 4 (éducation) : "Segments et tags : la logique qui change tout" (carrousel, Intérêt, Éducation)
  - Post 5 (problème) : "Pourquoi Mailchimp te coûte plus cher chaque année" (post simple, Intérêt, Crédibilité)
  - Post 6 (solution) : "Ma méthode de migration Mailchimp → FluentCRM en 3 étapes" (carrousel, Considération, Éducation)
  - Post 7 (comparatif) : "Mailchimp vs FluentCRM : 4 critères, 1 verdict" (mini-comparatif, Considération, Crédibilité)
  - Post 8 (preuve) : "6 mois avec FluentCRM sur schoolswp.com — chiffres réels" (carrousel, Considération, Crédibilité)
  - Post 9 (erreur) : "L'erreur qui fait crasher FluentCRM à partir de 5000 contacts" (post simple, Considération, Engagement)
  - Post 10 (transition) : "Le guide complet pour migrer" (carrousel, Pré-conversion, Conversion douce)

### Exemple 2 — Campagne "Lancement guide Rank Math"

- **Nom** : "Guide Rank Math — De zéro à site bien référencé"
- **Angle directeur** : "Positionner Rank Math comme alternative crédible à Yoast, avec la méthode schoolsWP pour s'en servir vraiment."

Structure similaire : teasing → éducation → preuve → comparatif Yoast → retour d'expérience → CTA guide.

## Commandes pendant la Campagne

| Commande                         | Effet                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------ |
| `Change le post N`               | Reprend uniquement la ligne N du tableau, en garde la logique globale                |
| `Inverse le post N et M`         | Échange deux posts dans la séquence                                                  |
| `Remplace [format] par [format]` | Change le format d'un post (ex : "Remplace le comparatif par un post simple")        |
| `Ajoute un post [rôle]`          | Insère un post supplémentaire (et retire le plus faible)                             |
| `Plus dur sur [post N]`          | Pousse le hook et la promesse du post N en version plus affirmée                     |
| `GO phase 2`                     | Déclenche Phase 2 (production détaillée)                                             |
| `GO phase 2 sauf post N`         | Produit les posts sauf N (utile si un post doit être retravaillé)                    |

---

## Critères d'acceptation Phase 1

- [ ] Nom de campagne clair et descriptif
- [ ] Angle directeur formulé en 1 phrase
- [ ] 10 posts avec progression logique
- [ ] Mix de formats (≥ 3 différents)
- [ ] Mix de niveaux d'intention (≥ 3 différents)
- [ ] Mix d'objectifs business (≥ 4 différents)
- [ ] Au moins 1 post "erreur" OU "comparatif"
- [ ] Au moins 1 post "retour d'expérience"
- [ ] Au moins 1 post de transition vers conversion douce
- [ ] Hooks écrits (pas des placeholders)
- [ ] CTAs variés (pas tous identiques)
- [ ] Zéro mot interdit
- [ ] Question finale `GO pour la phase 2 ?` posée

## Critères d'acceptation Phase 2

- [ ] 10 fiches éditoriales complètes (A)
- [ ] 10 contenus rédigés au format requis (B)
- [ ] 10 briefs visuels détaillés (C)
- [ ] 10 prompts visuels exploitables (D)
- [ ] Arborescence `/Reseaux/Campagne-[nom]/` créée avec 11 fichiers (tableau + 10 posts)
- [ ] Chaque post respecte checklist qualité schoolsWP (naming, tutoiement, preuve, CTA, phrases courtes)
