# Angles éditoriaux — contenu Instagram schoolsWP

> 9 angles récurrents qui fonctionnent pour la communauté schoolsWP (WordPress, SEO, automatisation, CRM, LMS, plugins). Chaque angle = une intention + une structure de pensée + des hooks associés.

À utiliser en complément de `hooks-library.md` et `carousel-structures.md`.

---

## Angle 1 — Erreur à éviter

**Intention** : alerter, sécuriser l'audience, générer des saves.

**Quand l'utiliser** :
- Un plugin / réglage / pratique très répandu mais mal maîtrisé
- Une idée reçue qui coûte du temps ou de l'argent
- Un piège récurrent lors de la configuration d'un outil

**Structure mentale** :
1. Nommer l'erreur précisément
2. Quantifier l'impact (temps, argent, perfs)
3. Expliquer la cause
4. Donner la correction en étapes concrètes
5. Preuve (test, cas, avant/après)

**Hooks associés** : typologie 1 (`hooks-library.md`)

**Exemples schoolsWP** :
- "L'erreur qui fait crasher FluentCRM à partir de 5000 contacts"
- "Pourquoi ton plugin de cache ralentit en fait ton WordPress"
- "Le réglage Rank Math que tout le monde laisse par défaut (et qui tue ton SEO)"

**Framework recommandé** : PSPC ou PAS.

## Angle 2 — Conseil pratique

**Intention** : transmettre un savoir-faire actionnable, renforcer l'autorité.

**Quand l'utiliser** :
- Pattern répétitif que Michael applique sur ses sites
- Bonne pratique méconnue
- "Fais ça dès le jour 1" type contenu

**Structure mentale** :
1. Annoncer le conseil clairement
2. Expliquer pourquoi c'est crucial
3. Montrer comment l'appliquer (étapes)
4. Ancrer dans une preuve / cas concret

**Hooks associés** : typologies 5, 9.

**Exemples schoolsWP** :
- "Fais ça avant d'activer un plugin affilié dans FluentAffiliate"
- "Le réglage à activer dans Kadence Pro dès l'installation"
- "3 paramètres FlyingPress à cocher avant de parler de perf"

**Framework recommandé** : PSPC.

## Angle 3 — Méthode (système schoolsWP)

**Intention** : partager un système reproductible, positionner Michael comme auteur de méthode.

**Quand l'utiliser** :
- Tu as une routine / un workflow testé
- Tu veux montrer la pensée derrière une pratique
- Tu veux faire levier sur "la méthode schoolsWP"

**Structure mentale** :
1. Nommer la méthode (ex : "Ma méthode SEO en 4 étapes")
2. Contexte (pour qui, pour quoi)
3. Étapes numérotées, chacune justifiée
4. Résultat obtenu

**Hooks associés** : typologies 5, 9.

**Exemples schoolsWP** :
- "Ma méthode pour configurer FluentCRM en 20 minutes"
- "La méthode schoolsWP pour migrer Yoast → Rank Math sans perdre ton SEO"
- "Comment je lance un LMS sur WordPress en 4 étapes"

**Framework recommandé** : PSPC ou AIDA.

## Angle 4 — Comparatif utile

**Intention** : aider à choisir, capter l'audience en phase de décision.

**Quand l'utiliser** :
- Deux outils concurrents dans un même segment
- Choix classique dans l'écosystème WordPress (Kadence vs GeneratePress, Rank Math vs Yoast, FluentCRM vs Mailchimp…)
- Nouveau plugin vs référence établie

**Structure mentale** :
1. Annoncer le comparatif + contexte d'usage
2. 4 à 6 critères objectifs, verdict par critère
3. "Quand choisir A" / "Quand choisir B"
4. Mon verdict tranché (avec honnêteté sur les limites)

**Règle absolue schoolsWP** : jamais de "tous les deux sont bons, à toi de choisir". Tranche.

**Hooks associés** : typologie 7.

**Exemples schoolsWP** :
- "FluentCRM vs Mailchimp : mon choix pour 2026"
- "Kadence Pro vs GeneratePress : lequel choisir en 2026 ?"
- "Rank Math gratuit vs Rank Math Pro : ça vaut les 59 € ?"

**Framework recommandé** : PSPC (preuve = le verdict).

## Angle 5 — Opinion tranchée

**Intention** : affirmer une position, générer du débat en commentaires, faire émerger la voix schoolsWP.

**Quand l'utiliser** :
- Michael a changé d'avis sur un outil / pratique
- Une pratique populaire te semble fausse
- Un débat WordPress mérite d'être cadré

**Structure mentale** :
1. Affirmer la position (slide 1)
2. Expliquer d'où vient la position (contexte, déclic)
3. Preuve concrète
4. Nuance honnête — à qui ça ne convient **pas**
5. Question ouverte pour engager

**Hooks associés** : typologie 2.

**Exemples schoolsWP** :
- "Je n'utilise plus Zapier en 2026. Voici pourquoi."
- "Les thèmes premium ne servent plus à rien si tu as Kadence Pro."
- "Arrête de chercher LE meilleur plugin CRM. Cherche la bonne stack."

**Framework recommandé** : PAS.

## Angle 6 — Retour d'expérience chiffré

**Intention** : crédibilité maximale, preuve par l'usage.

**Quand l'utiliser** :
- Tu as testé un outil / une méthode sur une durée significative
- Tu as des chiffres réels (trafic, conversions, temps gagné)
- Tu as un "avant / après" documentable

**Structure mentale** :
1. Situation de départ
2. Décision / changement appliqué
3. Obstacle rencontré
4. Ce qui a débloqué
5. Chiffres avant / après
6. Leçon transférable

**Règle schoolsWP** : zéro chiffre fabriqué. Chaque chiffre doit être sourçable ou vérifié sur schoolswp.com.

**Hooks associés** : typologies 3, 6.

**Exemples schoolsWP** :
- "J'ai remplacé WP Rocket par FlyingPress. Voilà les 3 gains concrets."
- "6 mois avec OttoKit : ce qui a changé dans mon workflow"
- "Ce que m'a appris la migration de schoolswp.com vers Kadence Pro"

**Framework recommandé** : PSPC.

## Angle 7 — Idée reçue déconstruite

**Intention** : éducatif + autorité. Repositionner un sujet mal compris.

**Quand l'utiliser** :
- Une croyance répandue dans la communauté WordPress ou SEO qui est fausse / dépassée
- Un mythe créé par une vieille version d'un outil
- Un "tout le monde fait ça" qui n'a plus de sens

**Structure mentale** :
1. Nommer la croyance
2. D'où elle vient (grain de vérité historique)
3. Pourquoi elle est dépassée / fausse aujourd'hui
4. La réalité actuelle
5. Comment s'aligner dessus

**Hooks associés** : typologie 8.

**Exemples schoolsWP** :
- "Non, WordPress n'est pas lent par nature"
- "Les hashtags Instagram ne servent à rien ? Fake news."
- "'Il faut publier tous les jours' — pas sur schoolsWP"

**Framework recommandé** : PAS (agitation = l'impact de la croyance).

## Angle 8 — Tutoriel condensé (pédagogie express)

**Intention** : apporter de la valeur applicable immédiatement, maximiser les saves.

**Quand l'utiliser** :
- Une tâche qui prend normalement 1 heure peut se résumer en 5 slides
- Un setup d'outil simple à montrer
- Un micro-workflow à vulgariser

**Structure mentale** :
1. Promesse du résultat
2. Prérequis (1 phrase)
3. Étapes numérotées (1 par slide)
4. Résultat visuel / chiffre
5. CTA vers l'article complet

**Hooks associés** : typologie 9.

**Exemples schoolsWP** :
- "Installer FluentBooking en 5 étapes"
- "Activer le mode dark sur Kadence en 3 clics"
- "Configurer une automation FluentCRM en 4 slides"

**Framework recommandé** : PSPC.

## Angle 9 — Analyse produit schoolsWP

**Intention** : partager la stack réelle de schoolswp.com, créer de la préférence d'outils testés.

**Quand l'utiliser** :
- Plugin présent dans `schoolswp-agents/shared/SITE.md`
- Outil que Michael utilise au quotidien
- Nouveau plugin intégré récemment dans la stack

**Structure mentale** :
1. Pourquoi cet outil mérite un post
2. Ce qu'il fait (concrètement, pas la doc commerciale)
3. Ce qui le démarque des alternatives
4. Limites / cas où il ne convient pas
5. Place dans la stack schoolsWP

**Hooks associés** : typologies 3, 5, 6.

**Exemples schoolsWP** :
- "Pourquoi FluentSMTP remplace Postmark dans ma stack"
- "ClickWhale : pourquoi j'ai migré mes liens affiliés dessus"
- "FreshRank AI : ce que ce plugin fait mieux que Rank Math"

**Framework recommandé** : PSPC.

## Règles de combinaison

1. **Varie les angles** sur un même sujet — 3 idées de carrousels = 3 angles différents de préférence.
2. **Ancre dans la stack** : un angle qui ne peut s'ancrer sur aucun plugin/outil/article schoolsWP est probablement un angle trop générique.
3. **Évite les angles "top 10" vagues** — préfère toujours un angle spécifique ("les 3 plugins que j'ai désinstallés cette année" plutôt que "top 10 plugins WordPress").
4. **Angle + framework = fit**. Un angle opinion avec PSPC tombe à plat. Un tutoriel avec PAS est anxiogène. Vérifie la compatibilité dans `frameworks.md`.

---

## Anti-angles (à éviter)

- **Motivation / mindset générique** ("lève-toi tôt pour réussir")
- **Top 10 sans tri** ("top 10 plugins WordPress 2026")
- **Tendance générique** ("ce qu'il faut savoir sur l'IA en 2026")
- **Post inspirationnel vide** ("n'abandonne jamais")
- **Listicle sans preuve** ("5 outils IA pour créer du contenu") sauf si test réel

Règle finale : si l'angle ne peut s'ancrer dans une **expérience concrète, un outil testé ou un cas schoolswp.com**, il est trop générique.
