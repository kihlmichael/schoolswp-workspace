Ta tâche :
Rédige un script complet optimisé pour la rétention.

Le script doit respecter la promesse, la question ouverte et le payoff définis dans le concept précédent.

Structure obligatoire :
1. Hook dans les 8 premières secondes.
2. Mise en contexte rapide.
3. Développement en segments numérotés : SEG-01, SEG-02, SEG-03, etc.
4. Une interruption de motif toutes les 60 à 90 secondes, marquée ainsi :
   [INTERRUPTION DE MOTIF - description précise]
5. Points de contrôle de rétention à environ 30 %, 50 % et 70 % du script :
   [CHECKPOINT RÉTENTION 30 %]
   [CHECKPOINT RÉTENTION 50 %]
   [CHECKPOINT RÉTENTION 70 %]
6. Payoff final qui tient exactement la promesse du hook.
7. Conclusion avec appel à l’action naturel et non forcé.

Pour chaque segment, indique :
- ID du segment.
- Objectif narratif.
- Dialogue exact.
- Notes visuelles / édition.
- Opportunités de B-roll.
- Risque de rétention éventuel.
- Raison pour laquelle ce segment donne envie de continuer.

Format obligatoire :
Un tableau en deux colonnes principales :
- Colonne GAUCHE : ce que je dis.
- Colonne DROITE : notes visuelles, montage, rythme, B-roll potentiel.
