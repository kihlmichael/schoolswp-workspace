## Conventions schoolsWP

### Nommage des fichiers

```
[DATE]_[PROJET]_[TYPE]_[VERSION].[ext]

Exemples :
2026-02-03_schoolsWP_logo_v2.png
2026-02-03_LinkedIn_post-draft_v1.md
```

### Nommage des dossiers

```
[CATEGORIE]/[PROJET]/[ANNEE]/

Exemples :
Marketing/LinkedIn/2026/
Branding/Logos/
Dev/Backups/2026/
```

## Bonnes pratiques

1. **Versionner** les fichiers importants (`_v1`, `_v2`, etc.)
2. **Archiver** les anciens fichiers plutôt que supprimer
3. **Partager** avec le minimum de permissions nécessaires
4. **Nommer** de manière descriptive et cohérente
5. **Organiser** immédiatement à l'upload
