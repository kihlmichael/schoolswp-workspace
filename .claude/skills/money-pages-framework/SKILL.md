# Money Pages Framework — schoolsWP

Tu fournis le framework complet pour creer des Money Pages : SEO + intention + decision + affiliation. Style schoolsWP : clair, utile, honnete.

## Definition


Une Money Page est une page SEO qui :
- capte une intention de decision
- aide reellement a choisir
- contient plusieurs blocs decisionnels
- pousse naturellement vers un outil affilie

Exemples : avis plugin, comparatif, alternatives, meilleurs outils, prix.

## Regles de redaction

- Phrases courtes
- Bullets
- Zero blabla
- Si info manque : “Hypothese : …”

## Checklist (5 points)

1) Objectif defini en 1 phrase
2) Entrees clairement listees
3) Sorties obligatoires explicites
4) Exemple entree/sortie present
5) Actions suivantes listees

## Les 5 types de Money Pages


### 1) Avis complet
Exemples : FluentCRM avis, Tutor LMS avis, Amelia avis
Intent : evaluation
Structure :
- Intro probleme
- Presentation outil
- Fonctionnalites
- Pour qui c’est adapte
- Limites
- Comparatif rapide
- Verdict schoolsWP
- CTA affilie

### 2) Comparatif
Exemples : FluentCRM vs MailerLite, TutorLMS vs LearnDash, Amelia vs FluentBooking
Intent : choix
Structure :
- Intro du probleme
- Presentation des outils
- Comparatif tableau
- Avantages
- Limites
- Pour qui chaque outil est adapte
- Verdict selon profil
- CTA affilies

### 3) Alternatives
Exemples : alternatives a FluentCRM, alternatives a Mailchimp, alternatives a Elementor
Intent : comparative
Structure :
- Pourquoi chercher une alternative
- Presentation des outils
- Comparatif rapide
- Recommandation schoolsWP
- Verdict selon usage
- CTA affilie

### 4) Meilleurs outils
Exemples : meilleurs CRM WordPress, meilleurs LMS WordPress, meilleurs plugins booking
Intent : selection
Structure :
- Intro probleme
- Criteres de selection
- Top outils
- Mini fiches outils
- Comparatif
- Verdict selon profil
- CTA affilies

### 5) Prix
Exemples : FluentCRM prix, Tutor LMS prix, Amelia prix
Intent : achat
Structure :
- Combien coute l’outil
- Plans tarifaires
- Ce qui est inclus
- Pour qui chaque plan est adapte
- Est-ce rentable
- Verdict schoolsWP
- CTA affilie
