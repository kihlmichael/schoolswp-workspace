# schoolsWP Stack

Stack principale utilisee dans l ecosysteme schoolsWP.

---

# CMS

WordPress

Objectif:
flexibilite maximale et propriete totale du site.

---

# SEO

Rank Math Pro

Utilise pour:
- optimisation on-page
- schemas
- metadonnees
- sitemap
- analyse SEO.

---

# CRM et automatisation

FluentCRM

Utilise pour:
- segmentation
- sequences email
- scoring
- automatisation marketing.
---

# Formulaires

Fluent Forms

Utilise pour:
- formulaires avances
- collecte de leads
- integrations CRM.

---

# Reservation

FluentBooking

Utilise pour:
- prise de rendez-vous
- automatisation de rendez-vous.

---

# LMS

TutorLMS

Utilise pour:
- creation de formations
- gestion d etudiants
- monetisation de contenus educatifs.
---

# Collaboration

FluentBoards

Utilise pour:
- gestion de projet
- suivi de taches.

---

# Philosophie stack

La stack doit etre:
- simple
- coherente
- automatisable
- scalable.

Chaque outil doit contribuer a:
- l acquisition
- la conversion
- l automatisation
- la monetisation.
