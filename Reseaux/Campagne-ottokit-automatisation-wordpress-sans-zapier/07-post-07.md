## B. Contenu du post

### Intro contexte

OttoKit vs Zapier. La question que beaucoup de créateurs WordPress se posent.
Voici 4 critères factuels pour décider.

### Critère 1 — Prix

OttoKit : plan gratuit généreux, pro à partir de ~9 $/mois.
Zapier : gratuit très limité, Starter à ~29 $/mois, Professional à ~73 $/mois.

→ OttoKit gagne sur le prix, largement.

### Critère 2 — Intégration WordPress

OttoKit : plugin natif WordPress. S'intègre directement avec FluentCRM, Fluent Forms, WooCommerce, TutorLMS, LearnDash.
Zapier : connexion via API externe. Fonctionne bien mais ajoute une dépendance hors WordPress.

→ OttoKit gagne sur l'intégration WordPress.

### Critère 3 — Apps externes (hors WordPress)

OttoKit : connecte Notion, Slack, Gmail, Google Sheets via webhooks. Catalogue plus limité que Zapier.
Zapier : 6 000+ apps intégrées. Imbattable pour les connexions multi-SaaS.

→ Zapier gagne sur les apps externes.

### Critère 4 — Facilité de maintenance

OttoKit : logs dans WordPress, debug depuis le tableau de bord, mises à jour plugin standard.
Zapier : logs dans l'interface Zapier, débogage hors WordPress, dépendance à une plateforme externe.

→ OttoKit gagne sur la maintenance pour un créateur WordPress.

### Verdict final tranché

Pour un site WordPress actif (FluentCRM, Fluent Forms, WooCommerce, LMS) : OttoKit est le choix par défaut.
Pour un écosystème multi-SaaS (Notion + Airtable + Slack + CRM externe) : Zapier reste pertinent.
Les deux outils peuvent coexister — mais 80 % des créateurs WordPress n'ont besoin que d'OttoKit.
