## 8. NOTES DE PRODUCTION

### Audio
- **Voix** : micro-cravate ou micro canon. Voix claire, débit moyen (pas rapide). Articulation nette.
- **Musique** : instrumentale légère en fond (lo-fi clean ou piano + pads). Volume à -18 dB sous la voix. Optionnelle — le silence fonctionne aussi.
- **Effets sonores** : 1 whoosh léger sur les pattern interrupts (titres plein écran). 1 "pop" subtle sur l'apparition du bouton Subscribe. Rien de plus.

### Vidéo
- **Éclairage** : lumière naturelle + key light douce. Fond neutre clair ou légèrement texturé.
- **Cadrage facecam** : alterner plan serré (poitrine+) et plan moyen (buste). Jamais plus large.
- **Sous-titres** : toujours activés. Style : fond semi-transparent sombre, texte blanc, Roboto, 2 lignes max. Mots-clés en highlight jaune ou vert.
- **Rythme** : cuts toutes les 2–4 secondes. Aucun plan statique au-delà de 5 secondes.
- **Pattern interrupts** : 3 minimum (voir découpage : 0:15, 0:41, 1:02).

### Textes à l'écran
- **Police** : Nunito Sans bold pour les titres/overlays.
- **Couleurs** : texte blanc sur fond sombre, ou vert `#00D400` sur fond clair.
- **Animation** : fade-in rapide (0.3s) + léger slide-up. Pas d'effets tape-à-l'œil.
- **Durée** : chaque texte reste 2–4 secondes à l'écran.

### Post-production
- **Étalonnage** : léger, lumineux, contraste modéré. Pas de filtre lourd.
- **End screen YouTube** : activer les 20 dernières secondes pour le bouton Subscribe + vidéo suivante.
- **Thumbnail** : visage + texte court (3–5 mots) + couleur verte schoolsWP.
