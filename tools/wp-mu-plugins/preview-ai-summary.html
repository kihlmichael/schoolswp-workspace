Comportement au clic

Chaque bouton ouvre dans un nouvel onglet une URL du type :

  • ChatGPT : https://chatgpt.com/?q=Lis+cet+article+...
  • Perplexity : https://www.perplexity.ai/search?q=...
  • Claude : https://claude.ai/new?q=...
  • Mistral : https://chat.mistral.ai/chat?q=...
  • Grok : https://grok.com/?q=...

Le prompt envoyé (modifiable via le filtre WP swp_ai_summary_prompt) :

Lis cet article schoolsWP intitulé "[Titre]" puis donne-moi un résumé clair en 5 points clés, en français : [URL]

Détails techniques

  • Fond carte : dégradé #1e293b → #12111F + halo radial vert subtil en bas-droite.
  • Pills : fond blanc 5% + bordure blanche 10%, texte blanc.
  • Hover : fond vert rgba(0,212,0,.12), bordure verte, léger translateY(-1px), ombre verte douce.
  • Icône : monochrome blanc dans un cercle blanc 10%. Au hover : gradient vert schoolsWP avec icône sombre.
  • Liens : target="_blank" rel="noopener noreferrer nofollow".
  • Zéro JS, zéro fichier externe, zéro stockage post meta, zéro appel API.
