## Checklist rapide : "Où ranger mon fichier ?"

1. **C'est un template réutilisable ?** → `02_TEMPLATES/[sous-catégorie]/02_VALIDÉ` ou `03_LIVE`
2. **C'est un prompt one-shot daté ?** → `03_PROMPTS/[sous-catégorie]/03_LIVE`
3. **C'est un email/séquence liée à un lancement ?** → `05_MONETISATION/04_Sequences_Email`
4. **C'est un email/CRM template réutilisable ?** → `02_TEMPLATES/02_Email_CRM_FluentCRM`
5. **C'est un email/CRM prompt one-shot ?** → `03_PROMPTS/02_Email_CRM`
6. **C'est un asset visuel ?** → `04_ASSETS/[sous-catégorie]`
7. **C'est un brief ou plan éditorial ?** → `06_SCHOOLS_WP_EDITORIAL/[sous-catégorie]`
8. **C'est un SOP ou script d'automation ?** → `07_AUTOMATION/[sous-catégorie]`
9. **C'est obsolète ?** → `99_ARCHIVES`
10. **Tu hésites ?** → `01_ADMIN/02_Checklists-Qualite` et demander validation
