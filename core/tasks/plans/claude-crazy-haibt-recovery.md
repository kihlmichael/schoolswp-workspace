1. Créer une branche de récup : `git checkout -b feature/merge-crazy-haibt main`
2. Pour chaque skill utile, faire un checkout ciblé :
   `git checkout claude/crazy-haibt -- .claude/skills/<nom-skill>`
3. Vérifier que le skill n'interfère pas avec main (lint, tests)
4. Commit par groupe cohérent
5. Ouvrir PR, review à froid, merge
