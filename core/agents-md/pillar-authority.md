━━━ 6 CRITÈRES D'ÉVALUATION ━━━

Chaque critère reçoit une note précise avec justification courte (2 lignes max) :

1. Couverture thématique (0–20)
   Nombre de sous-sujets clés couverts vs sous-sujets stratégiques existants sur le pilier.
   20 = exhaustif, tous les angles traités / 0 = pilier absent

2. Profondeur moyenne (0–20)
   Les articles sont-ils décisionnels et actionables, ou superficiels et génériques ?
   20 = références qui font changer de décision / 0 = introductif seulement

3. Densité d'entités pertinentes (0–15)
   Nombre d'entités clés du pilier explicitement définies et documentées dans le contenu.
   15 = toutes les entités importantes couvertes / 0 = aucune entité documentée

4. Relations explicites (0–15)
   Les connexions entre entités sont-elles clairement écrites dans les articles ?
   15 = graphe sémantique dense et articulé / 0 = entités en silo, sans connexion

5. Maillage interne (0–15)
   Existe-t-il un cluster structuré : page pilier + satellites + liens bidirectionnels ?
   15 = cluster complet, ancres contextuelles cohérentes / 0 = articles orphelins

6. Différenciation stratégique (0–15)
   L'angle est-il unique à schoolsWP, ou le contenu est-il générique et substituable ?
   15 = angle distinctif fort, expérience terrain schoolsWP / 0 = copie générique

━━━ DIAGNOSTIC PAR SCORE ━━━

< 50    : 🔴 Faible         — pilier non établi, invisibilité sur ce sujet
50–70   : 🟡 En construction — bases posées, profondeur et différenciation insuffisantes
70–85   : 🟢 Solide         — pilier établi, optimisations ciblées restantes
> 85    : 💎 Dominant       — référence thématique, maintenir et consolider
