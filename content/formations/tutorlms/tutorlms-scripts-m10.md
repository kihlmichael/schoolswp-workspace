### Lecon 10.1 — Reglages certificats

**Duree** : 6 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast du panneau Certificate
**Source** : Video #10 + doc settings/certificate

---

**[INTRO — face camera]**

Tes eleves terminent un cours — et apres ? Un certificat, c'est la preuve tangible qu'ils ont appris quelque chose. Ca motive, ca valorise, et ca donne envie de continuer. TutorLMS propose deux systemes de certificats : le mode legacy integre et le Certificate Builder pour des designs sur mesure. Dans cette lecon, on configure les reglages de base.

**[ECRAN — screencast WordPress admin]**

[Navigation vers Tutor LMS Pro > Add-ons]

Premiere etape : activer l'addon Certificate. Va dans Tutor LMS Pro, puis Add-ons. Cherche "Certificate" dans la liste et active-le. Sans cette activation, aucun reglage de certificat n'apparait.

**[ECRAN — screencast Settings > Certificate]**

[Vue du panneau Certificate Settings]

Maintenant, va dans Tutor LMS Pro, Settings, puis l'onglet Certificate. Tu arrives sur le panneau de configuration. Il y a deux parties : les reglages du Certificate Builder en haut, et les reglages legacy en bas.

**[ECRAN — screencast Certificate Builder Options]**

[Montre le toggle "Allow Instructors to Use Admin Templates"]

En haut, tu as une option importante : "Allow Instructors to Use Admin Templates". Si tu l'actives, tes instructeurs pourront utiliser les templates de certificats que toi, en tant qu'admin, tu as crees. Si tu la desactives, chaque instructeur devra creer ses propres designs. Pour un site ou tu veux garder une identite visuelle coherente, je te recommande de l'activer.

**[ECRAN — screencast Legacy Certificate]**

[Montre les champs legacy : Authorized Name, Company Name, etc.]

En dessous, les reglages legacy. Meme si tu comptes utiliser le Certificate Builder — et c'est ce que je recommande — ces champs servent de fallback :

- Authorized Name — le nom de la personne qui delivre le certificat
- Authorized Company Name — le nom de ton organisme ou de ton site
- Certificate Page — la page WordPress dediee aux certificats
- Show Instructor Name — affiche ou masque le nom de l'instructeur sur le certificat
- Certificate Link in Course Completion Email — ajoute automatiquement le lien vers le certificat dans l'email de fin de cours
- Upload Signature — pour ajouter l'image de ta signature manuscrite

**[ECRAN — screencast upload signature]**

[Montre le champ d'upload de signature]

Pour la signature, prepare une image PNG avec fond transparent. Ca rendra beaucoup mieux sur le certificat final.

**[ECRAN — screencast onglet All Certificates]**

[Montre la liste des certificats]

Dernier onglet : "All Certificates". C'est ici que tu retrouves tous les certificats crees avec le Certificate Builder. Tu peux changer leur statut entre Published et Draft, les modifier ou les supprimer.

**[TRANSITION — face camera]**

Les reglages sont en place. Mais le vrai potentiel, c'est le Certificate Builder. Un editeur visuel drag-and-drop qui te permet de creer des certificats PDF professionnels. On l'installe dans la prochaine lecon.

---

**Points cles** :
- Addon Certificate a activer dans Tutor LMS Pro > Add-ons
- Option "Allow Instructors to Use Admin Templates" pour controler l'acces
- Reglages legacy : nom autorise, entreprise, page, signature
- Lien certificat possible dans l'email de completion
- Signature en PNG fond transparent recommandee

**Mots cles SEO** : TutorLMS certificat, reglages certificat TutorLMS, certificat LMS WordPress, configurer certificat cours en ligne

Le Certificate Builder est un plugin separe de TutorLMS. Il te faut une licence Tutor LMS Pro pour y acceder. Dans cette lecon, on le telecharge, on l'installe, et on verifie que tout fonctionne.

**[ECRAN — screencast WordPress admin]**

[Navigation vers Plugins > Add New > Upload Plugin]

**[ECRAN — screencast activation plugin]**

[Montre le bouton Activate Plugin]

[Navigation vers la liste des add-ons, montre Certificate]

Etape 4 : va dans Tutor LMS Pro, Add-ons, et verifie que l'addon "Certificate" est bien active. Si ce n'est pas le cas, active-le. C'est cet addon qui fait le lien entre le Certificate Builder et TutorLMS.

**[ECRAN — screencast menu TutorLMS]**

[Montre le nouveau menu "Certificate Builder" dans le menu TutorLMS]

Verification : regarde le menu lateral de Tutor LMS. Un nouveau sous-menu "Certificate Builder" devrait apparaitre. Si tu le vois, l'installation est reussie.

**[ECRAN — screencast Settings > Certificate]**

[Montre le bouton "Create Certificate"]

Tu peux aussi verifier depuis Settings, Certificate. Le bouton "Create Certificate" doit etre present en haut de la page. C'est ce bouton qui lance l'editeur visuel.

**[TRANSITION — face camera]**

Le Certificate Builder est pret. Dans la prochaine lecon, on explore les templates disponibles et les elements que tu peux utiliser pour designer tes certificats.

---

**Points cles** :
- Licence Tutor LMS Pro requise
- Telechargement depuis tutorlms.com/account/downloads/
- Installation classique : upload ZIP + activation
- Activer l'addon Certificate dans Tutor LMS Pro > Add-ons
- Verification : menu "Certificate Builder" visible dans TutorLMS

### Lecon 10.3 — Certificate Builder : Templates & Elements

**Duree** : 7 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast du Certificate Builder
**Source** : doc certificate-builder/templates + elements

---

**[INTRO — face camera]**

Le Certificate Builder propose plus de 25 templates pre-construits et une dizaine d'elements dynamiques. Avant de se lancer dans le design, on fait le tour de ce qui est disponible. Ca t'evitera de tout construire a la main quand un template fait deja 80% du travail.

**[ECRAN — screencast Certificate Builder]**

[Clic sur "Create Certificate" depuis Settings > Certificate]

Quand tu cliques sur "Create Certificate", un ecran te propose deux options : partir d'un template existant ou commencer avec un canvas vierge. On va d'abord explorer les templates.

**[ECRAN — screencast selection de template]**

[Navigation dans les categories de templates]

Les templates sont organises en sept categories :

1. Professional — pour les formations corporate, certifications metier
2. Creatives — designs modernes, colores
3. Kids — adapte aux plateformes d'apprentissage pour enfants
4. Achievement — style recompense, badges
5. Minimal — epure, sobre
6. Musical — pour les ecoles de musique
7. University — style academique, formel

Chaque template existe en format paysage et portrait. Pour un cours en ligne classique, les categories Professional ou Minimal sont les plus polyvalentes.

**[ECRAN — screencast survol d'un template]**

[Montre le hover sur un template avec le bouton "Use This Template"]

Pour utiliser un template, survole-le et clique sur "Use This Template". Ca ouvre l'editeur avec le design pre-rempli. Tous les elements sont modifiables — couleurs, textes, positions, tailles.

**[ECRAN — screencast panneau Elements]**

[Montre l'onglet Elements dans le sidebar gauche]

Passons aux elements. Dans le panneau de gauche, l'onglet Elements te donne acces a tout ce que tu peux placer sur ton certificat. Il y a deux types : les elements dynamiques et les elements statiques.

**[ECRAN — screencast elements dynamiques]**

[Montre chaque element dynamique en le survolant]

Les elements dynamiques se remplissent automatiquement avec les donnees du cours et de l'eleve :

- Student Name — le nom de l'eleve qui recoit le certificat
- Course — le titre du cours complete
- Instructor — le nom de l'instructeur
- Grade — la note obtenue (necessite l'addon Gradebook)
- Point — les points accumules (necessite aussi Gradebook)
- Verification ID — un identifiant unique pour verifier l'authenticite
- Time — la date et l'heure de generation du certificat
- Duration — la duree du cours

C'est la ou le Certificate Builder prend tout son sens : tu places ces elements une fois, et chaque certificat genere sera personnalise automatiquement.

**[ECRAN — screencast elements statiques]**

[Montre Text, Signature, QR Code]

Les elements statiques, c'est toi qui les remplis :

- Text — pour ajouter du texte libre : titre du certificat, description, mentions legales. Tu peux personnaliser la police, la taille, l'epaisseur, l'espacement
- Signature — pour uploader une image de signature
- QR Code — genere automatiquement un QR code qui renvoie vers l'URL de verification du certificat

**[ECRAN — screencast onglets Media, Library, Backdrops]**

[Survol rapide des trois onglets]

Trois autres onglets completent les elements :

- Media — upload tes propres images, logos, ou pioche dans la bibliotheque Unsplash
- Library — formes, illustrations, badges, bordures, cadres et filigranes pre-faits
- Backdrops — couleurs de fond et motifs d'arriere-plan

**[ECRAN — screencast panneau Layers]**

[Montre le panneau de gestion des calques]

Dernier outil : le panneau Layers. Il te permet de gerer l'ordre d'empilement de tes elements. Tu peux monter ou descendre un element, le verrouiller, le masquer. Comme dans n'importe quel outil de design.

**[TRANSITION — face camera]**

Tu connais maintenant tout le materiel disponible. Dans la prochaine lecon, on passe a la pratique : on part d'un template et on cree un certificat complet, etape par etape.

---

**Points cles** :
- 25+ templates en 7 categories (Professional, Creatives, Kids, Achievement, Minimal, Musical, University)
- Formats paysage et portrait disponibles
- 8 elements dynamiques : Student Name, Course, Instructor, Grade, Point, Verification ID, Time, Duration
- 3 elements statiques : Text, Signature, QR Code
- Onglets supplementaires : Media (Unsplash), Library (formes/badges), Backdrops (fonds)
- Panneau Layers pour gerer l'empilement

**Mots cles SEO** : TutorLMS Certificate Builder templates, elements certificat TutorLMS, design certificat LMS, placeholder dynamique certificat

### Lecon 10.4 — Certificate Builder : Design complet

**Duree** : 7 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast design dans le builder
**Source** : doc certificate-builder/designing-with-a-template

---

**[INTRO — face camera]**

Theorie terminee. On passe a la pratique. Dans cette lecon, on part d'un template Professional, on le personnalise avec les couleurs schoolsWP, on ajoute les elements dynamiques, et on obtient un certificat pret a etre assigne a un cours.

**[ECRAN — screencast Certificate Builder]**

[Clic sur "Create Certificate" depuis Settings > Certificate]

Depuis Settings, Certificate, clique sur "Create Certificate". L'ecran de selection des templates s'affiche.

**[ECRAN — screencast choix du template]**

[Filtre categorie "Professional", survol des templates, clic "Use This Template"]

Etape 1 : selectionne la categorie Professional. Parcours les options. Choisis celui qui se rapproche le plus de ce que tu veux — on va tout personnaliser de toute facon. Survole-le et clique sur "Use This Template".

**[ECRAN — screencast editeur ouvert avec template]**

[Vue de l'editeur avec le template charge]

L'editeur s'ouvre avec le template pre-rempli. Avant de modifier quoi que ce soit, choisis le format du certificat.

**[ECRAN — screencast Settings > Choose Size]**

[Montre le panneau Settings dans le sidebar, section "Choose Size"]

Etape 2 : dans le panneau gauche, va dans Settings, puis "Choose Size". Deux options :

- Letter — 1139 x 880 pixels, format US/Canada
- A4 — 1245 x 880 pixels, format international

Pour un public francophone, choisis A4. Enregistre pour appliquer.

**[ECRAN — screencast modification du backdrop]**

[Clic sur l'onglet Backdrops, changement de couleur de fond]

Etape 3 : personnalise l'arriere-plan. Va dans l'onglet Backdrops. Tu peux choisir une couleur unie depuis la palette, ou uploader ta propre image de fond. Si tu as une charte graphique, c'est le moment de l'appliquer.

**[ECRAN — screencast ajout/modification d'elements texte]**

[Clic sur un element texte existant, modification du contenu et du style]

Etape 4 : modifie les textes. Clique sur n'importe quel element texte du template pour le selectionner. Tu peux changer :

- Le contenu — remplace par ton propre titre, par exemple "Certificat de reussite"
- La police et la taille
- L'epaisseur — regular, bold, semi-bold
- L'espacement entre les lettres et la hauteur de ligne
- La couleur du texte

Positionne chaque texte en le glissant directement sur le canvas.

**[ECRAN — screencast ajout elements dynamiques]**

[Drag-and-drop de Student Name, Course, Instructor, Time depuis le panneau Elements]

Etape 5 : ajoute les elements dynamiques. Depuis l'onglet Elements, glisse "Student Name" sur le certificat. Place-le la ou tu veux que le nom de l'eleve apparaisse. Fais pareil pour :

- Course — le titre du cours
- Instructor — ton nom ou celui de l'instructeur
- Time — la date de delivrance

Chaque element dynamique est stylable comme du texte normal : police, taille, couleur. Sur le canvas, tu vois un texte de demonstration. Dans le certificat final, il sera remplace par les vraies donnees.

**[ECRAN — screencast ajout logo via Media]**

[Onglet Media, upload d'un logo, placement sur le certificat]

Etape 6 : ajoute ton logo. Va dans l'onglet Media, uploade ton logo, puis clique dessus pour le placer. Tu peux ajuster la position, la taille et meme la transparence.

**[ECRAN — screencast ajout signature]**

[Drag-and-drop de l'element Signature, upload de l'image]

Etape 7 : ajoute la signature. Depuis l'onglet Elements, glisse "Signature" sur le certificat. Uploade ton image de signature — rappel : PNG avec fond transparent pour un rendu propre.

**[ECRAN — screencast QR Code]**

[Ajout de l'element QR Code]

Etape 8 : optionnel mais recommande — ajoute un QR Code. Il sera genere automatiquement et permettra a quiconque scanne le certificat de verifier son authenticite en ligne.

**[ECRAN — screencast gestion des calques]**

[Montre le panneau Layers, reordonne quelques elements]

Etape 9 : verifie l'ordre des calques. Si un element est cache derriere un autre, utilise le panneau Layers pour le remonter. Tu peux aussi verrouiller les elements que tu ne veux plus deplacer par erreur.

**[ECRAN — screencast bouton Publish]**

[Clic sur Publish en haut de l'editeur]

Etape 10 : quand tu es satisfait, clique sur "Publish" en haut a droite. Le certificat est maintenant disponible pour etre assigne a un cours.

**[TRANSITION — face camera]**

Ton certificat est cree et publie. Il ne manque plus qu'une chose : l'associer a un cours pour que tes eleves le recoivent automatiquement a la fin de leur formation. C'est ce qu'on fait dans la derniere lecon du module.

---

**Points cles** :
- Workflow : template > format (A4/Letter) > backdrop > textes > elements dynamiques > logo > signature > QR code > publish
- Format A4 (1245x880 px) recommande pour public francophone
- Elements dynamiques stylables comme du texte (police, taille, couleur)
- Signature en PNG fond transparent
- QR Code pour verification d'authenticite
- Panneau Layers pour gerer l'empilement et verrouiller les elements

**Mots cles SEO** : creer certificat TutorLMS, designer certificat LMS WordPress, Certificate Builder template, certificat PDF personnalise TutorLMS

### Lecon 10.5 — Ajouter un certificat a un cours

**Duree** : 5 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast Course Builder
**Source** : doc certificate-builder/add-certificate-to-a-course

---

**[INTRO — face camera]**

Tu as un certificat publie. Maintenant, il faut l'associer a un cours pour que tes eleves le recoivent quand ils terminent la formation. C'est rapide — on le fait depuis l'editeur de cours.

**[ECRAN — screencast WordPress frontend]**

[Navigation vers un cours existant, clic sur Edit]

Va sur ton site en frontend et ouvre le cours auquel tu veux ajouter le certificat. Clique sur "Edit" pour ouvrir le Course Builder.

**[ECRAN — screencast Course Builder]**

[Scroll vers la section "Certificate Template"]

Etape 1 : dans l'editeur de cours, cherche la section "Certificate Template". Elle se trouve dans les options du cours, generalement apres les reglages de contenu.

**[ECRAN — screencast selection du certificat]**

[Montre le dropdown avec les certificats disponibles]

Etape 2 : clique sur le menu deroulant. Tu vois la liste de tous les certificats publies — ceux que tu as crees dans le Certificate Builder. Selectionne celui que tu veux assigner a ce cours.

**[ECRAN — screencast publication du cours]**

[Clic sur "Publish Course" ou "Update Course"]

Etape 3 : enregistre le cours en cliquant sur "Publish Course" ou "Update Course" si le cours est deja publie. C'est fait. Le certificat est maintenant lie a ce cours.

**[ECRAN — screencast cote eleve]**

[Vue eleve : cours termine, bouton "Get Certificate" visible]

Maintenant, voyons ce que l'eleve voit. Quand un etudiant termine tous les contenus du cours, un bouton "Get Certificate" apparait sur la page d'accueil du cours.

**[ECRAN — screencast telechargement certificat]**

[Clic sur "Get Certificate", montre les options]

En cliquant dessus, l'eleve accede a son certificat avec plusieurs options :

- Apercu du certificat avec ses informations personnalisees
- Telechargement en JPG ou PDF
- Impression au format A4
- Partage direct sur Facebook, X (anciennement Twitter) ou LinkedIn

Le PDF est genere a la volee avec toutes les donnees dynamiques : nom de l'eleve, titre du cours, nom de l'instructeur, date. Exactement ce qu'on a configure dans le builder.

**[ECRAN — screencast Settings > Certificate > Legacy]**

[Montre l'option "Certificate Link in Course Completion Email"]

Un detail a ne pas oublier : retourne dans Settings, Certificate, et verifie que l'option "Certificate Link in Course Completion Email" est activee. Ca ajoute automatiquement le lien vers le certificat dans l'email de fin de cours. Ton eleve recoit l'email, clique, telecharge. Pas besoin de chercher.

**[ECRAN — screencast partage LinkedIn]**

[Montre le bouton de partage LinkedIn sur le certificat]

Le partage LinkedIn est particulierement utile. Quand ton eleve partage son certificat, ca cree de la visibilite pour ta formation. C'est de la preuve sociale gratuite.

**[TRANSITION — face camera]**

Voila, ton systeme de certificats est operationnel. Tu as configure les reglages, installe le Certificate Builder, cree un design personnalise, et assigne le certificat a un cours. Tes eleves recoivent maintenant une preuve concrete de leur reussite — et ils peuvent la partager en ligne. Dans le quiz suivant, on verifie que tu maitrises tout ca.

---

**Points cles** :
- Assignation depuis le Course Builder frontend > section "Certificate Template"
- Un certificat publie peut etre assigne a plusieurs cours
- Eleve : bouton "Get Certificate" apres completion du cours
- Formats disponibles : JPG, PDF, impression A4
- Partage social : Facebook, X, LinkedIn
- Activer "Certificate Link in Course Completion Email" pour l'envoi automatique

**Mots cles SEO** : ajouter certificat cours TutorLMS, assigner certificat TutorLMS, certificat completion cours LMS, telecharger certificat TutorLMS

**Question 1**

Ou active-t-on l'addon Certificate dans TutorLMS ?

- A) Tutor LMS > Settings > General
- B) Tutor LMS Pro > Add-ons
- C) Plugins > Add New
- D) Tutor LMS > Certificates

**Reponse** : B

**Explication** : L'addon Certificate s'active depuis la page Tutor LMS Pro > Add-ons, independamment de l'installation du plugin Certificate Builder.

---

**Question 2**

Que faut-il pour telecharger le Certificate Builder ?

- A) Un compte WordPress.org gratuit
- B) Le plugin Tutor LMS gratuit
- C) Une licence Tutor LMS Pro
- D) Le plugin WooCommerce

**Reponse** : C

**Explication** : Le Certificate Builder est un plugin exclusif reserve aux utilisateurs ayant une licence Tutor LMS Pro valide. Il se telecharge depuis tutorlms.com/account/downloads/.

---

**Question 3**

Combien de categories de templates sont disponibles dans le Certificate Builder ?

- A) 3
- B) 5
- C) 7
- D) 10

**Reponse** : C

**Explication** : Il y a 7 categories : Professional, Creatives, Kids, Achievement, Minimal, Musical et University.

---

**Question 4**

Quel element dynamique necessite l'addon Gradebook pour fonctionner ?

- A) Student Name
- B) Verification ID
- C) Grade
- D) Time

**Reponse** : C

**Explication** : Les elements Grade et Point necessitent l'addon Gradebook pour afficher les notes et points de l'eleve sur le certificat.

---

**Question 5**

Quel format de certificat est recommande pour un public francophone ?

- A) Letter (1139x880 px)
- B) A4 (1245x880 px)
- C) A3 (1754x1240 px)
- D) Custom (taille libre)

**Reponse** : B

**Explication** : Le format A4 (1245x880 pixels) est le standard international, utilise en France et dans la plupart des pays francophones.

---

**Question 6**

Depuis ou assigne-t-on un certificat a un cours ?

- A) Tutor LMS > Settings > Certificate
- B) Le Certificate Builder
- C) Le Course Builder frontend, section "Certificate Template"
- D) Tutor LMS > Add-ons > Certificate

**Reponse** : C

**Explication** : L'assignation se fait depuis le Course Builder en frontend, dans la section "Certificate Template", en selectionnant un certificat publie dans le menu deroulant.

---

**Question 7**

Quels formats de telechargement sont proposes a l'eleve pour son certificat ?

- A) PNG et SVG
- B) JPG et PDF
- C) PDF uniquement
- D) JPG, PNG et PDF

**Reponse** : B

**Explication** : L'eleve peut telecharger son certificat en JPG ou PDF, l'imprimer en A4, ou le partager sur les reseaux sociaux.

---

**Question 8**

Quel element du Certificate Builder genere automatiquement un code scannable renvoyant vers l'URL de verification ?

- A) Verification ID
- B) Signature
- C) QR Code
- D) Time

**Reponse** : C

**Explication** : L'element QR Code genere automatiquement un code QR scannable qui renvoie vers l'URL de verification du certificat, permettant d'en confirmer l'authenticite.
