### Leçon 10.1 — Réglages certificats

**Durée** : 6 min
**Type** : Vidéo HeyGen
**Écran** : Face caméra pour intro/conclusion, screencast du panneau Certificate
**Source** : Vidéo #10 + doc settings/certificate

---

**[INTRO — face caméra]**

Tes élèves terminent un cours — et après ? Un certificat, c'est la preuve tangible qu'ils ont appris quelque chose. Ça motive, ça valorise, et ça donne envie de continuer. TutorLMS propose deux systèmes de certificats : le mode legacy intégré et le Certificate Builder pour des designs sur mesure. Dans cette leçon, on configure les réglages de base.

**[ÉCRAN — screencast WordPress admin]**

[Navigation vers Tutor LMS Pro > Add-ons]

Première étape : activer l'addon Certificate. Va dans Tutor LMS Pro, puis Add-ons. Cherche "Certificate" dans la liste et active-le. Sans cette activation, aucun réglage de certificat n'apparaît.

**[ÉCRAN — screencast Settings > Certificate]**

[Vue du panneau Certificate Settings]

Maintenant, va dans Tutor LMS Pro, Settings, puis l'onglet Certificate. Tu arrives sur le panneau de configuration. Il y a deux parties : les réglages du Certificate Builder en haut, et les réglages legacy en bas.

**[ÉCRAN — screencast Certificate Builder Options]**

[Montre le toggle "Allow Instructors to Use Admin Templates"]

En haut, tu as une option importante : "Allow Instructors to Use Admin Templates". Si tu l'actives, tes instructeurs pourront utiliser les templates de certificats que toi, en tant qu'admin, tu as créés. Si tu la désactives, chaque instructeur devra créer ses propres designs. Pour un site où tu veux garder une identité visuelle cohérente, je te recommande de l'activer.

**[ÉCRAN — screencast Legacy Certificate]**

[Montre les champs legacy : Authorized Name, Company Name, etc.]

En dessous, les réglages legacy. Même si tu comptes utiliser le Certificate Builder — et c'est ce que je recommande — ces champs servent de fallback :

- Authorized Name — le nom de la personne qui délivre le certificat
- Authorized Company Name — le nom de ton organisme ou de ton site
- Certificate Page — la page WordPress dédiée aux certificats
- Show Instructor Name — affiche ou masque le nom de l'instructeur sur le certificat
- Certificate Link in Course Completion Email — ajoute automatiquement le lien vers le certificat dans l'email de fin de cours
- Upload Signature — pour ajouter l'image de ta signature manuscrite

**[ÉCRAN — screencast upload signature]**

[Montre le champ d'upload de signature]

Pour la signature, prépare une image PNG avec fond transparent. Ça rendra beaucoup mieux sur le certificat final.

**[ÉCRAN — screencast onglet All Certificates]**

[Montre la liste des certificats]

Dernier onglet : "All Certificates". C'est ici que tu retrouves tous les certificats créés avec le Certificate Builder. Tu peux changer leur statut entre Published et Draft, les modifier ou les supprimer.

**[TRANSITION — face caméra]**

Les réglages sont en place. Mais le vrai potentiel, c'est le Certificate Builder. Un éditeur visuel drag-and-drop qui te permet de créer des certificats PDF professionnels. On l'installe dans la prochaine leçon.

---

**Points clés** :
- Addon Certificate à activer dans Tutor LMS Pro > Add-ons
- Option "Allow Instructors to Use Admin Templates" pour contrôler l'accès
- Réglages legacy : nom autorisé, entreprise, page, signature
- Lien certificat possible dans l'email de complétion
- Signature en PNG fond transparent recommandée

**Mots clés SEO** : TutorLMS certificat, réglages certificat TutorLMS, certificat LMS WordPress, configurer certificat cours en ligne

### Leçon 10.2 — Certificate Builder : Installation

**Durée** : 5 min
**Type** : Vidéo HeyGen
**Écran** : Face caméra pour intro/conclusion, screencast installation plugin
**Source** : doc certificate-builder/installation

---

**[INTRO — face caméra]**

Le Certificate Builder est un plugin séparé de TutorLMS. Il te faut une licence Tutor LMS Pro pour y accéder. Dans cette leçon, on le télécharge, on l'installe, et on vérifie que tout fonctionne.

**[ÉCRAN — screencast navigateur]**

[Navigation vers tutorlms.com/account/downloads/]

Étape 1 : connecte-toi à ton compte sur tutorlms.com, puis va dans Account, Downloads. Tu devrais voir le plugin "Tutor LMS Certificate Builder" dans la liste de tes téléchargements. Clique sur Download pour récupérer le fichier ZIP.

**[ÉCRAN — screencast WordPress admin]**

[Navigation vers Plugins > Add New > Upload Plugin]

Étape 2 : retour dans ton WordPress. Va dans Plugins, Ajouter, puis clique sur "Upload Plugin" en haut. Sélectionne le fichier ZIP que tu viens de télécharger, puis clique sur "Install Now".

**[ÉCRAN — screencast activation plugin]**

[Montre le bouton Activate Plugin]

Étape 3 : une fois l'installation terminée, clique sur "Activate Plugin". Le plugin est maintenant installé, mais il reste une dernière étape.

**[ÉCRAN — screencast Tutor LMS Pro > Add-ons]**

[Navigation vers la liste des add-ons, montre Certificate]

Étape 4 : va dans Tutor LMS Pro, Add-ons, et vérifie que l'addon "Certificate" est bien activé. Si ce n'est pas le cas, active-le. C'est cet addon qui fait le lien entre le Certificate Builder et TutorLMS.

**[ÉCRAN — screencast menu TutorLMS]**

[Montre le nouveau menu "Certificate Builder" dans le menu TutorLMS]

Vérification : regarde le menu latéral de Tutor LMS. Un nouveau sous-menu "Certificate Builder" devrait apparaître. Si tu le vois, l'installation est réussie.

**[ÉCRAN — screencast Settings > Certificate]**

[Montre le bouton "Create Certificate"]

Tu peux aussi vérifier depuis Settings, Certificate. Le bouton "Create Certificate" doit être présent en haut de la page. C'est ce bouton qui lance l'éditeur visuel.

**[TRANSITION — face caméra]**

Le Certificate Builder est prêt. Dans la prochaine leçon, on explore les templates disponibles et les éléments que tu peux utiliser pour designer tes certificats.

---

**Points clés** :
- Licence Tutor LMS Pro requise
- Téléchargement depuis tutorlms.com/account/downloads/
- Installation classique : upload ZIP + activation
- Activer l'addon Certificate dans Tutor LMS Pro > Add-ons
- Vérification : menu "Certificate Builder" visible dans TutorLMS

**Mots clés SEO** : installer Certificate Builder TutorLMS, plugin certificat TutorLMS, TutorLMS Pro addon certificat

### Leçon 10.3 — Certificate Builder : Templates & Elements

**Durée** : 7 min
**Type** : Vidéo HeyGen
**Écran** : Face caméra pour intro/conclusion, screencast du Certificate Builder
**Source** : doc certificate-builder/templates + elements

---

**[INTRO — face caméra]**

Le Certificate Builder propose plus de 25 templates pré-construits et une dizaine d'éléments dynamiques. Avant de se lancer dans le design, on fait le tour de ce qui est disponible. Ça t'évitera de tout construire à la main quand un template fait déjà 80% du travail.

**[ÉCRAN — screencast Certificate Builder]**

[Clic sur "Create Certificate" depuis Settings > Certificate]

Quand tu cliques sur "Create Certificate", un écran te propose deux options : partir d'un template existant ou commencer avec un canvas vierge. On va d'abord explorer les templates.

**[ÉCRAN — screencast sélection de template]**

[Navigation dans les catégories de templates]

Les templates sont organisés en sept catégories :

1. Professional — pour les formations corporate, certifications métier
2. Creatives — designs modernes, colorés
3. Kids — adapté aux plateformes d'apprentissage pour enfants
4. Achievement — style récompense, badges
5. Minimal — épuré, sobre
6. Musical — pour les écoles de musique
7. University — style académique, formel

Chaque template existe en format paysage et portrait. Pour un cours en ligne classique, les catégories Professional ou Minimal sont les plus polyvalentes.

**[ÉCRAN — screencast survol d'un template]**

[Montre le hover sur un template avec le bouton "Use This Template"]

Pour utiliser un template, survole-le et clique sur "Use This Template". Ça ouvre l'éditeur avec le design pré-rempli. Tous les éléments sont modifiables — couleurs, textes, positions, tailles.

**[ÉCRAN — screencast panneau Elements]**

[Montre l'onglet Elements dans le sidebar gauche]

Passons aux éléments. Dans le panneau de gauche, l'onglet Elements te donne accès à tout ce que tu peux placer sur ton certificat. Il y a deux types : les éléments dynamiques et les éléments statiques.

**[ÉCRAN — screencast éléments dynamiques]**

[Montre chaque élément dynamique en le survolant]

Les éléments dynamiques se remplissent automatiquement avec les données du cours et de l'élève :

- Student Name — le nom de l'élève qui reçoit le certificat
- Course — le titre du cours complété
- Instructor — le nom de l'instructeur
- Grade — la note obtenue (nécessite l'addon Gradebook)
- Point — les points accumulés (nécessite aussi Gradebook)
- Verification ID — un identifiant unique pour vérifier l'authenticité
- Time — la date et l'heure de génération du certificat
- Duration — la durée du cours

C'est là où le Certificate Builder prend tout son sens : tu places ces éléments une fois, et chaque certificat généré sera personnalisé automatiquement.

**[ÉCRAN — screencast éléments statiques]**

[Montre Text, Signature, QR Code]

Les éléments statiques, c'est toi qui les remplis :

- Text — pour ajouter du texte libre : titre du certificat, description, mentions légales. Tu peux personnaliser la police, la taille, l'épaisseur, l'espacement
- Signature — pour uploader une image de signature
- QR Code — génère automatiquement un QR code qui renvoie vers l'URL de vérification du certificat

**[ÉCRAN — screencast onglets Media, Library, Backdrops]**

[Survol rapide des trois onglets]

Trois autres onglets complètent les éléments :

- Media — upload tes propres images, logos, ou pioche dans la bibliothèque Unsplash
- Library — formes, illustrations, badges, bordures, cadres et filigranes pré-faits
- Backdrops — couleurs de fond et motifs d'arrière-plan

**[ÉCRAN — screencast panneau Layers]**

[Montre le panneau de gestion des calques]

Dernier outil : le panneau Layers. Il te permet de gérer l'ordre d'empilement de tes éléments. Tu peux monter ou descendre un élément, le verrouiller, le masquer. Comme dans n'importe quel outil de design.

**[TRANSITION — face caméra]**

Tu connais maintenant tout le matériel disponible. Dans la prochaine leçon, on passe à la pratique : on part d'un template et on crée un certificat complet, étape par étape.

---

**Points clés** :
- 25+ templates en 7 catégories (Professional, Creatives, Kids, Achievement, Minimal, Musical, University)
- Formats paysage et portrait disponibles
- 8 éléments dynamiques : Student Name, Course, Instructor, Grade, Point, Verification ID, Time, Duration
- 3 éléments statiques : Text, Signature, QR Code
- Onglets supplémentaires : Media (Unsplash), Library (formes/badges), Backdrops (fonds)
- Panneau Layers pour gérer l'empilement

**Mots clés SEO** : TutorLMS Certificate Builder templates, éléments certificat TutorLMS, design certificat LMS, placeholder dynamique certificat

### Leçon 10.4 — Certificate Builder : Design complet

**Durée** : 7 min
**Type** : Vidéo HeyGen
**Écran** : Face caméra pour intro/conclusion, screencast design dans le builder
**Source** : doc certificate-builder/designing-with-a-template

---

**[INTRO — face caméra]**

Théorie terminée. On passe à la pratique. Dans cette leçon, on part d'un template Professional, on le personnalise avec les couleurs schoolsWP, on ajoute les éléments dynamiques, et on obtient un certificat prêt à être assigné à un cours.

**[ÉCRAN — screencast Certificate Builder]**

[Clic sur "Create Certificate" depuis Settings > Certificate]

Depuis Settings, Certificate, clique sur "Create Certificate". L'écran de sélection des templates s'affiche.

**[ÉCRAN — screencast choix du template]**

[Filtre catégorie "Professional", survol des templates, clic "Use This Template"]

Étape 1 : sélectionne la catégorie Professional. Parcours les options. Choisis celui qui se rapproche le plus de ce que tu veux — on va tout personnaliser de toute façon. Survole-le et clique sur "Use This Template".

**[ÉCRAN — screencast éditeur ouvert avec template]**

[Vue de l'éditeur avec le template chargé]

L'éditeur s'ouvre avec le template pré-rempli. Avant de modifier quoi que ce soit, choisis le format du certificat.

**[ÉCRAN — screencast Settings > Choose Size]**

[Montre le panneau Settings dans le sidebar, section "Choose Size"]

Étape 2 : dans le panneau gauche, va dans Settings, puis "Choose Size". Deux options :

- Letter — 1139 x 880 pixels, format US/Canada
- A4 — 1245 x 880 pixels, format international

Pour un public francophone, choisis A4. Enregistre pour appliquer.

**[ÉCRAN — screencast modification du backdrop]**

[Clic sur l'onglet Backdrops, changement de couleur de fond]

Étape 3 : personnalise l'arrière-plan. Va dans l'onglet Backdrops. Tu peux choisir une couleur unie depuis la palette, ou uploader ta propre image de fond. Si tu as une charte graphique, c'est le moment de l'appliquer.

**[ÉCRAN — screencast ajout/modification d'éléments texte]**

[Clic sur un élément texte existant, modification du contenu et du style]

Étape 4 : modifie les textes. Clique sur n'importe quel élément texte du template pour le sélectionner. Tu peux changer :

- Le contenu — remplace par ton propre titre, par exemple "Certificat de réussite"
- La police et la taille
- L'épaisseur — regular, bold, semi-bold
- L'espacement entre les lettres et la hauteur de ligne
- La couleur du texte

Positionne chaque texte en le glissant directement sur le canvas.

**[ÉCRAN — screencast ajout éléments dynamiques]**

[Drag-and-drop de Student Name, Course, Instructor, Time depuis le panneau Elements]

Étape 5 : ajoute les éléments dynamiques. Depuis l'onglet Elements, glisse "Student Name" sur le certificat. Place-le là où tu veux que le nom de l'élève apparaisse. Fais pareil pour :

- Course — le titre du cours
- Instructor — ton nom ou celui de l'instructeur
- Time — la date de délivrance

Chaque élément dynamique est stylable comme du texte normal : police, taille, couleur. Sur le canvas, tu vois un texte de démonstration. Dans le certificat final, il sera remplacé par les vraies données.

**[ÉCRAN — screencast ajout logo via Media]**

[Onglet Media, upload d'un logo, placement sur le certificat]

Étape 6 : ajoute ton logo. Va dans l'onglet Media, uploade ton logo, puis clique dessus pour le placer. Tu peux ajuster la position, la taille et même la transparence.

**[ÉCRAN — screencast ajout signature]**

[Drag-and-drop de l'élément Signature, upload de l'image]

Étape 7 : ajoute la signature. Depuis l'onglet Elements, glisse "Signature" sur le certificat. Uploade ton image de signature — rappel : PNG avec fond transparent pour un rendu propre.

**[ÉCRAN — screencast QR Code]**

[Ajout de l'élément QR Code]

Étape 8 : optionnel mais recommandé — ajoute un QR Code. Il sera généré automatiquement et permettra à quiconque scanne le certificat de vérifier son authenticité en ligne.

**[ÉCRAN — screencast gestion des calques]**

[Montre le panneau Layers, réordonne quelques éléments]

Étape 9 : vérifie l'ordre des calques. Si un élément est caché derrière un autre, utilise le panneau Layers pour le remonter. Tu peux aussi verrouiller les éléments que tu ne veux plus déplacer par erreur.

**[ÉCRAN — screencast bouton Publish]**

[Clic sur Publish en haut de l'éditeur]

Étape 10 : quand tu es satisfait, clique sur "Publish" en haut à droite. Le certificat est maintenant disponible pour être assigné à un cours.

**[TRANSITION — face caméra]**

Ton certificat est créé et publié. Il ne manque plus qu'une chose : l'associer à un cours pour que tes élèves le reçoivent automatiquement à la fin de leur formation. C'est ce qu'on fait dans la dernière leçon du module.

---

**Points clés** :
- Workflow : template > format (A4/Letter) > backdrop > textes > éléments dynamiques > logo > signature > QR code > publish
- Format A4 (1245x880 px) recommandé pour public francophone
- Éléments dynamiques stylables comme du texte (police, taille, couleur)
- Signature en PNG fond transparent
- QR Code pour vérification d'authenticité
- Panneau Layers pour gérer l'empilement et verrouiller les éléments

**Mots clés SEO** : créer certificat TutorLMS, designer certificat LMS WordPress, Certificate Builder template, certificat PDF personnalisé TutorLMS

### Leçon 10.5 — Ajouter un certificat à un cours

**Durée** : 5 min
**Type** : Vidéo HeyGen
**Écran** : Face caméra pour intro/conclusion, screencast Course Builder
**Source** : doc certificate-builder/add-certificate-to-a-course

---

**[INTRO — face caméra]**

Tu as un certificat publié. Maintenant, il faut l'associer à un cours pour que tes élèves le reçoivent quand ils terminent la formation. C'est rapide — on le fait depuis l'éditeur de cours.

**[ÉCRAN — screencast WordPress frontend]**

[Navigation vers un cours existant, clic sur Edit]

Va sur ton site en frontend et ouvre le cours auquel tu veux ajouter le certificat. Clique sur "Edit" pour ouvrir le Course Builder.

**[ÉCRAN — screencast Course Builder]**

[Scroll vers la section "Certificate Template"]

Étape 1 : dans l'éditeur de cours, cherche la section "Certificate Template". Elle se trouve dans les options du cours, généralement après les réglages de contenu.

**[ÉCRAN — screencast sélection du certificat]**

[Montre le dropdown avec les certificats disponibles]

Étape 2 : clique sur le menu déroulant. Tu vois la liste de tous les certificats publiés — ceux que tu as créés dans le Certificate Builder. Sélectionne celui que tu veux assigner à ce cours.

**[ÉCRAN — screencast publication du cours]**

[Clic sur "Publish Course" ou "Update Course"]

Étape 3 : enregistre le cours en cliquant sur "Publish Course" ou "Update Course" si le cours est déjà publié. C'est fait. Le certificat est maintenant lié à ce cours.

**[ÉCRAN — screencast côté élève]**

[Vue élève : cours terminé, bouton "Get Certificate" visible]

Maintenant, voyons ce que l'élève voit. Quand un étudiant termine tous les contenus du cours, un bouton "Get Certificate" apparaît sur la page d'accueil du cours.

**[ÉCRAN — screencast téléchargement certificat]**

[Clic sur "Get Certificate", montre les options]

En cliquant dessus, l'élève accède à son certificat avec plusieurs options :

- Aperçu du certificat avec ses informations personnalisées
- Téléchargement en JPG ou PDF
- Impression au format A4
- Partage direct sur Facebook, X (anciennement Twitter) ou LinkedIn

Le PDF est généré à la volée avec toutes les données dynamiques : nom de l'élève, titre du cours, nom de l'instructeur, date. Exactement ce qu'on a configuré dans le builder.

**[ÉCRAN — screencast Settings > Certificate > Legacy]**

[Montre l'option "Certificate Link in Course Completion Email"]

Un détail à ne pas oublier : retourne dans Settings, Certificate, et vérifie que l'option "Certificate Link in Course Completion Email" est activée. Ça ajoute automatiquement le lien vers le certificat dans l'email de fin de cours. Ton élève reçoit l'email, clique, télécharge. Pas besoin de chercher.

**[ÉCRAN — screencast partage LinkedIn]**

[Montre le bouton de partage LinkedIn sur le certificat]

Le partage LinkedIn est particulièrement utile. Quand ton élève partage son certificat, ça crée de la visibilité pour ta formation. C'est de la preuve sociale gratuite.

**[TRANSITION — face caméra]**

Voilà, ton système de certificats est opérationnel. Tu as configuré les réglages, installé le Certificate Builder, créé un design personnalisé, et assigné le certificat à un cours. Tes élèves reçoivent maintenant une preuve concrète de leur réussite — et ils peuvent la partager en ligne. Dans le quiz suivant, on vérifie que tu maîtrises tout ça.

---

**Points clés** :
- Assignation depuis le Course Builder frontend > section "Certificate Template"
- Un certificat publié peut être assigné à plusieurs cours
- Élève : bouton "Get Certificate" après complétion du cours
- Formats disponibles : JPG, PDF, impression A4
- Partage social : Facebook, X, LinkedIn
- Activer "Certificate Link in Course Completion Email" pour l'envoi automatique

**Mots clés SEO** : ajouter certificat cours TutorLMS, assigner certificat TutorLMS, certificat complétion cours LMS, télécharger certificat TutorLMS

**Question 1**

Où active-t-on l'addon Certificate dans TutorLMS ?

- A) Tutor LMS > Settings > General
- B) Tutor LMS Pro > Add-ons
- C) Plugins > Add New
- D) Tutor LMS > Certificates

**Réponse** : B

**Explication** : L'addon Certificate s'active depuis la page Tutor LMS Pro > Add-ons, indépendamment de l'installation du plugin Certificate Builder.

---

**Question 2**

Que faut-il pour télécharger le Certificate Builder ?

- A) Un compte WordPress.org gratuit
- B) Le plugin Tutor LMS gratuit
- C) Une licence Tutor LMS Pro
- D) Le plugin WooCommerce

**Réponse** : C

**Explication** : Le Certificate Builder est un plugin exclusif réservé aux utilisateurs ayant une licence Tutor LMS Pro valide. Il se télécharge depuis tutorlms.com/account/downloads/.

---

**Question 3**

Combien de catégories de templates sont disponibles dans le Certificate Builder ?

- A) 3
- B) 5
- C) 7
- D) 10

**Réponse** : C

**Explication** : Il y a 7 catégories : Professional, Creatives, Kids, Achievement, Minimal, Musical et University.

---

**Question 4**

Quel élément dynamique nécessite l'addon Gradebook pour fonctionner ?

- A) Student Name
- B) Verification ID
- C) Grade
- D) Time

**Réponse** : C

**Explication** : Les éléments Grade et Point nécessitent l'addon Gradebook pour afficher les notes et points de l'élève sur le certificat.

---

**Question 5**

Quel format de certificat est recommandé pour un public francophone ?

- A) Letter (1139x880 px)
- B) A4 (1245x880 px)
- C) A3 (1754x1240 px)
- D) Custom (taille libre)

**Réponse** : B

**Explication** : Le format A4 (1245x880 pixels) est le standard international, utilisé en France et dans la plupart des pays francophones.

---

**Question 6**

Depuis où assigne-t-on un certificat à un cours ?

- A) Tutor LMS > Settings > Certificate
- B) Le Certificate Builder
- C) Le Course Builder frontend, section "Certificate Template"
- D) Tutor LMS > Add-ons > Certificate

**Réponse** : C

**Explication** : L'assignation se fait depuis le Course Builder en frontend, dans la section "Certificate Template", en sélectionnant un certificat publié dans le menu déroulant.

---

**Question 7**

Quels formats de téléchargement sont proposés à l'élève pour son certificat ?

- A) PNG et SVG
- B) JPG et PDF
- C) PDF uniquement
- D) JPG, PNG et PDF

**Réponse** : B

**Explication** : L'élève peut télécharger son certificat en JPG ou PDF, l'imprimer en A4, ou le partager sur les réseaux sociaux.

---

**Question 8**

Quel élément du Certificate Builder génère automatiquement un code scannable renvoyant vers l'URL de vérification ?

- A) Verification ID
- B) Signature
- C) QR Code
- D) Time

**Réponse** : C

**Explication** : L'élément QR Code génère automatiquement un code QR scannable qui renvoie vers l'URL de vérification du certificat, permettant d'en confirmer l'authenticité.
