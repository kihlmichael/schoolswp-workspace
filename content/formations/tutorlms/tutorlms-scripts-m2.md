### Lecon 2.1 — Dashboard frontend : ce que voient tes utilisateurs

**Duree** : 5 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast du dashboard frontend

---

**[INTRO — face camera]**

Quand un etudiant se connecte a ta plateforme, qu'est-ce qu'il voit ? Pas le back-office WordPress. Il voit le dashboard frontend de TutorLMS. C'est sa page d'accueil, son espace personnel. Dans cette lecon, je te montre chaque section de ce dashboard pour que tu comprennes exactement l'experience de tes utilisateurs.

**[ECRAN — screencast frontend dashboard]**

[Navigation vers le dashboard frontend en tant qu'etudiant]

Le dashboard frontend est accessible depuis l'URL /dashboard de ton site. C'est une page generee automatiquement par TutorLMS a l'installation. Chaque utilisateur connecte y accede.

[Montre la vue d'ensemble du dashboard]

Premiere chose que tu vois : un resume en haut de page. Le nombre de cours auxquels l'etudiant est inscrit, le nombre de cours actifs, et le nombre de cours termines. C'est un apercu rapide de sa progression.

**[ECRAN — screencast section "Mes cours"]**

[Montre la liste des cours inscrits]

Etape 1 : la section "Enrolled Courses". C'est la liste de tous les cours auxquels l'etudiant est inscrit. Chaque carte affiche le titre du cours, la barre de progression en pourcentage, et un bouton pour reprendre la ou il s'est arrete.

Si l'etudiant n'est inscrit a aucun cours, cette zone est vide avec un message d'invitation a decouvrir le catalogue.

**[ECRAN — screencast menu lateral]**

[Montre le menu lateral du dashboard]

Etape 2 : le menu lateral. Il contient plusieurs onglets. Dashboard pour la vue d'ensemble qu'on vient de voir. Enrolled Courses pour la liste complete. Wishlist pour les cours mis en favoris. Reviews pour les avis laisses. My Quiz Attempts pour l'historique des quiz. Order History pour les commandes si tu as un modele payant. Settings pour modifier le profil et le mot de passe.

[Clique sur chaque onglet pour montrer]

Chaque onglet donne acces a une partie specifique de l'experience etudiant. On va voir les plus importants.

**[ECRAN — screencast Wishlist + Reviews]**

[Montre la Wishlist]

La Wishlist permet a l'etudiant de mettre des cours en favoris avant de s'inscrire. Pratique si tu as un catalogue avec beaucoup de formations.

[Montre les Reviews]

L'onglet Reviews affiche tous les avis que l'etudiant a laisses sur tes cours. Il peut les modifier ou les supprimer depuis cet ecran.

**[ECRAN — screencast Settings]**

[Montre l'onglet Settings]

Etape 3 : les Settings. L'etudiant peut modifier sa photo de profil, son nom affiche, sa bio, et son mot de passe. Tout se fait depuis le frontend — il n'a jamais besoin d'aller dans le back-office WordPress.

C'est un point important. Tes etudiants ne voient jamais l'admin WordPress. Ils restent dans cette interface dediee.

**[TRANSITION — face camera]**

Tu sais maintenant ce que voit un etudiant quand il se connecte. Le dashboard frontend est son espace central. Dans la prochaine lecon, on passe de l'autre cote : le dashboard instructeur et admin, la ou tu geres tout.

---

**Points cles** :
- Le dashboard frontend est accessible via /dashboard — genere automatiquement par TutorLMS
- Vue d'ensemble : cours inscrits, actifs, termines
- Menu lateral : Enrolled Courses, Wishlist, Reviews, Quiz Attempts, Order History, Settings
- L'etudiant ne voit jamais le back-office WordPress
- Settings permet de modifier profil et mot de passe depuis le frontend

**Mots cles SEO** : TutorLMS dashboard etudiant, frontend dashboard TutorLMS, interface etudiant LMS WordPress

---

**[INTRO — face camera]**

Le menu Cours dans TutorLMS, c'est la ou tout commence. C'est la liste de toutes tes formations, avec les outils pour les trier, les filtrer et les gerer en masse. Dans cette lecon, je te fais le tour complet de ce menu.

**[ECRAN — screencast admin WordPress > Tutor LMS > Courses]**

[Navigation vers Tutor LMS > Courses]

Etape 1 : dans le menu WordPress a gauche, clique sur Tutor LMS puis sur Courses. Tu arrives sur la liste de tous tes cours.

[Montre la liste des cours]

La liste affiche chaque cours avec plusieurs colonnes. Le titre du cours, l'instructeur assigne, les categories, le nombre d'etudiants inscrits et la date de publication.

**[ECRAN — screencast filtres et tri]**

[Montre la barre de filtres en haut]

Etape 2 : les filtres. En haut de la liste, tu as plusieurs options pour affiner l'affichage. Tu peux filtrer par statut : publie, brouillon, en attente. Par categorie de cours. Ou par instructeur si tu en as plusieurs.

[Montre le tri par colonnes]

Tu peux aussi trier par colonne en cliquant sur les en-tetes. Trier par date pour voir les plus recents, ou par nombre d'etudiants pour identifier tes cours les plus populaires.

**[ECRAN — screencast actions en masse]**

[Montre les cases a cocher et le menu d'actions groupees]

Etape 3 : les actions en masse. Coche plusieurs cours, puis utilise le menu deroulant "Bulk Actions". Tu peux mettre en brouillon, publier, ou supprimer plusieurs cours d'un coup. Pratique quand tu reorganises ton catalogue.

[Clique sur Quick Edit]

Le Quick Edit est rapide pour corriger un titre ou changer de categorie. Pour modifier le contenu du cours — lecons, quiz, chapitres — il faut passer par Edit.

Etape 5 : quand tu cliques sur Edit, tu ouvres l'editeur de cours complet. On ne va pas detailler l'editeur ici — c'est l'objet du Module 3 entier. Ce qu'il faut retenir pour l'instant, c'est que tout part de cette liste dans le menu Cours.

- Actions en masse : publier, brouillon, supprimer par lot

### Lecon 2.4 — Categories & Tags : organise ton catalogue

**Duree** : 4 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast des menus Categories et Tags

---

**[INTRO — face camera]**

Si tu as 3 cours, tu peux t'en sortir sans organisation. A partir de 5 ou 10, c'est le chaos sans categories. Les categories et les tags dans TutorLMS fonctionnent comme ceux de WordPress, mais pour tes cours. Je te montre comment les configurer correctement.

**[ECRAN — screencast admin > Tutor LMS > Categories]**

[Navigation vers Tutor LMS > Categories]

Etape 1 : va dans Tutor LMS puis Categories. L'ecran est divise en deux. A gauche, le formulaire pour creer une nouvelle categorie. A droite, la liste des categories existantes.

[Montre le formulaire de creation]

Etape 2 : pour creer une categorie, remplis trois champs. Le nom : c'est ce qui s'affiche publiquement. Par exemple "WordPress", "Marketing Email", ou "LMS". Le slug : genere automatiquement depuis le nom, c'est la partie de l'URL. La description : optionnelle, mais utile pour le SEO si ton theme l'affiche.

**[ECRAN — screencast categories parentes]**

[Montre le champ "Parent Category"]

Etape 3 : le champ Parent. Tu peux creer une hierarchie. Par exemple, une categorie parente "WordPress" avec des sous-categories "Plugins", "Themes", "Performance". Ca structure ton catalogue proprement pour les visiteurs.

[Cree une categorie avec un parent pour montrer]

Mon conseil : ne depasse pas deux niveaux de profondeur. Parent et enfant, pas plus. Sinon la navigation devient confuse.

**[ECRAN — screencast admin > Tutor LMS > Tags]**

[Navigation vers Tutor LMS > Tags]

Etape 4 : les Tags. Le menu est identique dans sa structure : formulaire a gauche, liste a droite. Mais les tags n'ont pas de hierarchie. Pas de parent, pas d'enfant. C'est a plat.

[Montre la creation d'un tag]

Les tags servent a ajouter des mots-cles transversaux. Un cours "Maitriser FluentCRM" pourrait avoir la categorie "Marketing Email" et les tags "automatisation", "segmentation", "newsletters". Les tags permettent de retrouver des cours par theme, independamment de la categorie.

**[ECRAN — screencast assignation sur un cours]**

[Ouvre l'editeur d'un cours, montre les metaboxes categorie et tags]

Etape 5 : pour assigner une categorie ou un tag a un cours, tu le fais dans l'editeur du cours. Dans la colonne de droite, tu trouves les metaboxes "Course Categories" et "Course Tags". Coche les categories, tape les tags. Simple.

**[ECRAN — slide bonnes pratiques]**

Quelques regles pour rester organise. Limite-toi a une categorie principale par cours. Utilise 3 a 5 tags maximum par cours. Choisis des noms de categories courts et clairs. Pense a tes etudiants : ils doivent trouver le bon cours en 2 clics dans ton catalogue.

**[TRANSITION — face camera]**

Categories et tags sont en place. Ton catalogue est structure. Dans la prochaine lecon, on passe aux menus Etudiants et Instructeurs pour gerer les personnes sur ta plateforme.

---

**Points cles** :
- Categories : hierarchiques (parent/enfant), limitees a 2 niveaux
- Tags : non hierarchiques, mots-cles transversaux
- Formulaire identique : nom, slug, description (+ parent pour les categories)
- Assignation dans l'editeur de cours (metaboxes a droite)
- Bonne pratique : 1 categorie principale, 3-5 tags par cours

**Mots cles SEO** : TutorLMS categories cours, tags cours TutorLMS, organiser catalogue LMS WordPress

### Lecon 2.5 — Etudiants & Instructeurs : gere tes utilisateurs

**Duree** : 5 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast des menus Students et Instructors

---

**[INTRO — face camera]**

Tes cours sont crees, ton catalogue est organise. Maintenant, les personnes. TutorLMS ajoute deux roles WordPress specifiques : etudiant et instructeur. Dans cette lecon, je te montre ou les trouver et comment les gerer depuis le back-office.

**[ECRAN — screencast admin > Tutor LMS > Students]**

[Navigation vers Tutor LMS > Students]

Etape 1 : va dans Tutor LMS puis Students. Tu arrives sur la liste de tous les utilisateurs inscrits en tant qu'etudiants. L'affichage montre le nom, l'email, la date d'inscription, et le nombre de cours auxquels chaque etudiant est inscrit.

[Montre la barre de recherche]

Etape 2 : la barre de recherche en haut te permet de trouver un etudiant par nom ou email. Pratique quand tu as des dizaines ou des centaines d'inscrits.

**[ECRAN — screencast profil etudiant]**

[Clique sur un etudiant pour voir son profil]

Etape 3 : en cliquant sur un etudiant, tu accedes a son profil detaille. Tu vois ses cours en cours, ses cours termines, ses resultats de quiz, et son activite recente. C'est un suivi individuel complet.

Tu peux aussi inscrire manuellement un etudiant a un cours depuis cette vue. Utile si tu veux offrir un acces VIP ou corriger une inscription manquante.

**[ECRAN — screencast admin > Tutor LMS > Instructors]**

[Navigation vers Tutor LMS > Instructors]

Etape 4 : le menu Instructors. Meme logique : une liste de tous les utilisateurs avec le role instructeur. Tu vois leur nom, leur email, le nombre de cours crees, et le nombre total d'etudiants.

[Montre les options d'un instructeur]

Pour chaque instructeur, tu peux voir ses cours, approuver ou bloquer son compte, et ajuster ses permissions.

**[ECRAN — screencast ajout d'un instructeur]**

[Montre le processus d'ajout]

Etape 5 : pour ajouter un instructeur, deux options. Soit tu changes le role d'un utilisateur existant depuis la page Users de WordPress — tu selectionnes "Instructor". Soit tu actives l'inscription instructeur dans les reglages TutorLMS, et les utilisateurs peuvent postuler depuis le frontend.

Si tu actives la candidature instructeur, chaque demande passe par une validation admin. Tu decides qui peut enseigner sur ta plateforme.

**[ECRAN — slide "Etudiant vs Instructeur vs Admin"]**

Recapitulons les trois roles. L'etudiant peut s'inscrire a des cours, suivre les lecons, passer les quiz, et laisser des avis. L'instructeur peut tout ca, plus creer et gerer ses propres cours, envoyer des annonces et repondre aux Q&A. L'admin a le controle total : tous les cours, tous les utilisateurs, tous les reglages.

Si tu es seul sur ta plateforme, tu es admin et instructeur en meme temps. Tu n'as pas besoin de creer un compte instructeur separe.

**[TRANSITION — face camera]**

Tu sais maintenant ou trouver et gerer tes etudiants et instructeurs. Prochaine lecon : les annonces et le systeme de Q&A, deux outils de communication directe avec tes etudiants.

---

**Points cles** :
- Menu Students : liste, recherche, profil detaille, inscription manuelle
- Menu Instructors : liste, approbation, permissions
- Trois roles : etudiant (suit les cours), instructeur (cree les cours), admin (controle total)
- Ajout instructeur : changement de role WP ou candidature frontend avec validation
- Seul sur la plateforme = admin + instructeur cumules

**Mots cles SEO** : TutorLMS gestion etudiants, role instructeur TutorLMS, utilisateurs LMS WordPress

### Lecon 2.6 — Annonces & Q&A : communique avec tes etudiants

**Duree** : 5 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast des menus Announcements et Q&A

---

**[INTRO — face camera]**

Tes etudiants suivent tes cours. Mais comment tu communiques avec eux ? TutorLMS integre deux outils : les annonces et le systeme de questions-reponses. Les annonces pour les messages importants, le Q&A pour les echanges dans chaque cours. Je te montre comment les utiliser.

**[ECRAN — screencast admin > Tutor LMS > Announcements]**

[Navigation vers Tutor LMS > Announcements]

Etape 1 : va dans Tutor LMS puis Announcements. Tu arrives sur la liste de toutes les annonces publiees. Chaque annonce est liee a un cours specifique. Tu ne peux pas envoyer une annonce globale a tous tes etudiants — c'est toujours cours par cours.

[Montre la liste des annonces]

L'affichage montre le titre de l'annonce, le cours concerne, la date, et le nombre d'etudiants qui la verront.

**[ECRAN — screencast creation d'annonce]**

[Clique sur "Add New"]

Etape 2 : pour creer une annonce, clique sur "Add New". Tu remplis le titre, le contenu — un editeur classique WordPress — et tu selectionnes le cours concerne dans le menu deroulant.

[Montre la redaction d'une annonce]

Exemple concret : tu viens d'ajouter 3 nouvelles lecons a ton cours. Tu crees une annonce "3 nouvelles lecons disponibles" avec un resume de ce qui a change. Tous les etudiants inscrits a ce cours voient l'annonce dans leur dashboard.

[Publie l'annonce]

Etape 3 : clique sur Publier. L'annonce apparait immediatement dans le dashboard frontend des etudiants inscrits au cours.

**[ECRAN — screencast vue etudiant de l'annonce]**

[Montre l'annonce cote frontend]

Voici ce que voit l'etudiant. L'annonce s'affiche dans la section Announcements de la page du cours. Le plus recent en haut. L'etudiant peut aussi recevoir une notification par email si tu as active cette option dans les reglages.

**[ECRAN — screencast admin > Tutor LMS > Q&A]**

[Navigation vers Tutor LMS > Q&A]

Etape 4 : le systeme Q&A. Va dans Tutor LMS puis Q&A. Tu vois toutes les questions posees par tes etudiants, tous cours confondus.

[Montre la liste des Q&A]

Chaque entree affiche la question, l'etudiant qui l'a posee, le cours concerne, et le statut : en attente de reponse, repondu, ou resolu.

**[ECRAN — screencast reponse a une question]**

[Clique sur une question pour repondre]

Etape 5 : clique sur une question pour l'ouvrir. Tu vois le message de l'etudiant et un champ pour repondre. Tu peux ecrire ta reponse et la publier. L'etudiant recoit une notification.

[Montre la reponse publiee]

Le Q&A est visible par tous les etudiants du cours. C'est public, pas prive. Un etudiant qui pose une question aide les autres qui avaient la meme. Pense-le comme un mini-forum integre a chaque cours.

**[ECRAN — screencast cote etudiant]**

[Montre l'onglet Q&A dans un cours cote frontend]

Cote etudiant, le Q&A est accessible depuis la page du cours. L'etudiant clique sur l'onglet "Q&A", pose sa question, et attend ta reponse. Il peut aussi lire les questions des autres etudiants.

**[TRANSITION — face camera]**

Annonces pour les messages importants, Q&A pour les echanges du quotidien. Ces deux outils gardent le lien avec tes etudiants sans quitter TutorLMS. Prochaine lecon : les quiz attempts et les outils complementaires.

---

**Points cles** :
- Annonces : liees a un cours, pas globales — visibles dans le dashboard etudiant
- Creation : titre + contenu + selection du cours
- Notification email possible si activee dans les reglages
- Q&A : questions-reponses publiques, par cours, visibles par tous les etudiants
- Statuts Q&A : en attente, repondu, resolu
- Le Q&A fonctionne comme un mini-forum integre a chaque cours

**Mots cles SEO** : TutorLMS annonces cours, Q&A TutorLMS, communication etudiants LMS WordPress

### Lecon 2.7 — Quiz Attempts & Outils : surveille et optimise

**Duree** : 5 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast des menus Quiz Attempts et Tools

---

**[INTRO — face camera]**

Derniere lecon avant le quiz du module. On couvre deux menus que tu vas utiliser regulierement : Quiz Attempts pour suivre les resultats de tes etudiants, et Tools pour les fonctions utilitaires de TutorLMS. Deux menus, une lecon, on va droit au but.

**[ECRAN — screencast admin > Tutor LMS > Quiz Attempts]**

[Navigation vers Tutor LMS > Quiz Attempts]

Etape 1 : va dans Tutor LMS puis Quiz Attempts. Tu arrives sur la liste de toutes les tentatives de quiz de ta plateforme. Chaque ligne affiche l'etudiant, le quiz concerne, le cours associe, le score obtenu, et le statut : reussi ou echoue.

[Montre la liste avec des exemples]

C'est ton tableau de bord d'evaluation. D'un coup d'oeil, tu vois qui a passe quoi, avec quel resultat.

**[ECRAN — screencast filtres Quiz Attempts]**

[Montre les filtres disponibles]

Etape 2 : les filtres. Tu peux filtrer par cours, par date, ou par statut (reussi/echoue). Si tu veux voir tous les etudiants qui ont echoue a un quiz specifique, c'est ici que tu cherches.

[Applique un filtre pour montrer]

Ce filtre est particulierement utile pour identifier les lecons problematiques. Si 80% de tes etudiants echouent au meme quiz, c'est probablement le contenu de la lecon qui doit etre revu, pas les etudiants.

**[ECRAN — screencast detail d'une tentative]**

[Clique sur une tentative pour voir le detail]

Etape 3 : en cliquant sur une tentative, tu vois le detail question par question. La reponse de l'etudiant, la bonne reponse, les points obtenus. Pour les questions ouvertes ou a correction manuelle, tu peux attribuer les points ici.

[Montre la correction manuelle]

Si ton quiz contient des questions a reponse libre, elles restent en "pending" jusqu'a ta correction. Tu peux approuver, ajuster le score, et valider.

**[ECRAN — screencast admin > Tutor LMS > Tools]**

[Navigation vers Tutor LMS > Tools]

Etape 4 : le menu Tools. C'est le couteau suisse de TutorLMS. Tu y trouves plusieurs onglets.

[Montre l'onglet Pages]

Le premier onglet, Pages, te montre quelles pages WordPress sont assignees aux fonctions TutorLMS. La page Dashboard, la page Instructor Registration, la page Student Registration. Si une page est manquante, tu peux la regenerer depuis cet ecran.

[Montre l'onglet Import/Export]

Le deuxieme onglet important : Import/Export. Tu peux exporter tes cours au format JSON et les reimporter sur un autre site. Utile si tu migres ta plateforme ou si tu veux dupliquer un cours sur un site de test.

**[ECRAN — screencast onglet Status]**

[Montre l'onglet Status/System Info]

L'onglet Status affiche les informations systeme. Version de TutorLMS, version de PHP, limites serveur. C'est la premiere chose a verifier si quelque chose ne fonctionne pas. Le support TutorLMS te demandera toujours ces informations.

[Montre les eventuels warnings]

Si un parametre serveur n'est pas optimal, TutorLMS affiche un avertissement en rouge. Par exemple, une limite de memoire PHP trop basse ou une version PHP obsolete.

**[TRANSITION — face camera]**

### Lecon 2.8 — Quiz Module 2

**Type** : Quiz QCM (8 questions)
**Seuil de reussite** : 75% (6/8)
**Tentatives** : illimitees

---

**Question 1**
Quelle URL donne acces au dashboard frontend de TutorLMS ?

- A) /admin
- B) /wp-admin
- C) /dashboard
- D) /my-account

**Reponse correcte** : C
**Explication** : Le dashboard frontend TutorLMS est accessible via /dashboard. C'est la page generee automatiquement a l'installation du plugin.

---

**Question 2**
Que peut faire un instructeur depuis le dashboard frontend que l'etudiant ne peut pas faire ?

- A) S'inscrire a des cours
- B) Creer et gerer ses propres cours
- C) Modifier son mot de passe
- D) Laisser un avis sur un cours

**Reponse correcte** : B
**Explication** : L'instructeur peut creer, editer et gerer ses cours directement depuis le frontend, sans acceder au back-office WordPress. L'etudiant peut uniquement suivre les cours.

---

**Question 3**
Dans le menu Cours du back-office, que permet le Quick Edit ?

- A) Modifier les lecons et quiz d'un cours
- B) Modifier le titre, le slug, la categorie et le statut
- C) Dupliquer un cours
- D) Exporter un cours en JSON

**Reponse correcte** : B
**Explication** : Le Quick Edit permet de modifier rapidement le titre, le slug, la categorie et le statut sans ouvrir l'editeur complet du cours.

---

**Question 4**
Quelle est la difference principale entre les categories et les tags de cours ?

- A) Les categories sont publiques, les tags sont prives
- B) Les categories sont hierarchiques, les tags ne le sont pas
- C) Les tags sont limites a 3 par cours
- D) Les categories ne sont pas visibles sur le frontend

**Reponse correcte** : B
**Explication** : Les categories supportent une hierarchie parent/enfant. Les tags sont a plat, sans hierarchie. Les deux sont visibles publiquement.

---

**Question 5**
Comment ajouter un instructeur sur ta plateforme TutorLMS ?

- A) Creer un nouveau site WordPress
- B) Changer le role d'un utilisateur ou activer la candidature instructeur
- C) Installer un plugin supplementaire
- D) Envoyer un email d'invitation automatique

**Reponse correcte** : B
**Explication** : Deux methodes : changer le role d'un utilisateur existant depuis WordPress, ou activer l'inscription instructeur avec validation admin.

---

**Question 6**
Les annonces dans TutorLMS sont-elles globales ou liees a un cours ?

- A) Globales — tous les etudiants les voient
- B) Liees a un cours — seuls les etudiants inscrits au cours les voient
- C) Envoyees par email uniquement
- D) Visibles uniquement dans le back-office

**Reponse correcte** : B
**Explication** : Chaque annonce est associee a un cours specifique. Seuls les etudiants inscrits a ce cours la voient dans leur dashboard.

---

**Question 7**
Le systeme Q&A de TutorLMS est-il public ou prive ?

- A) Prive — seul l'etudiant et l'instructeur voient les echanges
- B) Public — tous les etudiants du cours peuvent voir les questions et reponses
- C) Visible uniquement par l'admin
- D) Accessible uniquement par email

**Reponse correcte** : B
**Explication** : Le Q&A est public au sein du cours. Tous les etudiants inscrits peuvent voir les questions et reponses, ce qui profite a tout le groupe.

---

**Question 8**
Dans le menu Tools, quel onglet utilises-tu pour migrer un cours vers un autre site ?

- A) Pages
- B) Status
- C) Import/Export
- D) Settings

**Reponse correcte** : C
**Explication** : L'onglet Import/Export permet d'exporter des cours au format JSON et de les reimporter sur un autre site WordPress avec TutorLMS.
