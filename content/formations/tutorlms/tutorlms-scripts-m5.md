### Leçon 5.1 : Frontend Course Builder

**Durée** : 7 min
**Type** : Vidéo HeyGen
**Écran** : Face caméra pour intro/conclusion, screencast du frontend
**Source** : Vidéo #14 + doc frontend-course-builder

---

**[INTRO - face caméra]**

Dans le module précédent, tu as créé des cours depuis le backend WordPress - le tableau de bord admin. Mais TutorLMS propose une autre approche : le Frontend Course Builder. L'idée est simple - tes instructeurs créent et gèrent leurs cours sans jamais voir le backend WordPress. C'est ce qu'on va configurer ensemble.

**[ÉCRAN - screencast WordPress admin]**

[Navigation vers Tutor LMS > Settings > Course]

Pour activer le Frontend Course Builder, direction les réglages de TutorLMS. Va dans Tutor LMS, puis Settings, puis l'onglet Course. Tu vas trouver l'option "Frontend Course Builder". Active-la. À partir de maintenant, les instructeurs auront accès à un éditeur de cours complet directement depuis le front-end de ton site.

**[ÉCRAN - screencast front-end dashboard]**

[Connexion en tant qu'instructeur, vue du dashboard front-end]

Quand un instructeur se connecte, il arrive sur son tableau de bord front-end. C'est son espace de travail. Il voit ses cours en cours, ses statistiques, ses gains si tu as activé la monétisation. En haut ou dans le menu, il a un bouton "Create a New Course". C'est le point de départ.

**[ÉCRAN - screencast création de cours frontend]**

[Clic sur "Create a New Course" - vue du formulaire]

L'interface du Frontend Course Builder reprend les mêmes sections que le backend - Course Info, Curriculum, Additional Settings - mais dans une mise en page adaptée au front-end. Pas de menu WordPress, pas de sidebar admin. Juste le nécessaire pour construire un cours.

**[ÉCRAN - screencast Course Info frontend]**

[Remplissage du titre, description, catégorie]

Première section : les informations de base. Titre du cours, description, catégorie, image mise en avant. Tu retrouves exactement les mêmes champs que dans le backend. La différence, c'est la présentation - plus épurée, plus guidée.

Un point important : la description utilise un éditeur simplifié, pas l'éditeur WordPress complet. Suffisant pour du texte structuré avec des titres, des listes et du gras, mais pas de shortcodes ni de blocs avancés.

**[ÉCRAN - screencast Curriculum frontend]**

[Ajout d'un topic et d'une leçon depuis le frontend]

La section Curriculum fonctionne pareil. Tu crées des topics, tu ajoutes des leçons et des quiz à l'intérieur. L'éditeur de leçon s'ouvre dans une modale - tu rédiges le contenu, tu ajoutes une vidéo, tu sauvegardes. Même logique que le backend, interface différente.

**[ÉCRAN - screencast Additional Settings frontend]**

[Scroll vers les réglages additionnels]

Les réglages additionnels sont là aussi - objectifs d'apprentissage, prérequis, durée estimée, pièces jointes. Tout ce qu'on a vu dans le Module 4 reste accessible. La seule différence : certaines options avancées comme les certificats ou les intégrations Zoom peuvent ne pas apparaître ici selon ta configuration.

**[ÉCRAN - screencast bouton Submit/Publish]**

[Montre les options de soumission]

En bas du formulaire, tu as les options de publication. Et c'est là qu'il y a une vraie différence avec le backend. Selon tes réglages, l'instructeur peut soit publier directement, soit soumettre le cours pour revue. C'est toi qui décides dans Settings > Course > "Instructor Can Publish Courses".

Si tu désactives cette option, le cours part en "Pending Review". L'administrateur reçoit une notification, valide le contenu, et publie. C'est le workflow recommandé quand tu travailles avec plusieurs instructeurs - tu gardes le contrôle qualité.

**[ÉCRAN - screencast Settings instructeur]**

[Navigation vers Settings > Course > options instructeur]

Deux autres réglages à connaître pour le frontend. "Instructor Can Delete Courses" - est-ce que l'instructeur peut supprimer ses propres cours ? Par défaut, non. Et "Enable Course Marketplace" - si activé, n'importe quel utilisateur peut demander à devenir instructeur via un formulaire. Utile si tu veux ouvrir ta plateforme à d'autres formateurs.

**[TRANSITION - face caméra]**

Le Frontend Course Builder est l'outil idéal quand tu travailles avec des instructeurs externes. Ils ont tout ce qu'il faut pour créer un cours pro, et toi tu gardes la main sur la validation et la publication. Dans la prochaine leçon, on découvre le Course Builder 3.0 - la refonte complète de l'interface de création.

---

**Points clés** :
- Frontend Course Builder à activer dans Settings > Course
- Mêmes sections que le backend (Course Info, Curriculum, Additional Settings) dans une interface épurée
- Option "Instructor Can Publish Courses" : publication directe ou workflow de validation
- "Enable Course Marketplace" pour ouvrir l'inscription des instructeurs
- Recommandé pour les plateformes multi-instructeurs

### Leçon 5.2 : Naviguer le nouveau Course Builder 3.0

**Durée** : 7 min
**Type** : Vidéo HeyGen
**Écran** : Face caméra pour intro/conclusion, screencast du Course Builder 3.0
**Source** : Vidéo #31

---

**[INTRO - face caméra]**

TutorLMS a complètement refait son interface de création de cours avec le Course Builder 3.0. Si tu as utilisé les versions précédentes, tu vas voir que c'est un autre niveau en termes d'ergonomie. Et si tu débutes, tant mieux - tu pars directement sur la meilleure version. Je te fais le tour complet.

**[ÉCRAN - screencast Course Builder 3.0]**

[Ouverture du Course Builder - vue globale de la nouvelle interface]

Première chose qui frappe : l'interface est en pleine page. Fini le formulaire qui s'empile dans la colonne WordPress. Le Course Builder 3.0 prend tout l'écran, avec une navigation par onglets en haut. C'est plus clair, plus rapide, et chaque section a son propre espace.

**[ÉCRAN - screencast onglets du Builder]**

[Montre les onglets : Course, Curriculum, Settings, etc.]

Les onglets principaux. Tu as "Course" pour les informations de base - titre, description, image, vidéo d'introduction. "Curriculum" pour la structure pédagogique - topics, leçons, quiz. "Settings" pour les réglages avancés. Et selon tes add-ons actifs, tu peux avoir des onglets supplémentaires comme "Certificate" ou "Prerequisites".

**[ÉCRAN - screencast onglet Course]**

[Navigation dans l'onglet Course - édition du titre et de la description]

L'onglet Course utilise un éditeur modernisé. Le titre du cours est en haut, bien visible. La description a un éditeur riche avec barre d'outils. Tu peux ajouter l'image mise en avant et la vidéo d'introduction directement dans cette vue - plus besoin de chercher une meta box sur le côté.

Le sélecteur de catégorie est aussi intégré ici. Tout est regroupé logiquement au même endroit.

**[ÉCRAN - screencast onglet Curriculum 3.0]**

[Vue du Curriculum avec drag & drop]

L'onglet Curriculum, c'est là où le 3.0 brille vraiment. Le drag & drop est fluide - tu réorganises tes topics, tes leçons, tes quiz en les glissant. Plus besoin de supprimer et recréer pour changer l'ordre.

[Démonstration du drag & drop d'une leçon entre deux topics]

Tu peux même déplacer une leçon d'un topic à un autre par simple glisser-déposer. Avant, il fallait supprimer la leçon du topic et la recréer dans l'autre. Maintenant c'est instantané.

**[ÉCRAN - screencast édition de leçon inline]**

[Clic sur une leçon - ouverture du panneau d'édition]

Quand tu cliques sur une leçon, le panneau d'édition s'ouvre sur le côté ou en modale - selon la taille de ton écran. Tu édites le titre, le contenu, la vidéo, les pièces jointes, sans quitter la page du curriculum. C'est un vrai gain de temps quand tu construis un cours avec beaucoup de leçons.

**[ÉCRAN - screencast onglet Settings 3.0]**

[Navigation dans l'onglet Settings]

L'onglet Settings regroupe tout ce qui était dispersé dans l'ancienne interface. Durée du cours, nombre maximum d'étudiants, niveau de difficulté, objectifs d'apprentissage, prérequis - tout est là, organisé en sections pliables. Tu déplies ce dont tu as besoin, tu laisses le reste fermé.

**[ÉCRAN - screencast preview et publication]**

[Montre le bouton Preview et les options de publication]

En haut à droite, tu as le bouton "Preview" pour voir ton cours comme un étudiant le verrait. À côté, les boutons "Save Draft" et "Publish". Le 3.0 sauvegarde aussi automatiquement en arrière-plan - tu ne perds plus ton travail si tu fermes l'onglet par accident.

**[ÉCRAN - screencast comparaison ancien vs nouveau]**

[Slide comparatif : ancien builder vs Course Builder 3.0]

Pour résumer les différences clés entre l'ancien builder et le 3.0 :

1. Interface pleine page au lieu d'un formulaire WordPress classique
2. Navigation par onglets au lieu de tout en une seule colonne
3. Drag & drop natif pour réorganiser le curriculum
4. Édition des leçons inline sans quitter la page
5. Sauvegarde automatique en arrière-plan
6. Design modernisé et plus réactif

**[ÉCRAN - screencast compatibilité]**

[Montre les réglages de mise à jour TutorLMS]

Note importante : le Course Builder 3.0 est disponible à partir de TutorLMS 3.0. Si tu es sur une version antérieure, tu verras l'ancien builder. Pour vérifier ta version, va dans Plugins dans le menu WordPress et regarde le numéro de version à côté de TutorLMS. La mise à jour se fait comme n'importe quel plugin WordPress.

**[TRANSITION - face caméra]**

Le Course Builder 3.0 rend la création de cours nettement plus fluide. Interface claire, drag & drop, édition inline, sauvegarde auto - tout est pensé pour te faire gagner du temps. Tu as maintenant les clés pour créer des cours depuis le backend et le frontend de TutorLMS. Le quiz qui suit va te permettre de valider tout ça.

---

**Points clés** :
- Course Builder 3.0 : interface pleine page avec navigation par onglets
- Drag & drop natif pour réorganiser topics, leçons et quiz
- Édition des leçons en inline sans quitter le curriculum
- Sauvegarde automatique en arrière-plan
- Disponible à partir de TutorLMS 3.0 - vérifier la version du plugin
- Bouton Preview pour voir le cours côté étudiant avant publication
