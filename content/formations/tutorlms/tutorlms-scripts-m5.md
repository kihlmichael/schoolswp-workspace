### Lecon 5.1 — Frontend Course Builder

**Duree** : 7 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast du frontend
**Source** : Video #14 + doc frontend-course-builder

---

**[INTRO — face camera]**

Dans le module precedent, tu as cree des cours depuis le backend WordPress — le tableau de bord admin. Mais TutorLMS propose une autre approche : le Frontend Course Builder. L'idee est simple — tes instructeurs creent et gerent leurs cours sans jamais voir le backend WordPress. C'est ce qu'on va configurer ensemble.

**[ECRAN — screencast WordPress admin]**

[Navigation vers Tutor LMS > Settings > Course]

Pour activer le Frontend Course Builder, direction les reglages de TutorLMS. Va dans Tutor LMS, puis Settings, puis l'onglet Course. Tu vas trouver l'option "Frontend Course Builder". Active-la. A partir de maintenant, les instructeurs auront acces a un editeur de cours complet directement depuis le front-end de ton site.

**[ECRAN — screencast front-end dashboard]**

[Connexion en tant qu'instructeur, vue du dashboard front-end]

Quand un instructeur se connecte, il arrive sur son tableau de bord front-end. C'est son espace de travail. Il voit ses cours en cours, ses statistiques, ses gains si tu as active la monetisation. En haut ou dans le menu, il a un bouton "Create a New Course". C'est le point de depart.

**[ECRAN — screencast creation de cours frontend]**

[Clic sur "Create a New Course" — vue du formulaire]

L'interface du Frontend Course Builder reprend les memes sections que le backend — Course Info, Curriculum, Additional Settings — mais dans une mise en page adaptee au front-end. Pas de menu WordPress, pas de sidebar admin. Juste le necessaire pour construire un cours.

**[ECRAN — screencast Course Info frontend]**

[Remplissage du titre, description, categorie]

Premiere section : les informations de base. Titre du cours, description, categorie, image mise en avant. Tu retrouves exactement les memes champs que dans le backend. La difference, c'est la presentation — plus epuree, plus guidee.

Un point important : la description utilise un editeur simplifie, pas l'editeur WordPress complet. Suffisant pour du texte structure avec des titres, des listes et du gras, mais pas de shortcodes ni de blocs avances.

**[ECRAN — screencast Curriculum frontend]**

[Ajout d'un topic et d'une lecon depuis le frontend]

La section Curriculum fonctionne pareil. Tu crees des topics, tu ajoutes des lecons et des quiz a l'interieur. L'editeur de lecon s'ouvre dans une modale — tu rediges le contenu, tu ajoutes une video, tu sauvegardes. Meme logique que le backend, interface differente.

**[ECRAN — screencast Additional Settings frontend]**

[Scroll vers les reglages additionnels]

Les reglages additionnels sont la aussi — objectifs d'apprentissage, prerequis, duree estimee, pieces jointes. Tout ce qu'on a vu dans le Module 4 reste accessible. La seule difference : certaines options avancees comme les certificats ou les integrations Zoom peuvent ne pas apparaitre ici selon ta configuration.

**[ECRAN — screencast bouton Submit/Publish]**

[Montre les options de soumission]

En bas du formulaire, tu as les options de publication. Et c'est la qu'il y a une vraie difference avec le backend. Selon tes reglages, l'instructeur peut soit publier directement, soit soumettre le cours pour revue. C'est toi qui decides dans Settings > Course > "Instructor Can Publish Courses".

Si tu desactives cette option, le cours part en "Pending Review". L'administrateur recoit une notification, valide le contenu, et publie. C'est le workflow recommande quand tu travailles avec plusieurs instructeurs — tu gardes le controle qualite.

**[ECRAN — screencast Settings instructeur]**

[Navigation vers Settings > Course > options instructeur]

Deux autres reglages a connaitre pour le frontend. "Instructor Can Delete Courses" — est-ce que l'instructeur peut supprimer ses propres cours ? Par defaut, non. Et "Enable Course Marketplace" — si active, n'importe quel utilisateur peut demander a devenir instructeur via un formulaire. Utile si tu veux ouvrir ta plateforme a d'autres formateurs.

**[TRANSITION — face camera]**

Le Frontend Course Builder est l'outil ideal quand tu travailles avec des instructeurs externes. Ils ont tout ce qu'il faut pour creer un cours pro, et toi tu gardes la main sur la validation et la publication. Dans la prochaine lecon, on decouvre le Course Builder 3.0 — la refonte complete de l'interface de creation.

---

**Points cles** :
- Frontend Course Builder a activer dans Settings > Course
- Memes sections que le backend (Course Info, Curriculum, Additional Settings) dans une interface epuree
- Option "Instructor Can Publish Courses" : publication directe ou workflow de validation
- "Enable Course Marketplace" pour ouvrir l'inscription des instructeurs
- Recommande pour les plateformes multi-instructeurs

### Lecon 5.2 — Naviguer le nouveau Course Builder 3.0

**Duree** : 7 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast du Course Builder 3.0
**Source** : Video #31

---

**[INTRO — face camera]**

TutorLMS a completement refait son interface de creation de cours avec le Course Builder 3.0. Si tu as utilise les versions precedentes, tu vas voir que c'est un autre niveau en termes d'ergonomie. Et si tu debutes, tant mieux — tu pars directement sur la meilleure version. Je te fais le tour complet.

**[ECRAN — screencast Course Builder 3.0]**

[Ouverture du Course Builder — vue globale de la nouvelle interface]

Premiere chose qui frappe : l'interface est en pleine page. Fini le formulaire qui s'empile dans la colonne WordPress. Le Course Builder 3.0 prend tout l'ecran, avec une navigation par onglets en haut. C'est plus clair, plus rapide, et chaque section a son propre espace.

**[ECRAN — screencast onglets du Builder]**

[Montre les onglets : Course, Curriculum, Settings, etc.]

Les onglets principaux. Tu as "Course" pour les informations de base — titre, description, image, video d'introduction. "Curriculum" pour la structure pedagogique — topics, lecons, quiz. "Settings" pour les reglages avances. Et selon tes add-ons actifs, tu peux avoir des onglets supplementaires comme "Certificate" ou "Prerequisites".

**[ECRAN — screencast onglet Course]**

[Navigation dans l'onglet Course — edition du titre et de la description]

L'onglet Course utilise un editeur modernise. Le titre du cours est en haut, bien visible. La description a un editeur riche avec barre d'outils. Tu peux ajouter l'image mise en avant et la video d'introduction directement dans cette vue — plus besoin de chercher une meta box sur le cote.

Le selecteur de categorie est aussi integre ici. Tout est regroupe logiquement au meme endroit.

**[ECRAN — screencast onglet Curriculum 3.0]**

[Vue du Curriculum avec drag & drop]

L'onglet Curriculum, c'est la ou le 3.0 brille vraiment. Le drag & drop est fluide — tu reorganises tes topics, tes lecons, tes quiz en les glissant. Plus besoin de supprimer et recreer pour changer l'ordre.

[Demonstration du drag & drop d'une lecon entre deux topics]

Tu peux meme deplacer une lecon d'un topic a un autre par simple glisser-deposer. Avant, il fallait supprimer la lecon du topic et la recreer dans l'autre. Maintenant c'est instantane.

**[ECRAN — screencast edition de lecon inline]**

[Clic sur une lecon — ouverture du panneau d'edition]

Quand tu cliques sur une lecon, le panneau d'edition s'ouvre sur le cote ou en modale — selon la taille de ton ecran. Tu edites le titre, le contenu, la video, les pieces jointes, sans quitter la page du curriculum. C'est un vrai gain de temps quand tu construis un cours avec beaucoup de lecons.

**[ECRAN — screencast onglet Settings 3.0]**

[Navigation dans l'onglet Settings]

L'onglet Settings regroupe tout ce qui etait disperse dans l'ancienne interface. Duree du cours, nombre maximum d'etudiants, niveau de difficulte, objectifs d'apprentissage, prerequis — tout est la, organise en sections pliables. Tu deplies ce dont tu as besoin, tu laisses le reste ferme.

**[ECRAN — screencast preview et publication]**

[Montre le bouton Preview et les options de publication]

En haut a droite, tu as le bouton "Preview" pour voir ton cours comme un etudiant le verrait. A cote, les boutons "Save Draft" et "Publish". Le 3.0 sauvegarde aussi automatiquement en arriere-plan — tu ne perds plus ton travail si tu fermes l'onglet par accident.

**[ECRAN — screencast comparaison ancien vs nouveau]**

[Slide comparatif : ancien builder vs Course Builder 3.0]

Pour resumer les differences cles entre l'ancien builder et le 3.0 :

1. Interface pleine page au lieu d'un formulaire WordPress classique
2. Navigation par onglets au lieu de tout en une seule colonne
3. Drag & drop natif pour reorganiser le curriculum
4. Edition des lecons inline sans quitter la page
5. Sauvegarde automatique en arriere-plan
6. Design modernise et plus reactif

**[ECRAN — screencast compatibilite]**

[Montre les reglages de mise a jour TutorLMS]

Note importante : le Course Builder 3.0 est disponible a partir de TutorLMS 3.0. Si tu es sur une version anterieure, tu verras l'ancien builder. Pour verifier ta version, va dans Plugins dans le menu WordPress et regarde le numero de version a cote de TutorLMS. La mise a jour se fait comme n'importe quel plugin WordPress.

**[TRANSITION — face camera]**

Le Course Builder 3.0 rend la creation de cours nettement plus fluide. Interface claire, drag & drop, edition inline, sauvegarde auto — tout est pense pour te faire gagner du temps. Tu as maintenant les cles pour creer des cours depuis le backend et le frontend de TutorLMS. Le quiz qui suit va te permettre de valider tout ca.

---

**Points cles** :
- Course Builder 3.0 : interface pleine page avec navigation par onglets
- Drag & drop natif pour reorganiser topics, lecons et quiz
- Edition des lecons en inline sans quitter le curriculum
- Sauvegarde automatique en arriere-plan
- Disponible a partir de TutorLMS 3.0 — verifier la version du plugin
- Bouton Preview pour voir le cours cote etudiant avant publication
