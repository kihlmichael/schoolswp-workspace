**[INTRO — face camera]**

Dans cette lecon, je te montre pourquoi une Bio Link Page ClickWhale est une meilleure solution — gratuite, hebergee chez toi, et bonne pour ton SEO.

**[ECRAN — slide "Bio Link Page, c'est quoi ?"]**

Une Bio Link Page, c'est une page qui regroupe tous tes liens importants sur une seule URL. Tu la partages dans ta bio Instagram, ton profil LinkedIn, ta chaine YouTube, ou meme sur une carte de visite.

La difference avec Linktree, Koji ou Beacons ? Ta Bio Link Page ClickWhale est hebergee directement sur ton site WordPress. C'est une page de ton domaine. Pas un sous-domaine d'un service tiers.

**[ECRAN — slide comparatif "Linktree vs ClickWhale Bio Link Page"]**

Comparons concretement.

Le cout. Linktree gratuit est tres limite. Le plan Pro coute 5 dollars par mois, soit 60 dollars par an. ClickWhale ? Inclus dans le plugin gratuit. Zero cout supplementaire.

Le branding. Linktree gratuit affiche son logo en bas de ta page. Avec ClickWhale, aucun branding force. Ta page, ton design, ton domaine.

Le SEO. C'est le point le plus important. Une page Linktree vit sur linktr.ee. Les liens, le trafic, l'autorite — tout ca profite a Linktree, pas a toi. Avec ClickWhale, ta bio link page est sur tonsite.com/links. Google peut l'indexer. Les visites comptent pour ton domaine.

Les donnees. Linktree collecte les donnees de tes visiteurs. Avec ClickWhale, tout reste dans ta base de donnees WordPress.

[Montre une bio link page ClickWhale en front-end]

Voici a quoi ca ressemble. Une page simple, epuree, avec tes liens principaux. Chaque bouton renvoie vers une URL de ton choix. Le visiteur clique, il est redirige.

Tu peux ajouter jusqu'a 10 liens par page. C'est largement suffisant pour une bio link page. L'objectif n'est pas d'avoir 50 liens — c'est de diriger tes visiteurs vers les pages qui comptent.

**[ECRAN — slide "Pour qui ?"]**

A qui ca sert concretement ?

Si tu as un compte Instagram pro ou createur, tu n'as qu'un seul lien cliquable dans ta bio. Une bio link page te donne acces a tous tes liens importants depuis cette URL unique.

Meme logique pour LinkedIn. Tu peux mettre ta bio link page comme site web dans ton profil.

Pour YouTube, tu peux l'ajouter dans la description de tes videos ou dans la section "A propos" de ta chaine.

Et pour le monde physique : imprime un QR code de ta bio link page sur ta carte de visite. On verra comment generer un QR code dans le Module 4.

### Lecon 3.5 — Optimise le SEO de ta page (titre, meta description, slug)

**Duree** : 5 min
**Type** : Video HeyGen
**Ecran** : Face camera pour intro/conclusion, screencast de l'onglet SEO

---

**[INTRO — face camera]**

C'est la que ta bio link page prend un vrai avantage sur Linktree. Elle est hebergee sur ton domaine, donc Google peut l'indexer. Encore faut-il configurer correctement le SEO. C'est ce qu'on fait dans cette lecon.

**[ECRAN — screencast editeur, onglet SEO]**

[Ouvre une bio link page, clique sur l'onglet SEO]

Etape 1 : ouvre ta bio link page et clique sur l'onglet SEO. Tu vas trouver trois champs.

**[ECRAN — screencast champ Title]**

[Montre le champ Title]

Premier champ : Title tag. C'est le titre qui apparait dans l'onglet du navigateur et dans les resultats Google. C'est la premiere chose que les gens voient.

[Tape un exemple de titre]

Ecris un titre clair et descriptif. Par exemple : "Tous les liens schoolsWP — formations, articles, contact". Ou plus court : "Liens schoolsWP".

La regle : entre 50 et 60 caracteres. Au-dela, Google tronque le titre dans les resultats de recherche.

**[ECRAN — screencast champ Meta Description]**

[Montre le champ Meta Description]

Deuxieme champ : Meta description. C'est le texte qui apparait sous le titre dans les resultats Google. C'est ce qui donne envie de cliquer — ou pas.

[Tape un exemple de meta description]

Exemple : "Retrouve toutes les ressources schoolsWP : formation WordPress gratuite, derniers articles, newsletter et contact direct."

La regle : entre 140 et 160 caracteres. Sois precis sur ce que le visiteur va trouver sur la page.

**[ECRAN — screencast champ Slug]**

[Montre le champ Slug — deja configure en 3.2]

Troisieme champ : le slug. Tu l'as deja configure dans la lecon 3.2. C'est la partie de l'URL apres ton domaine.

Les bons slugs pour une bio link page : /links, /bio, /liens, /go. Court, memorisable, facile a dicter a voix haute.

Evite les slugs longs ou avec des caracteres speciaux. "tonsite.com/links" est mieux que "tonsite.com/ma-page-de-tous-mes-liens-importants".

**[ECRAN — slide "Pourquoi c'est important"]**

[Affiche la slide avec le comparatif SEO]

Pourquoi prendre le temps de configurer ca ?

Parce qu'une page Linktree ne t'appartient pas. L'URL est linktr.ee/tonnom. Le trafic, l'autorite, les signaux SEO — tout ca profite a Linktree.

Ta bio link page ClickWhale est sur tonsite.com/links. Chaque visite renforce l'autorite de ton domaine. Si quelqu'un cherche ton nom ou ta marque sur Google, ta bio link page peut apparaitre dans les resultats. Avec Linktree, c'est la page de Linktree qui apparait — pas la tienne.

**[ECRAN — screencast analytics]**

[Montre la section analytics de la link page dans le dashboard ClickWhale]

Dernier point : les analytics. ClickWhale tracke automatiquement les vues de page et les clics sur chaque lien de ta bio link page. Pas besoin de configurer quoi que ce soit.

[Montre les statistiques de vues et de clics]

Tu peux voir combien de personnes ont visite ta page et sur quels liens elles ont clique. Ces donnees sont precieuses pour optimiser — si un lien n'est jamais clique, remplace-le ou deplace-le plus haut.

Ton SEO est configure, tes analytics tournent. Dans la prochaine lecon, on va ajouter un formulaire directement sur ta bio link page pour capturer des emails.

## Exercice M3 — Cree ta bio link page complete

### Objectif

Creer une bio link page ClickWhale complete, personnalisee et optimisee, prete a etre partagee dans ta bio Instagram, ton profil LinkedIn ou ta chaine YouTube.

### Ce que tu dois faire

#### 1. Cree une nouvelle Bio Link Page

- Va dans ClickWhale > Link Pages > Add New
- Titre : le nom de ta marque ou de ton site (ex: "Liens schoolsWP")
- Slug : `/links` ou `/bio`

#### 2. Ajoute 5 liens (dans cet ordre de priorite)

| # | Lien | Exemple de texte bouton | Type de bloc |
|---|------|------------------------|--------------|
| 1 | Ta formation ou ressource gratuite | "Acces a la formation gratuite" | Link |
| 2 | Ton dernier article de blog | (titre de l'article) | Post |
| 3 | Ta page d'inscription newsletter | "Recois mes conseils chaque semaine" | Link |
| 4 | Ta page de contact | "Me contacter" | Link |
| 5 | Ta page a propos | "Qui suis-je ?" | Link |

Ajoute des blocs Heading pour structurer la page :
- "Ressources" avant les liens 1 et 2
- "Reste en contact" avant les liens 3, 4 et 5

#### 3. Ajoute 1 formulaire de capture email

- Prerequis : avoir Fluent Forms (ou un des 4 plugins supportes) installe avec un formulaire d'optin cree
- Le formulaire doit contenir au minimum : champ email + bouton d'envoi
- Place-le entre le lien 2 et le heading "Reste en contact"

#### 4. Personnalise les styles

- Background Color : la couleur de fond de ta charte graphique
- Text Color : une couleur contrastee avec le fond
- Button Color : ta couleur d'action principale
- Hover Color : une variante plus foncee/claire de ta couleur de bouton

#### 5. Configure le SEO

- Title tag : "[Ton nom/marque] — Tous mes liens" (50-60 caracteres)
- Meta description : description claire de ce que le visiteur trouvera (140-160 caracteres)
- Slug : verifie qu'il est court et memorisable
