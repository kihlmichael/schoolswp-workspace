# Script video — Module 3, Lecon 2 : Conversational forms

**Formation** : FluentForms Masterclass Formulaires
**Code** : FRM-012 (premium)
**Module** : 3 — Formulaires avances
**Lecon** : 2/8 — Conversational forms
**Duree** : 10 min (~1300 mots)
**Type** : Video HeyGen + voix ElevenLabs
**Ecran** : Face camera intro/outro, screencast activation et personnalisation
**Objectif** : Creer un formulaire conversationnel une question a la fois pour maximiser le taux de completion

---

**[INTRO — face camera]**

Tu connais Typeform ? L'outil de formulaires ou les questions apparaissent une par une, en plein ecran, avec une navigation au clavier. C'est elegant, fluide, et les taux de completion sont parmi les meilleurs du marche.

FluentForms integre cette fonctionnalite nativement. Pas de plugin supplementaire, pas d'abonnement Typeform a 29 dollars par mois. Tu actives le mode conversationnel, et ton formulaire se transforme.

**[ECRAN — screencast "Activer le mode conversationnel"]**

Ouvre un formulaire existant ou cree-en un nouveau.

Va dans Form Settings → Form Layout → Form Type.

Par defaut, le type est "Classic". Change-le en "Conversational".

C'est fait. Le formulaire entier bascule en mode conversationnel. Les memes champs, la meme logique conditionnelle, les memes notifications — mais l'affichage change completement.

**[ECRAN — screencast "L'experience visiteur"]**

Voyons ce que le visiteur voit.

Le formulaire prend toute la page. Fond colore, une seule question au centre. Pas de sidebar, pas de header, pas de footer. L'attention est concentree sur la question.

Le visiteur repond et appuie sur Entree ou clique sur le bouton "OK". La question suivante apparait avec une transition fluide. La precedente glisse vers le haut.

La navigation au clavier fonctionne : Entree pour passer a la question suivante, fleche haut pour revenir en arriere. Pour les champs select, les touches 1-9 selectionnent les options directement.

Une barre de progression en bas indique l'avancement. "3 sur 8" ou un pourcentage.

**[ECRAN — screencast "Design du mode conversationnel"]**

Le design est personnalisable.

Couleur de fond : choisis une couleur qui represente ta marque. Pas du blanc — le fond colore est la signature du mode conversationnel.

Image de fond : tu peux mettre une image au lieu d'une couleur unie. Attention a la lisibilite du texte par-dessus.

Couleur du texte des questions, couleur des boutons, couleur de la barre de progression.

Police : tu peux changer la typographie pour correspondre a ton site.

Logo : ajoute ton logo en haut a gauche pour le branding.

Message de bienvenue : un ecran d'accueil avant la premiere question. Titre, description, bouton "Commencer". Ca donne le contexte avant de lancer le questionnaire.

Message de fin : un ecran de remerciement apres la derniere question. Personnalisable.

**[ECRAN — slide "Quand utiliser le conversationnel"]**

Le mode conversationnel n'est pas adapte a tous les formulaires. Voici quand l'utiliser.

Ideal pour : les sondages, les quiz, les enquetes de satisfaction, les formulaires de qualification de leads, les formulaires a fort taux de completion. Tout ce qui ressemble a une conversation.

Pas ideal pour : les formulaires de contact rapides (3 champs — autant rester en classique), les formulaires de paiement complexes (le visiteur a besoin de voir le recapitulatif), les formulaires avec beaucoup de champs conditionnels imbriques (la navigation une question a la fois peut devenir confuse).

La regle : si ton formulaire a entre 5 et 15 questions et que l'objectif est que le visiteur aille jusqu'au bout, le mode conversationnel est fait pour ca.

**[ECRAN — screencast "Logique conditionnelle en mode conversationnel"]**

Bonne nouvelle : la logique conditionnelle fonctionne exactement pareil en mode conversationnel.

Si un champ est masque par une condition, la question correspondante est tout simplement sautee. Le visiteur passe directement a la question suivante visible. La barre de progression s'adapte automatiquement.

Exemple : question 3 "Type de projet" = Blog. Question 4 "Nombre de produits" (condition : type = E-commerce) est sautee. Le visiteur passe directement a la question 5. Il ne sait meme pas qu'une question a ete ignoree.

**[ECRAN — screencast "Cas pratique — sondage satisfaction"]**

Construisons un sondage de satisfaction en mode conversationnel.

Formulaire : "Sondage satisfaction — schoolsWP".

Champs :
1. Ratings "Note globale" — 1 a 5 etoiles
2. Radio "Recommanderais-tu schoolsWP ?" — Oui, Peut-etre, Non
3. Checkbox "Qu'est-ce qui t'a le plus aide ?" — Articles, Formations video, Outils, Communaute
4. Textarea "Qu'est-ce qu'on pourrait ameliorer ?" — optionnel
5. NPS "De 0 a 10, quelle est la probabilite que tu recommandes schoolsWP ?"
6. Email "Ton email (optionnel, pour te recontacter)"

Six questions. En mode classique, c'est court. En mode conversationnel, c'est une experience engageante.

J'active le mode conversationnel. Fond bleu fonce, texte blanc, logo schoolsWP en haut a gauche. Message de bienvenue : "Aide-nous a nous ameliorer — 2 minutes suffisent."

En preview : la premiere question apparait en grand. Les etoiles sont cliquables, bien visibles. Je clique sur 4 etoiles, Entree. Question suivante. Radio "Recommanderais-tu..." — je clique sur "Oui", Entree. Et ainsi de suite.

Le rythme est naturel. C'est comme une conversation, pas comme un formulaire.

**[ECRAN — slide "Conversational vs Multi-step"]**

Question frequente : conversationnel ou multi-step ?

Multi-step : plusieurs champs par etape. Adapte aux formulaires utilitaires (candidature, inscription, devis). Le visiteur remplit, valide, passe a la suite.

Conversationnel : un champ par ecran. Adapte aux formulaires d'engagement (sondage, quiz, qualification). Le visiteur repond comme dans une conversation.

Les deux sont Pro. Les deux augmentent le taux de completion. Choisis en fonction du contexte.

Conseil : si le visiteur a BESOIN de remplir le formulaire (candidature, inscription obligatoire), le multi-step suffit. Si tu as besoin de CONVAINCRE le visiteur de remplir le formulaire (sondage optionnel, quiz), le conversationnel est plus efficace.

**Points cles** :
- Mode conversationnel : une question a la fois, plein ecran, navigation clavier
- Activer : Form Settings → Form Type → Conversational
- Design : couleur de fond, logo, message de bienvenue et de fin
- Logique conditionnelle : les questions masquees sont sautees automatiquement
- Ideal pour sondages, quiz, qualification — pas pour les formulaires utilitaires
- Alternative gratuite a Typeform (inclus dans FluentForms Pro)
