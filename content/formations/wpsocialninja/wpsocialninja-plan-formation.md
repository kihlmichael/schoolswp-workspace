## Faisabilité page « Vidéos » (confirmée par la doc)

- **Source « Specific Videos »** : curation manuelle par ID vidéo (plusieurs IDs séparés par virgule). Filtres : masquer des vidéos, ordre (récent/ancien/aléatoire).
- **4 sections par thème** : un template par thème, chacun avec son shortcode `[wp_social_ninja id="X" platform="youtube"]`, posés sur la même page.
- **Layout Grid** : gratuit (la grille de la maquette). Skins Vega/Sirius/Polaris/Rigel. Gallery, compteurs likes/commentaires : Pro.
- **Prérequis** : clé API YouTube Data v3 (projet Google Cloud gratuit) ou OAuth Google.
