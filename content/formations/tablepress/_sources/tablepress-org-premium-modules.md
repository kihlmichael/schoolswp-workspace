---

Les plans TablePress Premium (Pro et Max) ajoutent le support email prioritaire et de nombreuses
fonctionnalités au-delà de la version gratuite. Chaque module Premium dispose de sa propre page
(description, mode d'emploi, exemples, documentation).

## Frontend & Styling

| Module | Description | URL |
| --- | --- | --- |
| Responsive Tables (fortement amélioré) | Tables lisibles sur toutes les tailles d'écran | /modules/responsive-tables/ |
| Default Style Customizer | Personnaliser le style par défaut via un outil visuel | /modules/default-style-customizer/ |
| Fixed Rows and Columns | Figer en-tête, pied et premières/dernières colonnes au scroll | /modules/datatables-fixedheader-fixedcolumns/ |
| User Action Buttons | Boutons télécharger, copier, imprimer, visibilité des colonnes | /modules/datatables-buttons/ |
| Row Grouping | Grouper les lignes par mot-clé, catégorie ou titre | /modules/datatables-rowgroup/ |
| Cell Highlighting | Classes CSS sur les cellules selon leur contenu | /modules/cell-highlighting/ |
| Row Highlighting | Classes CSS sur les lignes selon leur contenu | /modules/row-highlighting/ |
| Index Column | Première colonne en compteur de position de ligne | /modules/datatables-counter-column/ |
| Table Layout | Personnaliser disposition et position des éléments autour de la table | /modules/datatables-layout/ |
| Advanced Pagination | Paramètres de pagination personnalisés | /modules/datatables-pagination/ |
