## Les trois niveaux

### Basic (gratuit)

Le socle solide pour tous les besoins de tableaux :

- Gestion et édition faciles des tables
- Tables illimitées, sans limite de taille
- Tables accessibles et SEO-friendly
- Intégration via Bloc, Widget ou Shortcode
- Import depuis fichiers et URLs (Excel, CSV, HTML, JSON)
- Export des tables (CSV, HTML, JSON, ZIP)
- Formules mathématiques type Excel
- Options de table de base (tri, recherche, pagination, scroll horizontal)
- Style manuel via code CSS

Téléchargement : `https://downloads.wordpress.org/plugin/tablepress.latest-stable.zip`

### Pro - 89 $/an (le plus populaire)

« Perfect for individuals and small sites. » Inclut tout Basic +

- Support email direct
- Responsive Tables
- Fixed Rows and Columns
- Visual Default Style Customizer
- User Action Buttons
- Row Grouping
- Table Layout + Advanced Pagination
- Cell + Row Highlighting
- Index and Counter Column
- Filter Dropdowns + Individual Column Filtering
- Alphabet Search, Search Highlighting, Search Panes, Automatic Filtering
- Column + Row Order
- Row Filtering
- Automatic Table Export

### Max - 189 $/an

« Ideal for professionals and businesses. » Inclut tout Pro +

- Support email prioritaire avec Personal Success Manager
- Automatic Periodic Table Import
- Advanced Access Rights
- Advanced Loading
- Server-side Processing
- Inverted Filtering
- Fuzzy Search
- Custom Search Builder
- Email Notifications
- REST API

## Conditions commerciales

- Licences pour 1, 5, 25 ou 100 sites (packs multi-sites remisés au checkout).
- Abonnement annuel (renouvellement automatique, mises à jour + support 1 an) OU licence à vie (paiement unique, sans expiration).
- Changement de plan possible à tout moment (upgrade au prorata, downgrade en extension).
- Paiement : cartes (Visa, Mastercard, Amex), PayPal, virement SEPA pour les entreprises UE avec n° de TVA (licence à vie).
- Vendeur officiel (Merchant of Record) : Freemius, Inc.
- TVA/GST en sus selon localisation.
- Garantie 100 % remboursé sous 30 jours, sans justification (hors paiements de renouvellement automatique).
- Sites de dev/test/staging/localhost : pas de licence séparée, inclus avec la licence du site de production.
- À l'expiration d'une licence : les tables et données restent, mais plus de fonctions premium, plus de mises à jour (y compris sécurité), plus de support direct.

## Délais de support

Réponse visée sous 12 h les jours ouvrés (lundi-vendredi, 8 h-16 h CET). Max : messages remontés en tête de file automatiquement.

## Installation (rappel officiel)

- Option 1 : écran « Extensions » → « Ajouter » → rechercher « TablePress » → « Installer » → « Activer ».
- Option 2 : télécharger le ZIP → « Ajouter une extension » → « Téléverser une extension » → choisir le ZIP → « Installer » → « Activer ».
- Après activation d'une licence Premium, la version gratuite (si présente) peut être supprimée. Toutes les tables et réglages continuent de fonctionner.
