# Formation TablePress - dossier source

> **Statut : matière brute. La formation n'est pas encore produite.**

Ce dossier rassemble la matière scrappée sur le site officiel TablePress, en vue d'une **future
formation schoolsWP** sur le plugin TablePress. Rien ici n'est destiné à la publication tel quel :
c'est du matériau de travail.

## Précautions avant de produire la formation

- **Tarifs et versions évoluent** : revérifier prix (89 $/189 $), liste des modules et numéro de version avant tout enregistrement.
- **Licence du contenu** : le matériau ici est issu du site officiel TablePress (Tobias Bäthge, tous droits réservés). Il sert de référence pédagogique. La formation schoolsWP doit être un contenu original (captures, exemples et formulations propres), pas une copie.
- **Stack de livraison schoolsWP** : TutorLMS (cours) + FluentCart (checkout) - voir `reference_formation_template_schoolswp` en mémoire.
- **Branding** : appliquer BRAND_RULES schoolsWP (tutoiement, voix au « je », pas d'em-dash).
