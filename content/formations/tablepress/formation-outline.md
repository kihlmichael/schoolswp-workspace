# Formation TablePress - ossature proposée

> Brouillon d'ossature dérivé du scrape officiel (2026-05-21). Point de départ, pas une version figée.
> À arbitrer avec Michael avant production.

## Positionnement

- **Cible** : freelances WordPress, créateurs de contenu, petites équipes qui gèrent des données structurées (comparatifs, catalogues, tarifs, statistiques) sans coder.
- **Promesse** : créer, styliser, rendre interactives et automatiser des tableaux WordPress propres, rapides et accessibles avec TablePress, du gratuit jusqu'aux fonctions Premium.
- **Pré-requis** : un site WordPress fonctionnel, aucune compétence en code exigée.
- **Format pressenti** : cours TutorLMS + checkout FluentCart (stack formation schoolsWP).

## Modules

### Module 1 - Découvrir TablePress
- Le plugin, son histoire (depuis 2008), 750 000+ sites actifs, l'auteur Tobias Bäthge.
- Quand TablePress est le bon choix (vs tableaux natifs Gutenberg, vs Ninja Tables, vs WP Table Builder).
- Basic / Pro / Max : ce que chaque niveau débloque, comment décider.
- Installer et activer le plugin (les 2 méthodes officielles).

### Module 2 - Créer et gérer ses premières tables
- L'interface type tableur : lignes, colonnes, cellules.
- Importer des données existantes : Excel, CSV, HTML, JSON, depuis un fichier ou une URL.
- Exporter une table (CSV, HTML, JSON, ZIP) - sauvegarde et portabilité.
- Organiser sa bibliothèque de tables (nommage, recherche par nom).

### Module 3 - Intégrer une table dans le contenu
- Le bloc Gutenberg TablePress (recommandé) : recherche par nom, aperçu direct.
- Le shortcode `[table id=...]` : flexibilité, thèmes anciens, page builders.
- Le widget.
- Cas page builders : Elementor, Divi, Bricks.

### Module 4 - Rendre les tables interactives (fonctions de base, gratuites)
- Tri, recherche/filtre, pagination, scroll horizontal.
- Réglages par table : ce qui est pertinent selon le type de données.
- Bonnes pratiques UX pour les visiteurs.

### Module 5 - Mettre en forme ses tables
- Style manuel via « Custom CSS » : sélecteurs et exemples.
- Default Style Customizer (Premium) : variations visuelles sans code.
- Cell Highlighting et Row Highlighting (Premium) : mise en évidence conditionnelle.

### Module 6 - Tables responsive et accessibilité
- Responsive Tables (Premium) : comportement sur mobile/tablette/desktop.
- Accessibilité native : structure sémantique, ARIA, lecteurs d'écran.
- Tables SEO-friendly : ce que Google lit.

### Module 7 - Recherche, filtres et données avancées (Premium)
- Filtres par colonne, dropdowns, Search Panes, Alphabet Search.
- Fuzzy Search, Custom Search Builder, Inverted Filtering.
- Row Grouping, Fixed Rows and Columns, Index Column.
- Column/Row Order, Row Filtering.

### Module 8 - Automatisation et performance (Premium Max)
- Automatic Periodic Table Import : synchroniser une table depuis une source externe.
- Server-side Processing et Advanced Loading : tenir les très grandes tables.
- Automatic Table Export, Email Notifications.
- REST API : exploiter les données ailleurs.
- Advanced Access Rights : restreindre l'accès par utilisateur.

### Module 9 - Formules et données calculées
- Formules type Excel dans les cellules : syntaxe, cas d'usage.

### Module 10 - Maintenir et faire évoluer ses tables
- Suivre les versions de TablePress (exemple concret : ce qu'apporte la 3.3).
- Mettre à jour sans risque : sauvegarde JSON, test en staging.
- Gérer une licence Premium (renouvellement, multi-sites, expiration).

## Idées d'exercices fil rouge

- Construire un tableau comparatif réel (ex. comparatif d'outils) de A à Z.
- Importer un CSV de catalogue produits, le rendre filtrable, le styliser.
- Mettre en place un import périodique automatique depuis un Google Sheet.
