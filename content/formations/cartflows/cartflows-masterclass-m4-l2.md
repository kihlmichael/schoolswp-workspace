# Lecon 4.2 — Creer ton premier order bump

## Metadata

- **Formation** : CartFlows Masterclass Vente (premium — FRM-007)
- **Module** : 4 — Order Bumps
- **Duree cible** : 8 min (~1100 mots)
- **Type** : Video HeyGen + voix ElevenLabs
- **Objectif pedagogique** : Creer un order bump fonctionnel dans CartFlows Pro — de la selection du produit a la configuration du style, en passant par le texte de l'offre et le test.

---

## Script narration

**[INTRO — face camera]**

Tu sais ce qu'est un order bump et pourquoi ca fonctionne. Maintenant on passe a la pratique. Dans cette lecon, tu vas creer ton premier bump dans CartFlows, de A a Z.

Prerequis : ton produit bump doit deja exister dans WooCommerce. Si tu veux proposer un pack de templates a 17 euros, ce produit doit etre cree dans WooCommerce avant de le configurer comme bump. CartFlows ne cree pas de produits — il les utilise.

---

**[SECTION 1 — Acceder aux order bumps]**

**[ECRAN — CartFlows → Flow → Step Checkout]**

Ouvre ton flow dans CartFlows. Clique sur le step Checkout — c'est la page ou le client remplit ses informations de paiement.

Dans les onglets du step, tu vas voir "Order Bump". C'est la que tout se passe. Clique dessus.

**[ECRAN — onglet Order Bump vide]**

Si c'est ton premier bump, l'ecran est vide. Tu vas cliquer sur "Add Order Bump" pour en creer un nouveau.

---

**[SECTION 2 — Selectionner le produit bump]**

**[ECRAN — configuration du bump — champ produit]**

Premiere etape : selectionner le produit. CartFlows te propose un champ de recherche. Tape le nom de ton produit WooCommerce — par exemple "Pack Templates Bonus".

Le produit apparait dans la liste. Selectionne-le. CartFlows recupere automatiquement le prix depuis WooCommerce.

Si tu veux proposer un prix reduit pour le bump — par exemple 17 euros au lieu de 27 euros — tu peux definir un prix special directement ici. C'est le "Discount Type". Tu choisis entre un pourcentage de reduction ou un prix fixe. Pour un bump, je te recommande le prix fixe : c'est plus clair pour le client.

**[ECRAN — prix special configure]**

Dans notre exemple : produit WooCommerce a 27 euros, prix bump a 17 euros. Le client voit 17 euros sur le checkout. Le prix barre n'est pas affiche par defaut — on verra comment l'ajouter dans la lecon sur le copywriting.

---

**[SECTION 3 — Position du bump]**

**[ECRAN — options de position]**

CartFlows te laisse choisir ou le bump apparait sur le checkout. Tu as plusieurs options.

"Before Checkout" — le bump apparait avant le formulaire de paiement. Le client le voit en premier, avant meme de remplir ses informations. C'est agressif mais visible.

"After Customer Details" — le bump apparait apres les informations client (nom, email, adresse) mais avant les champs de paiement. C'est la position que je recommande. Le client a deja commence a remplir le formulaire, il est engage. Le bump arrive au bon moment.

"After Order" — le bump apparait apres le recapitulatif de commande, juste avant le bouton "Commander". Derniere chance avant le clic. Efficace si le bump est tres complementaire au produit principal.

"After Payment" — le bump apparait sous les options de paiement. Peu visible, rarement recommande.

Pour ton premier bump, choisis "After Customer Details". C'est le meilleur compromis entre visibilite et moment psychologique.

---

**[SECTION 4 — Style du bump]**

**[ECRAN — options de style]**

CartFlows propose plusieurs styles visuels pour le bump.

"Style 1" — un encadre avec une case a cocher, le titre du bump et une description courte. Classique et efficace.

"Style 2" — un encadre plus large avec une image du produit a gauche et le texte a droite. Plus visuel, ideal si ton produit bump a une image parlante.

"Highlight" — un encadre avec une bordure coloree qui attire l'oeil. Utile quand tu veux que le bump se demarque clairement du reste du formulaire.

Choisis le style qui correspond a ton produit. Pour un produit digital (templates, ebook, acces communaute), le Style 1 suffit. Pour un produit avec une image forte, le Style 2 est plus adapte.

Tu peux personnaliser les couleurs de bordure, de fond et du texte pour matcher le design de ton checkout. Reste coherent avec ton theme Kadence — le bump doit s'integrer visuellement, pas detoner.

---

**[SECTION 5 — Texte de l'offre]**

**[ECRAN — champs titre et description du bump]**

Le texte du bump, c'est ce qui fait la difference entre 5 pourcent de taux de prise et 25 pourcent. On fera une lecon complete sur le copywriting, mais pour ton premier bump, voici les bases.

Titre : "Ajoute le Pack Templates Bonus pour seulement 17 euros". Direct, clair, avec le prix. Le client comprend en une seconde ce qu'il obtient et combien ca coute.

Description : "12 templates Gutenberg pretes a l'emploi — gagne 3 heures de travail des ta premiere utilisation." Une phrase, un benefice concret, un chiffre. Pas de paragraphe, pas d'argumentaire. Le bump doit se lire en 5 secondes.

Le label de la case a cocher : "Oui, j'ajoute le pack !" — affirmatif, engageant. Evite les formulations negatives ou ambigues.

---

**[SECTION 6 — Preview et test]**

**[ECRAN — preview du checkout avec le bump]**

Sauvegarde ta configuration. Maintenant, ouvre ton checkout en mode preview — soit via le bouton "Preview" dans CartFlows, soit en visitant l'URL du checkout directement.

**[ECRAN — checkout avec le bump visible]**

Verifie trois choses. Un : le bump est visible et bien positionne. Deux : le texte est lisible et le prix est correct. Trois : quand tu coches la case, le recapitulatif de commande se met a jour avec le produit bump et le nouveau total.

**[ECRAN — recapitulatif mis a jour apres cochage]**

Fais un achat test. Utilise un produit gratuit ou un coupon de reduction a 100 pourcent. Verifie que la commande dans WooCommerce contient bien le produit principal et le produit bump. Verifie que les prix sont corrects.

Ce test prend 2 minutes. Il t'evite de decouvrir un probleme quand un vrai client essaie de commander.

---

**[OUTRO — face camera]**

Ton premier order bump est en place. Un produit, un texte, une position, un style. C'est la base. Dans la prochaine lecon, on va voir comment empiler plusieurs bumps sur un meme checkout — et surtout comment le faire sans agresser le client.
