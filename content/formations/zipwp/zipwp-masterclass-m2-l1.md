# Lecon 2.1 - Astra : personnaliser le theme genere

## Metadata

- **Formation** : ZipWP Masterclass Business (FRM-010)
- **Module** : 2 - Personnalisation avancee
- **Lecon** : 1/8
- **Duree cible** : 10 min
- **Objectif pedagogique** : Maitriser le Customizer Astra pour personnaliser header, footer, couleurs, typographie et layout global du site genere.
- **Production** : HeyGen (avatar) + voix ElevenLabs (FR)

## Script narration

[INTRO]

Ton site est genere. Il a l'air correct. Mais il a exactement le meme look que tous les sites generes par ZipWP avec des parametres similaires. Pour qu'il devienne TON site, tu dois personnaliser le theme - et le theme, c'est Astra.

Astra se configure principalement via le Customizer de WordPress - Apparence, puis Personnaliser. C'est la que tu vas definir l'identite visuelle de ton site. Et la bonne nouvelle, c'est que tout se fait en visual - tu vois les changements en temps reel.

---

[SECTION 1 - Le header : logo, menu, bouton CTA]

Le header, c'est la barre du haut - celle qui apparait sur toutes les pages. C'est la premiere chose que tes visiteurs voient. Commence par la.

Dans le Customizer, va dans "Header Builder". Astra utilise un systeme de zones - gauche, centre, droite - ou tu places les elements par glisser-deposer.

Le logo. Clique sur l'element logo et uploade ton fichier. Pense a uploader deux versions : le logo normal et le logo retina (2x la taille). Definis aussi la largeur maximale - 150 a 200 pixels suffisent generalement.

Le menu. Il est deja cree par ZipWP avec les pages generees. Tu peux le reorganiser dans Apparence → Menus, puis l'assigner au header dans le Customizer. Verifie l'ordre des elements et supprime les pages inutiles.

Le bouton CTA. C'est un element optionnel mais recommande. Dans le Header Builder, ajoute un element "Button" dans la zone droite. Configure le texte - "Prendre rendez-vous", "Devis gratuit", "Nous contacter" - et le lien vers ta page de conversion. Choisis une couleur qui contraste avec le reste du header.

---

[SECTION 2 - Le footer : colonnes, widgets, credits]

Le footer, c'est la barre du bas. Souvent negligee, elle est pourtant visible sur chaque page.

Dans le Customizer, va dans "Footer Builder". Meme principe que le header - des zones ou tu places des elements.

La structure classique pour un site business : 3 ou 4 colonnes. Premiere colonne : logo + description courte de l'entreprise. Deuxieme colonne : liens rapides (Accueil, Services, Contact). Troisieme colonne : coordonnees (adresse, telephone, email). Quatrieme colonne optionnelle : reseaux sociaux.

Les credits en bas - "Powered by Astra / WordPress" - tu peux les modifier ou les supprimer dans les reglages du footer. Remplace-les par ton copyright : "2026 Nom de ton entreprise. Tous droits reserves."

Conseil : personnalise le header et le footer en premier. Ce sont les elements qui se repetent sur toutes les pages. Chaque minute investie ici a un impact sur 100% de ton site.

---

[SECTION 3 - Les couleurs globales]

Astra gere les couleurs a travers une palette globale. Dans le Customizer, va dans "Global" → "Colors".

Tu y trouves les couleurs principales : primaire (la couleur dominante - boutons, liens, accents), secondaire, et les neutres (texte, fond, bordures). Chaque couleur que tu modifies ici se repercute sur tout le site.

Si tu as une charte graphique, entre tes codes hex. Si tu n'en as pas, choisis 2 couleurs maximum : une couleur principale (celle de ta marque) et une couleur d'accent (pour les boutons et les CTA). Le reste doit rester neutre - blanc, gris clair, noir ou gris fonce pour le texte.

Erreur frequente : mettre trop de couleurs. Un site professionnel utilise 2-3 couleurs, pas 7. La sobriete inspire confiance.

---

[SECTION 4 - La typographie]

Toujours dans "Global", va dans "Typography". C'est la que tu definis les polices de caracteres.

Astra te propose deux reglages principaux : la police des titres (H1 a H6) et la police du corps de texte. Tu peux choisir parmi les Google Fonts - il y en a des centaines.

Mon conseil : choisis une police lisible pour le corps de texte - Inter, Open Sans, Lato, Nunito - et une police avec du caractere pour les titres - Playfair Display, Montserrat, Poppins. Deux polices maximum.

Definis aussi les tailles. Pour le corps de texte : 16 a 18 pixels sur desktop, 15 a 16 pixels sur mobile. Pour le H1 : 36 a 48 pixels sur desktop. Ces valeurs sont des standards web qui assurent une bonne lisibilite.

---

[SECTION 5 - Le layout global]

Le layout, c'est la mise en page generale - la largeur du contenu, les marges, les sidebars.

Dans le Customizer, va dans "Global" → "Container". Tu peux definir la largeur maximale du contenu - 1200 pixels est un standard confortable. Tu peux aller jusqu'a 1400 si tu veux un site plus aere.

Les pages generees par ZipWP sont generalement en full-width - pas de sidebar. C'est la norme pour les sites modernes. Si tu veux ajouter une sidebar (par exemple pour un blog), tu peux le configurer page par page dans les meta-options Astra.

Le layout de page : full-width (le contenu occupe toute la largeur) ou boxed (le contenu est contenu dans une boite avec des marges laterales). Full-width est plus moderne, boxed est plus classique. Choisis selon ton secteur.

---

[OUTRO]

Tu sais maintenant personnaliser les 5 piliers d'Astra : header, footer, couleurs, typographie, layout. Ces reglages definissent l'identite visuelle de ton site sur chaque page.

Dans la prochaine lecon, on passe a Spectra - le page builder qui te permet de modifier le contenu de chaque page en profondeur. Astra gere le cadre. Spectra gere ce qu'il y a dedans.
