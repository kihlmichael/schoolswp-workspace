# Lecon 4 — Ajouter une page et un formulaire

## Metadata

- **Formation** : ZipWP Quick Start (offerte — FRM-009)
- **Lecon** : 4/5
- **Duree cible** : 5 min
- **Objectif pedagogique** : Creer une nouvelle page et ajouter un formulaire de contact fonctionnel avec SureForms.
- **Production** : HeyGen (avatar) + voix ElevenLabs (FR)

---

## Script narration

[INTRO]

Ton site a deja les pages de base generees par l'IA. Mais tu as peut-etre besoin d'une page supplementaire — un "A propos" plus detaille, une page "Tarifs", ou simplement un formulaire de contact qui fonctionne. C'est ce qu'on fait dans cette lecon.

---

[SECTION 1 — Creer une nouvelle page]

Dans le dashboard WordPress, va dans Pages → Ajouter. Tu arrives sur l'editeur Gutenberg avec une page vierge.

Donne un titre a ta page — par exemple "Contact" ou "A propos".

Pour structurer le contenu, utilise les blocs Spectra. Clique sur le "+" pour ajouter un bloc. Les blocs Spectra les plus utiles pour une page simple :

Container : pour creer une section avec un fond de couleur ou une image. Heading : pour les titres et sous-titres avec un controle precis de la typographie. Paragraph : le bloc natif WordPress pour le texte courant.

Construis ta page section par section. Pour une page "A propos" : un hero avec ton titre + une phrase d'accroche, une section qui raconte ton histoire, et une section avec tes valeurs ou tes chiffres cles.

---

[SECTION 2 — Ajouter un formulaire avec SureForms]

SureForms est le plugin de formulaires installe automatiquement par ZipWP. Il est deja actif — tu n'as rien a installer.

Dans l'editeur de ta page, clique sur "+" et cherche "SureForms". Tu vois le bloc "SureForms Form". Insere-le dans ta page.

SureForms te propose de creer un nouveau formulaire ou d'en selectionner un existant. Clique sur "Create New Form".

Tu arrives dans l'editeur de formulaire. Par defaut, tu as trois champs : Nom, Email, Message. C'est exactement ce qu'il faut pour un formulaire de contact basique.

Si tu veux ajouter un champ — telephone, sujet, case a cocher RGPD — clique sur "+" dans le formulaire et choisis le type de champ. Mais pour l'instant, garde les 3 champs de base. Simple et efficace.

---

[SECTION 3 — Configurer l'email de reception]

Dans les reglages du formulaire — onglet "Settings" ou icone engrenage — configure l'email de reception. C'est l'adresse a laquelle tu recevras les messages de tes visiteurs.

Par defaut, SureForms envoie a l'adresse admin de ton WordPress. Si tu veux une adresse differente, change-la ici.

Configure aussi le message de confirmation — le texte que le visiteur voit apres avoir envoye son message. Quelque chose comme "Merci pour ton message. Je te reponds sous 24 heures." Court, clair, rassurant.

Sauvegarde le formulaire, puis retourne sur ta page et sauvegarde-la aussi.

---

[SECTION 4 — Ajouter la page au menu]

Ta page existe mais elle n'est pas encore accessible depuis le menu de navigation.

Va dans Apparence → Menus. Si un menu existe deja — c'est le cas si ZipWP en a genere un — tu le vois dans la liste.

Dans la colonne de gauche, sous "Pages", coche ta nouvelle page et clique sur "Ajouter au menu". Glisse-la a l'endroit ou tu veux qu'elle apparaisse dans la navigation. Sauvegarde.

Verifie sur le front-end : ta page apparait dans le menu et le formulaire fonctionne. Fais un test — remplis le formulaire toi-meme et verifie que tu recois l'email.

---

[OUTRO]

Tu as maintenant un site avec une page supplementaire et un formulaire de contact fonctionnel. Tes visiteurs peuvent te joindre directement depuis ton site.

Dans la derniere lecon, on met tout ca en ligne — publication ou export vers ton hebergeur. C'est la derniere etape.
