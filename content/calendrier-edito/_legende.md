# Legende calendrier editorial

## Statuts

| Statut | Sens | Symbole |
| --- | --- | --- |
| `idea` | concept attribue a une date, pas encore drafte | 💡 |
| `draft` | brouillon en cours | ✏️ |
| `scheduled` | drafte, valide, programme | ⏰ |
| `published` | publie | ✅ |
| `killed` | abandonne | ❌ |

| Canal | Cadence cible | Plateforme cible |
| --- | --- | --- |
| `newsletter` | 1/semaine | FluentCRM (envoi) |
| `linkedin` | 2-3/semaine | LinkedIn (Blotato ou natif) |
| `bluesky` | 2-3/semaine | Bluesky (Blotato) |
| `pinterest` | 5-10 pins/semaine | Pinterest (n8n + Placid) |

| `youtube-shorts` | 1-3/semaine | YouTube Shorts |
| `blog` | 1-2/mois | schoolswp.com (WordPress) |
| `instagram` | 1-2 carrousels/semaine | Instagram (Blotato) |
| `reddit` | 1/semaine | Reddit (manuel) |
| `discord` | au fil de l'eau | Discord (community) |
| `email-promo` | adhoc | FluentCRM (campagnes) |
