# Plan Cluster — OttoKit / Automatisation WordPress

## Pilier

**Titre** : OttoKit : l'outil d'automatisation WordPress qui mérite qu'on s'y attarde
**Slug** : ottokit-automatisation-wordpress
**Angle** : Présentation complète d'OttoKit comme couche d'automatisation native pour les solopreneurs et freelances WordPress qui veulent réduire leurs dépendances SaaS sans sacrifier l'efficacité
**H2 principaux** :
- Ce qu'est vraiment OttoKit (et ce qu'il n'est pas)
- Pourquoi l'automatisation WordPress mérite une réflexion stratégique
- Ce que OttoKit permet concrètement (déclencheurs, actions, workflows multi-étapes)
- OttoKit face aux alternatives : critères de choix honnêtes
- Comment OttoKit s'installe et se configure
- Pour quel profil OttoKit est-il vraiment adapté ?
- FAQ — Les questions que tu te poses vraiment sur OttoKit
