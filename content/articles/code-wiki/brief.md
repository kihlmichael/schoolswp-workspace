# Brief - Code Wiki Google pour WordPress

## Sujet

Présenter Code Wiki (Google Labs, lancé le 13 novembre 2025) à un public de créateurs WordPress non développeurs, et montrer comment l'utiliser pour mieux comprendre les plugins de leur stack.

## Angle éditorial

Pas un article tech "pour devs". Un article schoolsWP qui rend lisible un outil sous le radar et donne 4 cas d'usage immédiats pour un freelance ou solopreneur WordPress. Ton : pédagogique, pratique, "je teste pour toi je te traduis".

## Pourquoi maintenant (3 raisons)

1. **Market gap FR** : aucune couverture francophone identifiée à ce jour (mai 2026). Premier sur le sujet en français = autorité GEO/AEO + citations LLM.
2. **Cohérence pilier outils** : prolonge la logique schoolsWP "stack maîtrisée plutôt que stack fourre-tout".
3. **Tremplin** : sert de base à une future rubrique "Sous le capot" qui décortiquera FluentCRM, OttoKit, TutorLMS via Code Wiki.

## Mot-clé principal et requêtes adjacentes

- Principal : `code wiki google`
- Adjacents : `comprendre plugin wordpress`, `auditer plugin wordpress`, `code wiki wordpress`
- Long tail GEO : "Comment auditer un plugin WordPress sans être développeur", "Code Wiki c'est quoi"

Volume actuel quasi nul en FR. Jeu = être le premier indexé pour quand le trafic arrive (sortie Gemini 3 le 18 nov 2025 a relancé l'attention sur l'écosystème Google AI).

## Cible lecteur

Créateur WordPress solo, niveau intermédiaire, qui :
- N'est pas développeur
- Installe régulièrement des plugins
- Veut faire des choix techniques mieux informés
- Lit déjà schoolsWP pour les avis/comparatifs

## Promesse

À la fin de l'article, le lecteur sait :
1. Ce qu'est Code Wiki
2. Comment l'ouvrir et l'utiliser en 2 minutes
3. 4 cas d'usage concrets pour son site WordPress
4. Une méthode en 5 étapes pour auditer un plugin avec
5. Les limites à connaître
