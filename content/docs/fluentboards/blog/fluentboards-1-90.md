## Bulk Actions in Table View
Managing multiple tasks just got a whole lot easier!
![Bulk Actions in Table View](https://fluentboards.com/wp-content/uploads/2025/11/Screenshot-2025-11-12-at-3.20.07-PM-1024x360.webp)
FluentBoards’ Table View now supports bulk actions, allowing you to perform multiple updates at once, whether it’s moving tasks to a new stage, archiving them, changing priorities, assigning members, or adding labels, all with just a few clicks.
**How it helps:**
  * Speeds up task management by reducing repetitive manual actions
  * Helps during the [planning phase](<https://fluentboards.com/blog/project-planning-phase/>) by allowing you to assign or organize tasks in bulk
  * Keeps the execution phase smooth and efficient with quick mass updates
  * Ensures you can maintain project momentum without breaking focus

In short, bulk actions bring more efficiency, control, and speed to your Table View, saving you valuable time.
## Bulk Restore and Delete for Archived Tasks
Small upgrade, big relief!
![Bulk Restore and Delete for Archived Tasks](https://fluentboards.com/wp-content/uploads/2025/11/Screenshot-2025-11-12-at-3.38.33-PM-1024x727.webp)
Previously, deleting or restoring archived tasks and stages meant doing it one by one, a time-consuming and repetitive process. 
But not anymore! 
You can now select multiple archived tasks or stages and restore or permanently delete them all at once with just a single click.
**How it helps:**
  * Saves time by eliminating repetitive manual actions
  * Keeps your workspace clean and organized with quick bulk cleanups
  * Gives you more control over managing archived data effortlessly

It’s a small change that makes managing your projects smoother and faster, exactly how FluentBoards should feel!
## Additional Webhook Triggers
In the last update, we [introduced outgoing webhooks](<https://fluentboards.com/blog/fluentboards-outgoing-webhooks/>), a powerful way to keep your tools in sync and your workflows automated. 
![Additional Webhook Triggers
](https://fluentboards.com/wp-content/uploads/2025/11/Screenshot-2025-11-12-at-4.54.06-PM-1024x542.webp)
With this update, we’re taking it a step further to make sure you never miss any important changes to your tasks or projects.
Previously, FluentBoards webhooks were triggered only by core events such as task creation, status changes, stage updates, or task assignments.
Now, we’ve expanded those triggers to cover even more actions, including priority changes, due date updates, label additions, and new stage creation.
With these additional triggers, your integrations just became more dynamic and responsive, allowing you to automate more processes and stay on top of every key activity happening inside your projects.

  * **Improvement** : Better cross-board task movement handling
  * **Improvement** : WordPress Guidelines and coding standards compliance
  * **Improvement** : Enhanced error handling and dependency check
  * **Fixed** : Stages ordering issues in board duplication
  * **Fixed** : Board description rendering issue with ampersands
  * **Fixed** : Task deletion issue
  * **Fixed** : Parent ID falsy (zero) value handling
  * **Fixed** : Default preferences not applied to newly added settings
  * **Fixed** : Subtask group assignment inconsistencies
  * **Fixed:** Microsoft Office files attachment upload issue
  * Other Improvements & Bug Fixes
