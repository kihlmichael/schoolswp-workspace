## Board Export/Import
Previously, you could import and convert [Trello](<https://fluentboards.com/docs/import-from-trello/>) and [Asana](<https://fluentboards.com/docs/import-boards-from-asana/>) boards directly into FluentBoards. But what about FluentBoards itself?
Well, from now on, you can easily export and import any of your FluentBoards! 
To do this, go to the board menu, where you’ll find the export option. With just one click, you can export your entire board!
![FluentBoard Export: 
go to the board menu, where you'll find the export option. With just one click, you can export your entire board!](https://fluentboards.com/wp-content/uploads/2024/08/Screenshot-2024-08-21-at-3.16.10 PM-1024x432.webp)
If you want to import this board, you’ll find the import option ready and waiting!
![To import this board, you'll find the import option ready and waiting](https://fluentboards.com/wp-content/uploads/2024/08/Screenshot-2024-08-21-at-3.21.16 PM-1-1024x272.webp)
Just drag or upload the JSON file you exported earlier!
![Drag or upload the JSON file you exported earlier](https://fluentboards.com/wp-content/uploads/2024/08/Screenshot-2024-08-21-at-3.34.35 PM-1024x293.webp)
Yes, transferring FluentBoards from one website to another is that simple!
P.S.: This feature is only available in the FluentBoards Pro version!

When you update to the new version of FluentBoards, the first thing you’ll notice is a small button that stays with you, whether you’re on the all-boards dashboard or within a specific board!

## Complete Task Activity Insights
Project management is a team effort, and regardless of your team’s size, success depends on accountability, transparency, and clarity.
To hit your targets, everyone must know what’s happening within the project—who’s doing what, what has changed, and how close you are to achieving your goals. 
So, we decided to bring every action and activity of each team member under one roof.
![FluentBoards: Complete Task Activity Insights](https://fluentboards.com/wp-content/uploads/2024/08/Screenshot-2024-08-21-at-2.56.05 PM-1024x837.webp)
Previously, we offered separate sections for comments and tasks. But it wasn’t possible to monitor both at a single glance!
Well, now, that’s entirely possible!
## New Comment Features
Communication lies at the heart of any successful project! The more precise your commands, suggestions, and overall communication, the greater the chances of success!
And, we’ve added two new features to the comment section to make communication even easier, more dynamic, and more functional!
### Mention in comment
You can mention and tag your teammates in the comment section, ensuring that no instruction or conversation goes unnoticed!
![You can mention and tag your teammates in the comment section](https://fluentboards.com/wp-content/uploads/2024/08/Screenshot-2024-08-21-at-4.13.47 PM-1024x582.webp)
### Image in comment
It’s time to be more precise in your conversations—FluentBoards allows you to add images in the comment section!
![FluentBoards now allows you to add images in the comment section!](https://fluentboards.com/wp-content/uploads/2024/08/Screenshot-2024-08-21-at-4.18.06 PM-1024x731.webp)
## Dynamic Watching Options
First off, we’ve relocated the ‘**Preferences Settings** ‘ from the settings dashboard. To enhance user experience and minimize any confusion, you’ll now find them under the User Profile dashboard!
![You’ll now find Preferences Settings under the User Profile dashboard!](https://fluentboards.com/wp-content/uploads/2024/08/Screenshot-2024-08-23-at-11.59.29 AM-1024x338.webp)
The next thing you’ll notice is the new watching notification management options. These make it easier than ever to keep an eye on everything!
![FluentBoards: Dynamic watching options](https://fluentboards.com/wp-content/uploads/2024/08/Screenshot-2024-08-23-at-12.23.08 PM-1024x386.webp)
## Comment/Description Image Paste Feature
The success of your project largely depends on how clearly and precisely you convey objectives to your teammates.
Often, a picture is worth a thousand words! Wouldn’t it be great if you could just copy and paste images directly into the Comment or Description box?
Well, now you can!
With this update, simply copy your image, paste it into the project description or comment box, and it appears instantly—making your instructions even clearer!
## Bug Fixes & Improvements
Progress means not only adding new capabilities but also continuously refining and improving what we already offer!
That’s why, while we’ve been excitedly rolling out new features, we haven’t lost sight of the importance of resolving existing issues.
In this update, FluentBoards brings you these important bug fixes and enhancements:
  * **UI/UX Improvement:** Notification settings moved to User Profile
  * **Fixed:** Codefreeze/Security Plugin issue fixed
  * **Fixed:** 7G Firewall issue fixed
  * **Fixed** : Labels in the duplicated board
  * **Fixed** : Description styling
  * **Fixed** : Board activity styling
  * **Fixed:** Roadmap setting Issue
  * Other Improvement & Bug Fixes
