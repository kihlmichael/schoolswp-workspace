# Comment reproduire ce qu'il dit ?

> Source : texte colle (Substack Nathan Fenina, edition du 2026-05-05)
> Createur : Nathan Fenina
> Format : newsletter
> Capture : 2026-05-07

## Hook

> "Je me suis pris une claque. Claude est devenu mon assistant marketing.
> Carrousels, posts, newsletter, emails, ligne édito — il sort tout dans mon ton. Voici les coulisses du système que j'ai monté."

**Mecanique** : claque + revelation. Aveu de surprise personnelle ("je me suis pris une claque") qui pose une promesse forte (assistant complet). Le sous-titre liste tous les outputs en rafale pour creer la convoitise.

**Pourquoi ca marche** : trois leviers en 4 lignes — vulnerabilite (la claque), preuve concrete (les outputs listes), reveal teasing (les coulisses).

## Structure narrative

1. **Hook claque** - 3 lignes - declaration personnelle + liste outputs + promesse "voici les coulisses"
2. **Salut + accroche perso** - 1 ligne ("Salut, c'est Nathan")
3. **Preuve sociale courte** - 3 lignes - "tourne dans ma boite 7j/7" + ce qu'il sort + "tout sur mon PC, local, avec memoire, avec mon ton"
4. **Section "Ce qu'il fait, concretement"** (puces fleches `→`) - 6 outputs detailles + 2 captures d'ecran
5. **Section "Comment ca marche"** (puces fleches `→`) - 4 briques techniques (.md / memoire / dossiers / commandes) + une phrase de cloture qui isole la valeur ("c'est ce qui fait que ce qu'il sort sonne comme moi")
6. **Section "Une journee typique"** (puces fleches `→`) - 6 commandes slash en exemple + capture + benefice ("5 a 10 minutes pour passer d'une idee a un draft")
7. **Section "Pourquoi c'est different"** - 3 contre-arguments (pas un GPT, pas une chaine Make, pas un agent vague) chacun rejete + une phrase pivot ("c'est un systeme — pas un outil")
8. **Section "Bootcamp"** - softening pre-pitch ("je commence serieusement a reflechir") + offre + 3 bullet promesses + condition de declenchement ("si j'ai assez de candidatures")
9. **CTA principal** - "Si ca t'interesse, remplis ce formulaire" + bouton "Je veux le systeme"
10. **Signature** - "— Nathan"
11. **3 PS** - PS1 = lien direct formulaire, PS2 = engagement (like/repondre/commenter), PS3 = renforce la scarcite ("si pas assez nombreux c'est pas grave")

## Voix et ton

- Tutoiement systematique
- "Je" exclusif (pas de "nous"/"on")
- Registre : decontracte mais pro, peu de jargon technique
- Phrases courtes, beaucoup de retours a la ligne
- Signatures verbales : fleches `→` partout pour les listes (jamais de tirets standards), bullet visuel `✦` pour les sections (caractere unicode atypique), em-dash `—` parfois
- Langue : un peu de franglais ("leadmagnets", "drafte"), assume

## Mecaniques d'engagement

- **CTA principal** : "Je veux le système" (bouton, en milieu-fin, juste avant la signature)
- **Mecaniques secondaires** :
  - Scarcity conditionnelle : "Si j'ai assez de candidatures, je lance"
  - Engagement social : "like-la, reponds-moi, commente sur Substack"
  - Soft preuves : 2 captures d'ecran inserees dans le mail (ligne edito + post)
- **Format CTA** : phrase imperative courte + bouton link
- **PS** : 3 PS distincts
  - PS1 = repete le CTA (lien direct formulaire) — pour les scrollers
  - PS2 = engagement (like + repondre + commenter) — active la conversation
  - PS3 = scarcite assumée et detendue ("si pas assez, c'est pas grave") — paradoxe : reduit la pression et augmente l'envie

## Mise en forme

- Longueur : ~1100 mots
- Densite : faible (beaucoup de retours a la ligne, paragraphes de 1-3 phrases)
- Listes : majoritairement avec fleches `→`, jamais avec `-` ou `*`
- Sections : titrage avec `✦` au lieu de `##`, pas de markdown standard
- Emojis : peu (juste 👋, 👇, 🔓 dans les liens annexes)
- Visuels : 3 captures d'ecran integrees (ligne edito, post carrousel, capture newsletter elle-meme = "le meilleur exemple : cette newsletter que tu lis")
- Citations / mises en exergue : aucune `>` blockquote, juste des sauts de ligne et de l'italique parfois
- Separateurs : aucun `---` visible

## Offre / monetisation

**Offre principale** : Bootcamp "Claude Code Assistant Marketing" — 2 jours intensifs, scarcity conditionnelle (lance si assez de candidatures).

**Position** : presque en fin de mail, apres la demonstration de valeur (3 sections : ce que ca fait + comment ca marche + journee typique).

**Format** : softening verbal ("je commence serieusement a reflechir") + 3 bullet promesses (modules, install, output personnalise) + bouton CTA + repete dans PS1.

**Type** : formation propre (bootcamp 2 jours), pas d'affiliation visible dans ce mail.

## Transposition schoolsWP

### A garder

1. **Hook "claque" personnel** : aveu de surprise + liste rafale des outputs + promesse "voici les coulisses". Mecanique universelle, marche aussi pour schoolsWP ("je me suis pris une claque sur un plugin / un workflow / un audit...").
2. **Structure 3 actes** : ce que ca fait → comment ca marche → comment tu l'as toi-meme. Format newsletter premium qui sera reutilise.
3. **PS multiples avec fonctions distinctes** : PS1 amplifie CTA, PS2 engage, PS3 scarcity/scoop. Deja integre dans le format-newsletter.md schoolsWP.
4. **Scarcity conditionnelle non agressive** : "si j'ai assez de candidatures, je lance, sinon c'est pas grave". Pivot psychologique fort, fonctionne sans culpabiliser.
5. **Captures d'ecran integrees au mail** : 2-3 captures concretes valent mieux qu'un long discours abstrait. Pertinent pour les newsletters schoolsWP qui montrent un workflow / un audit / un plugin.
6. **Demonstration recursive** ("le meilleur exemple : cette newsletter que tu lis") : meta-preuve qui prouve la promesse en temps reel. Reutilisable.

### A adapter

1. **Fleches `→` partout** : signature visuelle de Nathan. Trop forte pour schoolsWP (deja signatures via `:`). On peut piocher selectivement (3-4 fleches max par mail) sans en faire le pattern dominant.
2. **Bullet `✦` pour les sections** : esthetique mais marginal. schoolsWP peut tester un equivalent simple (`---` ou icone unique) sans copier exact.
3. **Bootcamp comme offre principale** : modele B2B/formation. schoolsWP a des formations en preparation (FluentBoards en cours), donc applicable si on attend leur sortie. En attendant, l'equivalent = lead magnet ou avis plugin pilier.
4. **Scarcity conditionnelle** : a adapter en "si X personnes me repondent que ca les interesse, je le fais" plutot que copier l'exact "bootcamp candidatures".

### A NE PAS reprendre

1. **Em-dash `—`** : Nathan en utilise. Interdiction absolue chez schoolsWP (cf BRAND_RULES.md regle em-dash). Remplacer par ` : ` ou ` - ` ou `(...)`.
2. **Franglais "leadmagnet" / "drafte"** : marche dans la niche IA-marketing de Nathan. schoolsWP est WordPress/SEO et reste plus FR-friendly. Privilegier "lead magnet" en deux mots et "redige" plutot que "drafte" si possible (sauf si l'usage technique le justifie).
3. **CTA bouton style Substack** : schoolsWP envoie via FluentCRM, pas Substack. Le format CTA = lien Kadence (cf feedback_kadence_cta_template.md), pas un bouton Substack natif.
4. **Tone "self-aware claque"** repete : peut sonner faux si trop frequent. A garder pour les editions ou il y a vraiment un evenement/observation forte, pas chaque semaine.
