## Questions? I have the answers for you.

Get answers to a list of frequently asked questions.

**FAQ Q:** What are the major new features in TablePress 3.3?

This major update introduces a fixed header bar on the editing screen, keeping the "Save" and "Preview" buttons visible at all times. It also includes a quick navigation menu (accessible via the Cmd/Ctrl+J shortcut) and additional action menus to copy or export your tables instantly.

**FAQ Q:** What improvements have been made to Premium features?

The Pro and Max versions now feature a new "Reset" button for column filters, enhancing the user experience. Additionally, automatic periodic import now features a responsive interface for mobile devices, and column width calculations have been refined to prevent any visual misalignment when filtering.

**FAQ Q:** What are the minimum system requirements for this version?

To install TablePress 3.3, your site must be running on WordPress 6.7 or later. On the server side, PHP 7.4 or later is required to ensure the proper functioning of the new calculation methods and included security optimizations.

**FAQ Q:** Is TablePress 3.3 compatible with WordPress 7.0?

Yes, TablePress 3.3 is fully compatible with WordPress 7.0. The plugin has received a visual style update to align perfectly with the CMS’s new design, while its internal code has been optimized to ensure maximum stability on the latest versions of WordPress.

**FAQ Q:** How does the 3.3 update impact my site’s performance?

Performance is at the heart of this release thanks to on-demand translation loading, which significantly reduces the plugin’s footprint. The removal of obsolete code and the modernization of external libraries enable faster page loading and optimized server resource usage.

**FAQ Q:** How can I ensure a smooth transition to TablePress 3.3?

We strongly recommend performing a full backup of your tables using the built-in JSON export feature before initiating the update. Testing version 3.3 on a staging environment is also recommended to verify compatibility with your specific themes and plugins before deploying to production.
